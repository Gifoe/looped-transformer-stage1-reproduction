# 第二轮确认约定

第一轮在独立 ARC-Easy 与 CSQA 上出现真实双向迁移，也显示跨条件排序能力有限。因此第二轮扩大训练来源，用另一批确认题检验共享结构是否能决定训练数据。

设定 ARC、CSQA、OpenBookQA、QASC、ARC/CSQA 均衡混合五个训练配方，均用 1,119 道训练题及相同 K2/K3/K4 调度。两个种子为 261123137 与 261123271。每个配方用相同更新次数及对应种子相同初始化。ARC 与 CSQA 第一种子的同协议模型直接复用。第二批确认来自 70 道先前未分配的 ARC-Easy Validation 和 299 道新留出的 CSQA Train 问题。各配方在两域上都执行 K2–K6。不能根据这组确认数据回选或再训练。

主效应分别按数据域对两种子及 K2–K6 等权平均同题 acc_norm 改善，跨域通用性按两域较小的百分点看。另报告逐题、原始 acc、归一化 margin 和归一化 log odds。比较只用源标签拟合的事前预测与允许目标域 Train 标签的功能矩预测。两种信息条件单列。K5/K6 仍不参与任何矩估计或控制器训练。来源性能排序使用完整预定配方，不筛去失败的种子或负向条件。

附带有限剂量测试固定第一轮 Train 上共同的归一化 Γ 方向，按 Train 的未中心化状态谱估算读数尺度。独立确认前锁定 4,096 参数因子、三种外部剂量及同一批确认问题哈希。读取固定方向的低剂量正负翻转对称测试有符号预测，三倍正剂量作为非线性压力条件。所有更新仍分别按相同 0.45 相对上限裁剪。K1 层内路径独立观察。 [谱方向](results/SPECTRUM/SPECTRUM.json) · [翻转试验冻结](results/GAMMA/PROBE_LOCK.json)
