# 方法与执行协议

冻结 Ouro-1.4B Base 的全部参数。循环层和每圈末端的 RMSNorm 完整执行。控制器只有一个 2,048 维读向量和一个 2,048 维写向量，共 4,096 个 FP32 参数，无偏置。对每个候选的因果预测位置，计算单一标量读数，再将相应写向量按 0.45 的相对 RMS 上限写回。实际写回转回残差的 BF16 dtype，随后走模型自己的归一化、循环和 LM head。

K2–K6 的默认部署位置在最后一整圈之前，即第 K−1 圈末端的 RMSNorm 之前。K1 使用历史第 21 物理层后位置。实验 C 训练及执行时显式改变注入位置，固定总预算 K4。状态与时域实验在上述原生入口将接收边界和总深度独立指定。扩展接口仅注册临时 hook，恢复模型入口的循环参数。

从零训练以种子固定的随机读轴和全零写轴开始，实际初始算子为零。每组 AdamW 282 次更新、每次四题、学习率 0.001、weight decay 0.03，梯度范数上限 1。训练按题归一，沿用历史排序目标，等权组合温度化原始候选对数似然和字符归一化候选分数。各来源固定 1,119 道题，实际处理的 candidate、target token、padded token loop 和耗时分别记录。历史 T1 只用于冻权插入的归一化和传播分析。

常规推理只读写入位置的当前残差。每个候选用原生题干前缀及原生 LM head 给完整答案文本打分，控制器不访问标签、未来圈或额外教师。用于研究的自然方向参照使用下一圈的未控制状态，属于离线方向对照。标签梯度只用于训练矩、科学机制和事前预测评估。

候选评测包含原始 acc、acc_norm、归一化正确候选对最强错误候选的 margin，以及平滑正确候选 log odds。训练器另保存其历史混合排序效用。配对 bootstrap 按题抽样，按条件报告救回和退化。GPU 台账记录整个受控阶段的实际占用时长。延迟、候选评分调用数和 padded token loop 没有用理论 FLOP 替换。

部署每个预测位置的控制器额外增加一次内积、一次向量缩放及相对 RMS 运算。没有额外骨干前向。下面链接给出分候选 batch 实测和各实验的权重校验。 [控制注入实现](forward_control.py) · [训练与评分](depth_holdout.py) · [GPU 台账](GPU_LEDGER.tsv)

统一方法在第二轮确认前只选定一份权重。固定第一个种子，从 K2–K4 目标域 Train 的功能矩投影估计各候选在两个目标域的效用。每个域先用五个候选投影的绝对中位数确定尺度，再按两个域中较小的标准化预测值选定单一检查点。各深度始终使用同一权重。第二轮全部候选的运行用于检验该选择规则。 [预先锁定的单检查点](results/forecast_round2/SINGLE_CONTROLLER.json)
