# Ouro-1.4B 的秩一控制可以跨深度迁移，收益大小仍依赖任务和后缀

从零训练的 4,096 参数 Rank-1 在未训练深度仍能提高候选评分准确率。固定在第一处、第二处或第三处边界写入时，都能学出有益控制；同一写向量提前一圈经过原生计算后，哪怕匹配接收边界的实际 BF16 扰动量，效用也可能丢失。训练梯度–状态矩支持一个跨条件正一阶方向。它的有符号投影可以说明可行性，第一轮却没有可靠预测跨任务收益大小。

## 深度留出和跨任务

冻结模型的全部参数，比较实际执行过不同训练深度的六个随机初始化控制器。ARC-Challenge 训练 1,119 题，主确认是独立 ARC-Easy Validation 299 题。K2-only 对未训练的 K3/K4/K5/K6 的 acc_norm 分别上升 **9.03、9.36、10.70、9.03 个百分点**，K3-only 对 K2/K4 的增益为 23.41、14.05 个百分点。六组在五个深度的 30 个点估计全为正，最小为 9.03 个百分点。所有配置训练止于 K4。

在相同 K4、三处位置交叉训练的矩阵中，位置专门训练后的本位置正确数为 250/250/255（Native 211/299）。从第 3 圈写入训练得到的权重移动到第 1 圈时为 234/299。后期注入的实际优势包含控制器与训练位置适配，早期位置专门训练也能恢复相近的候选收益。 [完整留出矩阵与位置交叉](DEPTH_TRANSFER.md)

跨任务的两个方向均有收益。ARC-only 在独立 CommonsenseQA 的 K2–K6 提高 6.69–14.38 个百分点。CSQA-only 在独立 ARC-Easy 提高 4.01–19.73 个百分点，K3 的配对区间下界接近零。每项原始准确率、acc_norm、救回/退化与区间均可追溯到原题得分。ARC-Easy 与 ARC-Challenge 的难度分布不同，CSQA 新评测来自官方 Train 中未用于本研究拟合的题。对 Ouro 上游历史 10-shot 示例身份没有完整记录。 [跨任务矩阵](CROSS_TASK_TRANSFER.md) · [样本与历史范围](DATASET_SELECTION.md)

## 因果机制

固定同一个接收状态，仅改变原生后缀长度，历史 Rank-1 在三处接收状态都以剩余一圈获得最大连续效用。以 h1 为例，直接读出、剩一圈、两圈、三圈的归一化 log odds 变化为 **−0.0023、+0.3778、+0.1690、+0.1105**。独立切向干预复现 +0.3790，径向干预为 +0.0002。在三个接收状态的一圈条件中，切向干预的效用约为完整更新的 0.98–1.00 倍。实际逐点 RMSNorm 公式和 BF16 向量高度吻合。RMSNorm 解释了局部方向如何保留下来，后续计算仍决定由这种方向引起的任务收益。 [归一化分析和状态×时域图](NORMALIZED_GEOMETRY.md)

把早写传播和晚写带到同一个接收张量，并配成相同的逐候选全序列实际 RMS 后，晚写的效用优势依然为 **+0.0896**（95% CI [0.075, 0.105]）和 **+0.1605**（[0.140, 0.183]）。任务梯度点积对实际效用的相关性强于范数。恢复早写造成的 Attention 变化对两个边界都有正效应，恢复 MLP 在第二个边界有清晰正效应。它们是分别恢复路径的结果，两项可有交互。 [传播重放和恢复对照](CONTROL_TRANSPORT.md)

训练功能矩在正后缀条件的首方向占 ARC 约 70%–90%、CSQA 约 84%–99% 的 Frobenius 能量。固定后缀或对齐两任务比较时，前五维读取子空间比写入子空间更相近。训练矩联合找到正的秩一下界。ARC 与 CSQA 的可行下界排序在按首奇异值缩放后反转，说明用原始谱幅作为选数据来源的单一准则会受任务单位影响。 [谱、主角和联合下界](FUNCTIONAL_SPECTRUM.md)

## 事前预测

第一轮训练功能矩对 66 个控制器、状态或深度条件的效用符号猜对 64 个。始终猜正也同样猜对 64 个。两个负点都是无后缀的直接读出，区间跨零。全条件幅度排序只有 Spearman **0.161**，平均梯度竞争基线为 **0.283**。只看 K5/K6 时，功能矩排序为 **0.706**，简单平均梯度为 **0.837**。十个跨任务条件的功能矩排序反而为 **−0.406**。方向几何可以提供可检验的充分条件，源域投影无法可靠决定其他任务的效果大小。 [预测和近似误差](THEORY.md) · [真实对照及图 3](results/PREDICTION_AUDIT/AUDIT.json)

第二轮事前冻结了五种来源、两个种子、两个独立确认域的 100 个条件。源矩排序接近零（Spearman **−0.011**，连续效用）。允许使用目标域 Train 功能矩后，连续效用排序提高到 **0.490**，按域分层为 ARC-Easy **0.505**、CSQA **0.741**。限幅代理分别为 **0.536**、**0.778**。限幅代理对实际 acc_norm 净增的总体排序约为 **0.000**，有符号预测准确率仍与恒正基线相同，都是 93/100。全部七个负效用点来自 QASC→ARC-Easy，跨两个种子。模型漏报了这七个方向，且这些条件的 acc_norm 变化是零或正，因此负连续效用和负准确率也不能互相替代。 [预封存值](results/forecast_round2/PREDICTIONS.json) · [100 格效用、准确率和预测](results/ROUND2_AUDIT/RESULTS.json)

| ARC-Challenge | +17.43 | +10.17 | +10.17 |
| CommonsenseQA | +14.14 | +13.75 | **+13.75** |
| OpenBookQA | +13.14 | +7.66 | +7.66 |
| QASC | +9.86 | +7.53 | +7.53 |

按两个确认域中较弱者的 acc_norm 改善，CSQA-only 的点估计最高。事前采用目标域 Train 的投影选择了混合权重。该选择在 ARC-Easy 上保住了最高平均增益，但漏选了确认集上最稳妥的来源。这是几何选型的失败端点。保留事前单检查点和全部对照，不以确认结果换权重。固定混合检查点在 ARC-Easy 的 K2–K6 答对 **56/62/62/61/60**，Native 为 39/50/51/48/51，分母 70。在 CSQA 答对 **186/190/186/185/178**，Native 为 128/159/154/157/157，分母 299。 [单一检查点及 SHA](results/forecast_round2/SINGLE_CONTROLLER.json) · [两种子逐题配对](CROSS_TASK_TRANSFER.md)

第一轮以冻结 Native 为同题对照，未用这些确认题回调剂量或选择位置。第二轮受历史五选项校验限制，QASC 的第一次训练在数据验证时终止。追加官方八选项适配后完成两个种子；初次失败仍计入 GPU 台账。第二轮 bootstrap 首次调用因参数位置错误终止，改用显式 `size=` 后对同一批冻结分数运行，原脚本、初始日志和修正版本均保留。

## 用理论直接构造干预

从两个训练域的联合 `Γ₁` 解取出单一方向，无需额外优化，在读取第二轮确认标签前锁定方向、尺度和剂量。两个确认域、K2–K6 的十个条件中，低剂量正方向全部增加连续效用，反向全部降低，20 个配对区间均排除零。低剂量正向的 acc_norm 增益在 ARC-Easy 为 +4.29 至 +17.14 个百分点，在 CSQA 为 +3.34 至 +8.03 个百分点。两个域的 K1 历史层内位置没有出现稳定的改对净增。K3 的正反效应不完全对称，三倍剂量的收益也不能由线性比例外推。这个实验证实训练功能矩能确定对给定方向有效的干预符号，但第二轮 QASC 的结果给出了跨训练来源自然负迁移预测的反例。 [冻结的方向和剂量](results/GAMMA/PROBE_LOCK.json) · [两域所有深度的正反剂量结果](results/GAMMA/SUMMARY.json)

## K4 真实贪心生成与适用范围

统一提示要求输出选项字母，实际按完整词表贪心生成，最多 8 个新 token。没有正确标签约束解码。表格是冻结解析规则下的“正确／可解析／纯字母严格正确”数量。

| 训练来源 | ARC-Easy（70） | CSQA（299） |
|---|---:|---:|
| Native | 66／70／5 | 172／277／0 |
| ARC-Challenge | 65／68／2 | 158／264／0 |
| CommonsenseQA | 57／58／2 | 63／98／0 |
| ARC/CSQA 混合 | 65／66／1 | 160／245／0 |

冻结混合模型的 CSQA 生成正确减少 12 题，救回 19、退化 31，95% 区间 −8.70 至 +0.67 个百分点。输出可解析率下降 10.70 个百分点，区间 −16.05 至 −5.35。其 CSQA 真实总生成耗时为 8.64 s，Native 为 11.04 s。模型前向次数为 65 对 76，生成 token 为 1,232 对 1,754，耗时差包含各模型的停止行为，因此无同长度推理加速结论。 [完整生成和成本](results/TRANSFER_GENERATION/GENERATION_SUMMARY.json)

CSQA-only 在 CSQA 生成了 198 个小写选项。事后只放宽首字母大小写，正确数由 63 变为 185/299，相对 Native 为 +4.35 个百分点 [0.67, 8.36]。混合臂放宽大小写后只多一题。候选收益与原协议生成退化不应合并计分。这里的单检查点适用于完整候选评分实验，严格格式和自由生成保留作为独立失败端点。 [大小写诊断](results/TRANSFER_GENERATION/CASE_AUDIT.json)

Astra 在 GPU 实验完成后复核了机制和失败结果。下一项最小实验是在新的 CSQA 题上冻结 Native 与 CSQA-only K4，随机置换选项标签，用同一题面分别比较完整候选内容评分、合法字母读出、完整词表贪心。若合法字母读出消除损失，且救回主要来自原本非法的生成，支持格式或词表竞争解释。若约束后仍然退化、错误跟随候选内容而非标签，应否定单纯格式解释。当前证据不足以将候选增强直接带到 GSM8K 长文本推理，本轮保留为独立扩展。

GPU 台账共 2,571 秒（42 分 51 秒），含两次失败的 GPU 阶段。三个研究阶段分别为核心机制与深度留出、五个等预算数据来源、联合谱方向的有限剂量检验与短生成。全部新结果在独立目录。 [单卡复现](REPRODUCE.md) · [GPU 台账](GPU_LEDGER.tsv) · [发布审计](RELEASE_AUDIT.json)
