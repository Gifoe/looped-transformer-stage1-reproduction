# Functional Transferability

冻结 Ouro-1.4B Base。单张已获授权的 RTX 4090 D，同一项目最多 28,800 秒 GPU 台账时间。沿用旧完整候选文本、候选 token 对数似然相加及字符长度归一化。主连续效用为正确候选的归一化分数减错误候选归一化分数的 logsumexp。另保存 raw、acc_norm、正确候选对最强错误候选的 margin、救回与退化。按题配对。真实生成若开展，与候选评分分开。

第一步只检查原生入口的分数、K1–K4 无缓存历史干预的逐位一致和 K5/K6 可执行性。可以用历史 ARC Train 的固定小样本。该阶段只判接口/数值一致性，不选择模型结构或剂量。

验收后单独封存训练和确认划分及预测文件。留出深度模型不得读取旧检查点初始化。主比较使用 K1 历史层内位置（单列），K2–K6 最后一整圈之前的 pre-RMSNorm 边界以及 K4 的三组注入位置。主要数据比较为 ARC 与 CSQA 同数目的问题、同更新次数、相同种子初始化。事前预测需要只依赖训练期的功能矩以及目标状态的无标签观测，记录带符号效用、幅度相对排序和误差。能够读取目标标签的拟合只允许在明确独立的发现集，确认文件不用于选型。对已用过的历史基准显式标注先前用途。

定量机制按边界状态、后缀长度分解。固定历史 Rank-1 法则、小剂量方向、自然循环位移和等实际范数的随机方向。用相同后缀进一步对照早写的传播差和晚写更新，分别报告传播量、输出响应、梯度任务对齐及有符号效用。固定数字精度，记录实际 BF16 更新和范数，不用输入 `u,w` 的余弦作为有效证据。
