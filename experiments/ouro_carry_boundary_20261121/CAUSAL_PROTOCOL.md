# Carry boundary branch test

The behavior gate is defined in PREREGISTRATION.md. Run the branch screen and causal confirmation only when the native gate passes. Discovery uses 96 groups. Confirmation uses a separate 192 groups, with no branch selection or tuning on confirmation.

For each discovery example, measure the K2 target-minus-foil logit gap at the first differing token of the native tokenizer continuations for the exact correct integer and the arithmetic foil. Any shared prefix is used only in this offline diagnostic. Replace the output of a single normalized residual branch in the second pass, at the final token of the original prompt, with its first-pass counterpart on the same example and prefix. Start from the native first-pass state and assert exact equality to the unmodified native second-pass state before calculating differences. For every attention and MLP branch, let damage be the native K2 margin minus the replaced K2 margin. Select one branch per type (attention and MLP) by the largest discovery mean paired difference in damage between stop and its same-answer no-incoming condition, restricted to branches with positive mean damage in stop. Ties use earlier layer. Skip a type if its best score is nonpositive.

In confirmation, record the two native branch writes from the original prompt. Generate full-vocabulary greedy continuations with the exact native decoding protocol. Intervene at the original prompt's final token on all autoregressive steps. For K1, add W2-W1 at the original prompt anchor. For K2 subtract it. Matched controls add and subtract an independent Gaussian direction at the same position with the same per-example Euclidean norm. For forward transfer also add the corresponding natural direction from a different stop example whose correct integer differs by at least 100, rescaled to the same norm. The donor is deterministic and does not use baseline model correctness. Stop, continue, and same-answer no-incoming stop all use the same chosen branch. Record complete generated text and numeric outputs, intervention norm and donor identity.

Report exact integer accuracy, exact arithmetic foil frequency and paired group bootstrap intervals. Use 97.5% intervals for the primary contrasts to account for the two selected branches. Prespecified primary endpoints are the forward excess rescue over the matched control in stop, among all 192 confirmation groups with native +100 and native K2 correct counted explicitly, and the reverse excess restoration of that +100 error over the matched control on the same cases. Report also unconditional nets, cross-example transfer, and effects in both control conditions. Same-example substitution draws on a later pass and is an offline causal intervention. Cross-example transfer is a specificity check. Evidence for local causal mediation requires confidence interval lower endpoints above zero for both primary effects. A transferable carry operation additionally requires positive cross-example excess rescue with a lower endpoint above zero and the recipient integer, with adverse control effects reported. These tests cannot by themselves identify the arithmetic implemented inside a branch.
