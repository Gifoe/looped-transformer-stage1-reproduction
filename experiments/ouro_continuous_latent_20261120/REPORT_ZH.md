# Ouro-1.4B 的连续潜在动力学

**整轮阻尼 Euler 在实测分辨率内呈现稳定的几何收敛趋势。两种连续化得到不同轨迹，与原生循环相比也没有发现可复现、可因果归因的语义步骤链。**

冻结 Ouro-1.4B Base，使用 RTX 4090、BF16、原生 SDPA、无 KV cache。两种方法的 m=1 在三个四样本 batch 中逐位复现原生 K2 的全 token 隐状态和全词表 logits。独立 GPU 复核测量前后的加载参数字节哈希相同。正式轨迹覆盖 1,361 个世界，其中包括 299 道完整 ARC-Challenge 验证集题目。初版 1,584 条干预与补充 594 条三供体配对数据保留在仓库。 [对齐检查](results/NATIVE_PARITY.json) · [权重与耗时](results/GPU_TIMING.json) · [协议](STEP_SIZE_PROTOCOL.md)

## 1. 步长缩小时，隐藏空间是否出现稳定规律？

**整轮 Euler 有稳定趋势，分支微步在 m=32 仍有明显残差。** 两跳新结构留出上，有效 token 全宽终点相对 L2 如下。

| 终点比较 | 相对 L2 |
| --- | ---: |
| Euler m=8 与 m=16 | 0.0176 |
| Euler m=16 与 m=32 | 0.0082 |
| 分支微步 m=8 与 m=16 | 0.2110 |
| 分支微步 m=16 与 m=32 | 0.1293 |
| Euler m=32 与分支微步 m=32 | 1.0254 |
| Euler m=32 与原生 K2 | 0.3193 |

三类数据都显示 Euler 的细化差距缩小。在 12 道先导题上，同等 32 次整轮评估的 RK4 与 Euler 终点差为 0.0064–0.0082。把 Euler 的累加器换成 BF16 后，差距扩大至 0.0133–0.0147。几何证据只覆盖有限分辨率及量化向量场。分支微步的粗步比较可非单调，至 m=32 仍无法确定极限。 [连续动力学](CONTINUOUS_DYNAMICS.md) · [收敛图](results/figures/figure_3_convergence.pdf) · [插值对比](results/figures/figure_5_computed_vs_interpolation.pdf)

## 2. 是否出现可解释且有因果作用的语义阶段？

新结构的双跳任务可从题面确定来源行、规则行、桥柜行和答案选项。K1 的来源探针可读率为 58.6%。桥变量和答案探针都在约 33.3% 的三分类机会水平附近波动。位置标签复核中，原生、Euler m=32 和两种插值的持续桥事件先于答案比例均为 0%。分支微步 m=32 的比例为 12.0%，但桥、答案预测未表现出相应的稳定可读性。复核提示的原生 K2 实际只答对 107/324 个留出世界。这个任务表现限制了对已成功推理轨迹的判断。 [语义轨迹](SEMANTIC_TRAJECTORIES.md) · [语义图](results/figures/figure_4_semantic_readout.pdf)

用原始提示做单 token 替换，并对每个供体用四个等剂量随机方向。原生中点用同规则换桥供体，目标 margin 比匹配随机增加 **0.070**，95% 组 bootstrap 区间 **[0.002, 0.138]**。同一时点的同桥换来源供体也增加 **0.089 [0.007, 0.171]**。Euler m=16 晚段的同规则供体有正效应，但保留供体最终答案的换桥干预为 **0.012 [−0.457, 0.509]**。这一关键换桥对比在三个轨迹、三个时点的区间均含零，早晚差异也均含零。实验证实特定时点的完整向量编辑可以改变分数，现有对照无法把效应归因给桥变量。因此没有依据定位到某次 Attention 或 MLP 更新。 [因果事件](CAUSAL_EVENTS.md) · [等剂量图](results/figures/figure_6_causal_edits.pdf)

## 3. 是否达到 Hidden-Space CoT 判据？

| 判据 | 证据 |
| --- | --- |
| A. 原生中间语义变化 | 来源可以读出，原生桥变量未建立可靠的阶段。 |
| B. 细化后语义顺序稳定 | 几何细化成立，桥与答案的阶段顺序未跨两种构造复现。 |
| C. 中间变量影响后续计算 | 部分单 token 向量编辑改变 margin，同答案换桥的独立检验未通过。 |
| D. 作用迁移 | 几何规律跨任务和结构复现。新词表与改写提示上未确认桥变量的特异因果作用。 |
| E. 超出当前 margin 的预测 | 位置探针在新结构上的 Brier 从 0.2284 升至 0.2361。配对下降为 −0.0077 [−0.0191, +0.0069]。 |

判定为 **连续潜在动力学**。初版探针的跨组随机编号无法由题面唯一确定。初版曲线及干预全部保留，以可见位置重新定义标签后再判定。补充实验分别在改写提示上做语义读出、在原提示上做因果对照。两种提示各自的结论在本实验范围内成立。 [复核结果](results/confirmation/SUMMARY.json) · [复核检查](results/confirmation/CHECKS.json)

## 4. 哪些现象属于原生 Ouro？

原生 K1→K2 由 48 次真实残差更新和一次边界归一化构成。完整 ARC 验证集采用可见选项、单个候选答案字母和严格并列规则。原生 K1 为 **129/299（43.14%）**，原生 K2 为 **240/299（80.27%）**。预扫描的四类 K1/K2 正误转移完整保留。七道题的预扫描首最大预测与正式 batch 有差异，因此分层沿用冻结的预扫描，同时按正式 batch 重新报告无条件准确率。只有固定 48 道分层子集运行 m=16、32。 [原生轨迹](results/figures/figure_1_native_residuals.pdf) · [ARC 转移图](results/figures/figure_7_arc_transition_strata.pdf)

整轮 Euler 的人为时间让带归一化的完整共享栈反复重算。分支微步的人为时间按分支索引刻度定义，按原生顺序复用 Attention 和 MLP。两种构造在 m=1 有完全相同锚点，减小步长后得到不同动力学。Euler m=8 在全量 ARC 上为 **240/299（80.27%）**，分支 m=8 为 **193/299（64.55%）**。几何收敛对答题质量没有单调保证。 [按步长的轨迹](results/figures/figure_2_dynamics_by_step_size.pdf)

## 5. 是否找到可指导性能提升的机制？

没有找到达到该证据门槛的候选机制。最可复现的规律是整轮构造的几何细化，而选定的桥语义事件没有独立预测收益或稳定因果窗口。增加 m 也实际增加了模型调用。本次在完成位置标签与剂量复核后结束。

本结论覆盖固定 checkpoint、原生 K1→K2、两种构造、所测题型及答案位置编辑。更长行程、其他 token 位置和不同形式的语义读出仍在范围之外。全宽轨迹的距离计算使用所有有效 token，发布的原始数值包含逐题轨迹、探针和干预分数，以及两个全宽轨迹见证样本。 [复现入口](README.md) · [原始数据](results/)
