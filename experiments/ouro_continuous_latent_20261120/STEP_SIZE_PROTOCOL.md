# Ouro-1.4B recurrent step-size experiment

The release starts from commit `f5ce67d477e213b3437f403b291c3343c5980aef`. It reuses its 3×3 prompts, token positions and structural split. The model revision is `574fa66cb8bf5abdc979642d01cf2b79b16bfab1`, with frozen BF16 parameters, native SDPA and no KV cache. The pinned forward applies pre-attention RMSNorm, attention, post-attention RMSNorm and a residual addition. It then applies pre-MLP RMSNorm, MLP, post-MLP RMSNorm and a second residual addition. The shared stack has 24 layers and a loop-end norm. Each trajectory starts from native post-norm K1. [Official implementation](https://huggingface.co/ByteDance/Ouro-1.4B/blob/574fa66cb8bf5abdc979642d01cf2b79b16bfab1/modeling_ouro.py)

## Two constructed dynamics

- **A, full-loop damped Euler.** At each of m substeps evaluate the complete next-loop function, including its loop-end norm, with the captured K2 mask and position tensors. Accumulate `H + (F(BF16(H)) − H)/m` in FP32 for m > 1. Total artificial time is 1. At m=1 return F directly, which avoids cancellation at the parity anchor. The pilot also tests BF16 accumulation at m=32 and a distinct four-evaluation RK4 discretization at m=8. The finite-precision vector field is quantized through BF16.
- **B, residual branch micro-stepping.** For each native attention then MLP branch, recompute its own pre-norm, transform and post-norm on BF16 versions of the updated states. Accumulate each resulting increment scaled by 1/m in FP32 (native BF16 addition at m=1). Finish a branch before beginning the next one. Apply the loop-end norm once, after all micro-steps. The branch index divided by 48 defines a progress coordinate for plotting. Its value at the endpoint includes the boundary norm. This is a sequential composition of branch evolutions with a terminal norm.

Measure m=1,2,4,8,16,32 in each family on structured cohorts and the ARC high-resolution panel. Full ARC validation also has m=1,2,4,8. Compare against unchanged native 48 residual updates followed by the loop norm, linear interpolation, per-token norm-matched interpolation, and an equal-dose random walk. The random walk uses A's local full-token update norms and independent random directions. A reports individual substeps. B reports physical branch boundaries at m=1 and m=32, with a common eighth-grid for intermediate resolutions. Interchanging the A and B time coordinates is a descriptive comparison only.

## Evidence split and outcome definitions

- The technical pilot uses four frozen examples per input family from development data. It checks full-logit and full-state parity before the formal runner opens. Pilot examples from synthetic development can recur in that training split. Neither synthetic holdout is selected using pilot predictions.
- The 3×3 factorial uses 16 development groups, 16 new-entity groups and 20 new-structure groups, with all nine worlds per group. It uses the published open-content prompt form.
- The compact two-hop task adds an independent source, source-to-cabinet rotation, and cabinet-to-object rotation. All 27 worlds are measured for each of 10 development and 12 new-structure groups. The structural set uses fresh lexical sets and a changed query template. The rules and readout roles are token-aligned across worlds before they can be used for intervention.
- All 299 official ARC-Challenge validation examples use the zero-shot visible-option, single-letter candidate protocol. The ARC panel selects up to 12 fixed-hash IDs from each observed native K1→K2 correctness stratum. The panel is a conditional view. The rest of the validation population retains the lower-resolution measurements. Exact ties fail the strict scored-candidate correctness criterion. Strata use first-maximum argmax from the initial native scan and preserve any layout discrepancies.
- Normalized full-state distance excludes padding and divides by the comparison state norm. Distinct resolutions are compared at exact common time points. Speeds report relative displacement per reported interval. Turn cosines use consecutive displacements. BF16 output-head logits are restricted only for metric computation. The native parity run compares all vocabulary columns and all token positions.
- Fixed diagnostic readers are trained only on native development snapshots. They use the complete width of the same final query readout token, a documented ridge penalty and three-way group-specific semantic indices. The old 3×3 tableau does not identify an intermediate variable independently of its source. The separately crossed two-hop task provides that control. Onset requires two consecutive correct readouts. Interpolation is scored identically.
- Causal edits at t=0.25,0.5,0.75 replace one answer-boundary state and continue with the real remaining suffix in the same batch. The same-final-answer and different-bridge donor retains the receiver's original final answer under its donor rule. Under receiver rule, the changed bridge implies a different target. The other arms cover the same-rule donor, same-bridge different-source donor, equal-dose random edit, an unrelated token with the same dose and a separately baselined linear-interpolation edit. Pair estimates across groups.
- Predict native K2 correctness on new structural worlds using the midpoint candidate margin. Compare with a model that also gets the frozen reader's probability assigned to the true bridge. The comparison is diagnostic and uses independently supplied semantic ground truth.

## Identification and dose confirmation

The primary two-hop probe labels encoded randomized group-specific vocabulary indices. These indices are not identifiable from the prompt across groups. The confirmation defines source by first-table row, bridge by second-table row, mapping by the second-table row addressed by the first source row and answer by the position in a newly displayed option list. The display order comes from the preexisting counterbalanced candidate order. This prompt change makes the answer index independent of the bridge row, and all confirmation trajectories receive the same modified prompt. The ridge rule, model and independent group split are reused. Analysis checks correct-first-two-readouts, paired onset order relative to interpolation and final-answer margin with the grounded bridge probe.

The dose confirmation separately reuses the original prompts. Each donor is compared with four random directions of its own realized dose, with edit and factual lanes continuing through an identical suffix. The treatment is a whole vector at a single token. Even a consistent effect could implicate several co-varying features. Localization to an operator requires a repeatable time contrast on held-out groups.

Only the natural recurrence is native to Ouro. Constructing a trajectory from a pinned checkpoint has related precedents, including added damped loops and cross-loop transport of particular states.
