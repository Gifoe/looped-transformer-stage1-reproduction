# R13：原 token 投影的完整前缀分解

只读取原 discovery384 与 selection192。两文件从已发布 R7 归档恢复，逐 SHA 验证；未读 confirmation、validation、test。此次新增 GPU 时间为0。诊断定义及源码在结果计算前公开于 `29f29a672e6b9759df4617efe3811f852c02e5c8`。历史开发准确率、其他轮次 ARC 结果均已知，不能称为盲测。

本样本不支持把“完整词表归一化吞掉了有用目标增益”当成首要失败解释。损害更多表现为目标项本身变坏，以及原候选级 R6 纠错在改用 token 公式后消失。

A1为未修正Fixed core加相同晚期项Q4−Q5，共353/576；R6为360/576。“必要”仅指固定对手的 margin 分解中，移除某一代数项会消除该负margin，不表示移除该项后得到合法归一化解码器，也不构成隐藏状态因果实验。表中使用修正后最强错误对手；预先最强错误对手的结果完整保留，M2/M3的A1损害统计相同。损害样本分别只有8题和5题，不外推为普遍规律。

R6相对A1独有的10道开发纠错，M2只保留3道，M3保留2道，桥接保留6道。M2相对R6损害15题，其中7题A1原本已错；M3损害13题，其中8题A1原本已错。不能把这部分都归因于 token 更新误伤，因为换公式首先取消了原R6带来的正确排序。

逐题、逐候选、完整续写位置记录提供了40,251个实际scalar位置（含三个方法），覆盖6,912个候选记录与3,456个固定对手margin分解。令T为目标logit变化，P为负的log-partition变化，则新margin−A1margin=T+P+浮点残差；相对R6还必须加入“撤去原R6修正”的单独分量。

分解沿用原R7以p(Q4)中心化的logit规范；给logits加公共常数会在目标项与partition项之间重新分配数值、同时保持概率不变。因此这不是规范无关的物理机制归因。这些分量来自原真实全词表前向，未从候选LL反推词表。最大scalar恒等误差5.96e−8，评分重建残差2.92e−7，margin残差1.91e−7；所有误差均在保守FP32界内。代码保留残差，不声称位级精确恢复未保存的token概率。

由此冻结并完成了R14的一次检验：保留R6锚点，仅运输“自适应token投影相对整题alpha全词表桥接”的差分。结果349/576，低于R6的360，救回8题、损害19题，未通过预设门槛。该路线已停止，未打开确认/验证/测试集合，详见r14_REPORT_ZH.md。此结果说明仅在分数上保留锚点仍不足以保护正确margin，不能据代数退化恒等式推断纠错能力。
