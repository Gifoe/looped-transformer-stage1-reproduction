# R17: paired answer-cue response probe

This is one explanatory observation after the failed R16 pilot. It is not another decoder, an alternate R16 reference, or a new answer-accuracy experiment. Other benchmarks remain paused, and all files remain in the existing experiment folder.

The untested structural premise is that a response measured in a content-free reference context is relevant to, and transferable into, the real question context. Freeze12 uniformly sampled development questions and the old R6-predicted continuation for each. Change only the current answer cue from `Answer:` to `Response:` in both contexts. Preserve the real question and all25 demonstrations. Independently encode each full continuation and align positions by consumed literal text.

For context C, let `gC=.5*(zC4-zC1)`, with FP32 loop increments. Form cue responses `vC=gC_changed.double()-gC_original.double()` and reference direction `e=gN_original.double()`. Center all primary vectors under the same unchanged native-Q4 distribution and measure full-vocabulary weighted cosines and squared cosines. R2 is the fraction explained by a best signed scalar projection, solely a diagnostic. Check e versus vN and vN versus vQ, plus one fixed shuffled direction control, the original-N4 metric and static e/gQ alignment. Save all scalar prefix metrics and exact baseline parity evidence; do not retain vocabulary activation dumps.

The question is the uncertainty unit. Average positions within each of12 questions, then use10000 whole-question bootstrap resamples and4096 exploratory paired sign flips versus shuffle. The frozen .5 R2 threshold means majority captured energy, never a decoding gate. Reference-majority evidence is required before a low-transfer result can support the conditional failure statement. Undefined directions are explicitly masked; any undefined primary/control position blocks that operational screen.

This is an actual input intervention, but the cue change is not known to be pure nuisance. Failure to align with it cannot prove general reference irrelevance. No universal semantic transport theorem, successful repair or publishable mechanism is assumed. No alternate wording, outcome-selected sample expansion, fitted threshold, heldout result, new decoder or automatic extension is allowed.

One120-second worker plus at most15-second shutdown grace inherits all six prior ledgers under the unchanged21600-second total cap. Cached real states are reused; the changed-real and both reference contexts are actually forwarded to depth4. Same original attention path, frozen model and no KV optimization. This observation is not a standalone deployment profile.

Prior-art scope: [contextual calibration](https://proceedings.mlr.press/v139/zhao21c/zhao21c.pdf) estimates answer biases using content-free input; [domain-context calibration](https://aclanthology.org/2023.acl-long.783/) shows that existing bias estimates do not cover every source of label bias; [APD](https://aclanthology.org/2024.emnlp-main.484/) addresses a limitation of linear contrastive extrapolation through probability-curve extrapolation. These works do not establish that the specific shared-response premise tested here holds for Ouro, and this probe does not reproduce those methods or claim a new decoding principle.
