# Pre-effect statistical definitions

Unit: one original SHA-ranked training/development question. All conditions/depths for a question stay together in paired bootstrap (seed2021,20000 question-index draws, same index schedule for metrics with same n). Main24 and bounded4 are separate populations; never pool rotations/candidates as independent questions. All K1,K2,K3,K4 and all adjacent transitions are reported, not a selected best stage/sign.

Primary native score S is the original GPU FP32 complete-target log_softmax/gather/sum. Letter scoring uses raw sum, no answer-body division. Full-answer targets report both raw and one division by original answer-body character length (leading space excluded); char-normalized is designated full-answer primary, raw diagnostic. Never compare cross-format raw magnitude as one scale. B5 same25demo IDs/order/questions/correct answers, only output format changes; format mismatch/target length remain confounds.

B2 displayed-score argmax uses first displayed label for exact ties, then maps content via order[display]. Compare content-equivariance and display-letter-invariance separately. The subset where inverse_order[P0_content_prediction] differs from P0_display has a reported denominator; immobile content cannot distinguish these notions. All24 stay in the main analysis, even when this descriptive denominator changes with K/prediction.

B3 I_k(i,j)=S_original(i)-S_modified_j(i) only for unchanged i. Every adjacent deltaI=I_(k+1)-I_k. J_k(i,l;j)=I_i-I_l for all unchanged i<l; arbitrary index orientation means positive average J is not intrinsically beneficial. Report question meanabs/RMS J, raw-target-logit pair responses, Q-minus-N/A J/DID and every adjacent delta. The gold-relative quantity is explicitly I_gold-I_other = margin_original-margin_modified: positive means the intervention reduced gold margin. If discussing improvement use its negative, never a result-driven sign choice. FP64 fullV lognormalizers are diagnostics; their decomposition residual against actual FP32 S is retained, not called bitexact. N/A is not pure label bias and question-presence DID remains length/structure-confounded.

B3 secondary is first4 only: independent semantic review plus same whole-prompt token count, same changed-field token positions, exact unchanged prefix/suffix IDs/positions in both Q and N/A. Other20 are scope_not_attempted, not semantic rejections. Same shape does not make a pure semantic/difficulty-matched manipulation. Primary placeholder changes lexical/length/format cues. Final switch reports both display index and actual content text, including replacements at the same index.

B6 first4 fixed color-lookup/direct-letter-copy tasks use rank modulo n target position, independent of ARC gold. Four-task evidence is bounded; ceiling at K1 cannot reject H3. Main no-question target-match is relative to original ARC labels, not correctness of a question that was removed. No statistical metric automatically authorizes Experiment C or an internal causal claim.

B5 statistical matrix uses the same4 IDs for L-letter (P0 alias), L-full, F-letter, F-full. For both predeclared raw and char_norm readouts, report perK correctness and K4−K1, plus all fixed paired accuracy contrasts: demo effect for letter/full targets, target-format effect for letter/full demos, and (Ffull−Lfull)−(Fletter−Lletter). These compare correctness on matching questions, not cross-format raw score magnitudes. Never substitute P0n24 for the4-question L-letter baseline.
