# 查表纠正的证据链

以下证据来自同一冻结的 Ouro-1.4B Base。每次实验都有自己的样本与干预，表中的率按各自分母解释。

| 机制问题 | 已核验的证据 | 判定所覆盖的范围 |
|---|---|---|
| 单层查询能否决定整答 | 第 20 层输出位置交换全部 Q 后，70 道标准格式纠正题中有 21 道 K1 救回、2 道 K2 恢复原错、0 道同题双向成功。与等几何或分号位置对照相比，额外双向率的单侧上界都是 5.13%。[查询实验](../ouro_lookup_query_20261121/REPORT_ZH.md) | 支持一向救回。限制了指定层和位置的双向解释。 |
| 目标值何时可由残差转移 | 第 18 层入口在两种格式首次同时通过跨轮与跨表整答检验。新格式在入轮就出现 13/147 道跨表双向命中。[层界实验](../ouro_lookup_onset_20261121/REPORT_ZH.md) | 后续写入固定在受体原生轨迹。结论限定为残差在这些读取条件下的可用性。 |
| 后续原生计算会如何响应被改写的表值 | 第 20 层 Q 回拨后的残差旁路交换，在锁定后四层时双向转移 49/73，允许后四层重算时为 10/73。[残差旁路实验](../ouro_lookup_residual_20261121/REPORT_ZH.md) | 按当时的 Q 回拨和旁路编辑定义，原生后续重算能补偿部分被移入的值。 |
| 中层注意力写入能否在自由重算下改变整答 | 第 12–17 层注意力写入交换双向通过两种格式，分别为 25/88 和 44/167，几何对照为 2/88 和 3/167。[中层写入实验](../ouro_lookup_midwrites_20261121/REPORT_ZH.md) | 干预涉及完整注意力写入。原生 K1→K2 的选定因子还需隔离。 |
| 两轮路由与内容的乘积是否解释自然纠正 | 联合 A/V 交换在新格式高于两个单换。移除乘积的两格式跨轮双向效应均未确认。随后在原生 K2 动态重算中，仅删除乘积相对几何控制的定向复现效应上界为 7.18 和 3.59 个百分点。[因子交换](../ouro_lookup_av_20261121/REPORT_ZH.md) · [原生删除](../ouro_lookup_necessity_20261121/REPORT_ZH.md) | 按预设阈值结束这一乘积解释。结论约束第 12–17 层的指定删除和完整原错复现。 |
| 两个内容来源冲突时答案跟随什么 | 在同一题的两张表中交换目标行数字位置的 K2 V，或交换前一轮最后位置的输出残差，以完整供体值的双向转移检验两处携带内容的作用。[本轮结果](REPORT_ZH.md) | 两处源位置与下游执行保持可区分。受干预的来源偏好仍需与未干预运行中的路径依赖分开。 |
