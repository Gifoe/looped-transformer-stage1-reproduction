# Which table value follows a target-row V and an incoming answer-position residual?

Use the frozen Ouro-1.4B Base checkpoint with native greedy, FP32 eager, no cache. Freeze 448 new original prompts per layout. Score native K1 and K2. For every exact repair whose original K1 answer is a different value in the table, construct a paired table by exchanging that value and the true value while keeping the queried key, row order, and demonstrations. Construct two companion tables by exchanging only the other two rows' values. Include a fixed 64 native K1/K2-correct originals per layout by hash with a deterministic alternative table value as a stability reference. Only groups where native K2 gives the exact requested value in all four tables, with identical token offsets at the target-span locations, enter edited inference. Require at least 48 eligible repair pairs per layout for a full comparison. Record all denominators and the four native answers. The original and swapped tables are the two receiving directions.

On every actual emitted prefix, independently record the native final normalized K1 residual and native K2 value vectors in both main tables and the receiver's unrelated-row companion. In a V-only arm transplant counterpart native K2 V only at the digits of the *queried row's value*, in every K2 attention layer and all grouped value heads. Keep native dynamic Q, K, attention normalization, other V positions, residual addition and MLP computation. Keep the original K1 output unchanged. In an incoming-residual-only arm transplant the counterpart's normalized final K1 residual only at the current next-token prediction position, from the same emitted prefix; the earlier target digit positions remain causally unaffected and all K2 components recompute. A joint arm transplants both from the same other table, and a clean arm reinstalls the receiving reference values and residual. The two single interventions put the donor and receiver values in conflict while leaving the queried key and all token identities unchanged. All arms decode a full unconstrained integer, in both table directions, without feeding candidate answers.

For each single site, separately test a rotated geometric control matching the true displacement norm and radial component, and an actual unrelated-row-swap displacement at the same read site matched to the true norm per vector. If the unrelated swap leaves a vector unchanged to within 1e-8, use the matched geometric fallback and report its frequency. Numerically audit exact V position replacement, preservation of non-target V and unchanged earlier target V under incoming-residual-only replay, the initial hidden-state edit, attention recomputation and full clean answers. Distinguish dual exact transfer from mismatched integers and generic errors. Do not pool layouts or stable and repair cohorts.

The unit is one paired table. A dual exact transfer emits the counterpart's correct value from the original and the original's correct value from the counterpart, in the same arm. In the repair cohort compare each single against both controls in each layout with paired bootstrap intervals (40,000 replicates, eight Bonferroni-adjusted comparisons, familywise 95%). Support a site only if each layout has at least 8 authentic dual transfers and all its lower bounds are positive. Compare the two single-site dual rates descriptively, characterize the two conflict directions, and report the joint calibration and stable wrong-other rate. Estimate conservative one-sided 97.5% simultaneous upper bounds across all eight comparisons using extra dual successes and ignoring losses. Exclude effects of 10 percentage points or more for a path only if all four corresponding bounds are below that threshold. When cross-layout support and exclusion both fail, retain uncertainty. These interventions test the controlled transfer and competition of information at nominated sites; they do not alone identify natural path necessity.
