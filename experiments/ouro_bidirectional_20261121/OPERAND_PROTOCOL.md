# Recombination of a natural first-loop operand state

This independently specified causal test asks if K2 combines a natural H1 state for one operand with an unchanged recipient context. It does not change eligibility, pass rules, or outcomes of the exact common-K1-answer study. It does not test the carry-stop explanation, which failed the preceding behavioral gate.

Use the first available stem (smallest stem number) whose first operand is manipulated in each frozen midpoint bin, with both recipient directions. Choice uses input pairs only. Retain the pre-existing disjoint midpoint splits. For each recipient A+B use the other first operand A* from its stem. Obtain the natural donor's H1 at protected input positions from a prompt A*+B*, with B* different from B by exactly 100. Select B* so that A*+B* is three digits, differs from both recipient A+B and test answer A*+B, and does not change prompt token count. The transplanted positions end before the second operand, hence have no causal access to B*. All K1 output-side hidden states stay native, including the final prompt position and every generated-prefix position. The alternative complete correct answer is A*+B. Score actual free greedy generation of the first complete integer. Use the same fixed checkpoint, demonstrations, output parsing and native K2 continuation as the native run.

Prespecified primary treatment replaces all first-operand tokens through the last prefix token before the second operand, starting from the first modified input position. Primary placebo rotates each natural replacement around its recipient vector, matching the replacement vector norm and distance to the recipient exactly up to numerical tolerance. A secondary intervention transfers only differing token positions, with the same control. Compare every treatment's exact open outputs to the counterfactual A*+B, donor sum A*+B*, and recipient's original answer. Exact replay of recorded native K2 tokens, bitwise equality of the full native second pass and resumed forward, and unchanged direct unembedding inputs are implementation checks. Record token IDs and geometry.

Primary success requires the matched difference in both directions' exact counterfactual integer switches per stem to have a positive bootstrap lower endpoint (95%, midpoint as unit over all 200 confirmation bins including unalignable rows scored zero) and at least 12 confirmation bins with two switches. Report unconditionally and on the oriented subset whose original clean answer was wrong at K1 and correct at K2, with fixed denominator and separate native counts. Report the number of exact donor sums rather than combining them with counterfactual answers. The secondary treatment and subset are descriptive until confirmed independently. This establishes K2 access to operand-bearing prior state only if the treatment exceeds the placebo and yields the recipient-conditioned integer. Downstream operators require a further mediated intervention.
