# Counterfactual first-loop state transfer

Run only after the frozen native gate passes. For the exact direct-reversal stems, compare the lower and upper recipients at their K2 decoding runs. They have the same K1 integer and different correct K2 integers. Use no learned modules or altered model weights. Prompts must have the same token count. Define changed input positions by actual differing token IDs in the original prompt and require a nonempty set disjoint from the final prompt token. Record ineligible alignments in the denominator.

At every K2 greedy generation step independently compute native H1 from the recipient prompt and its generated prefix. Obtain donor H1 from the paired prompt with that same generated prefix. Resume the native next iteration from H1. Verify bitwise state equality with a full K2 pass on the same examples before any intervention. In either transfer, insert the donor's natural H1 vectors at the fixed positions of the original prompt, while keeping recipient H1 everywhere else. The baseline and three treatment families below must complete through the exact full-vocabulary decode. The donor can come from the opposite true direction because its K1 result is the same.

1. Replace only the positions with different input token IDs. This leaves the native H1 final prompt and all generated-prefix readout vectors exactly equal to the recipient's.
2. Replace only the final prompt token state. This candidate may be a local answer-bearing representation.
3. Independently for each type, generate controls with the same replaced-vector norms and angles to the recipient at every position. Use the actual donor vector's component parallel to the recipient and rotate its orthogonal component to a fixed-seed random orthogonal direction. Verify distances and geometry, and log exact anchor identity under type 1.

Discovery/confirmation assignments never overlap in midpoint bins. Evaluate both position types on eligible direct-reversal stems. The independent confirmation endpoints are the number of complete outputs equal to the donor correct integer and the rate at which both transfer directions in one stem follow the corresponding donor exact integer, in both treatments and controls. The primary gate for mechanistic continuation is positive matched-control excess in two-way transfer for changed positions, with 95% cluster bootstrap lower endpoint above zero, and a minimum of six independent bins with two-way donor swaps. Readout swaps are a diagnostic. The original full-state donor replay is an implementation positive control, not mechanism evidence.

If that transfer gate passes, test attention mediation. In discovery compare restoration of each K2 attention residual write at positions after the last changed prompt token, reusing natural recipient writes. Select the smallest layer index among those maximizing the recovery of recipient direction in the original exact-correct vs donor integer diagnostic. Freeze the selected branch before applying confirm. On confirmation directly re-decode with that write restored. Compare exact recipient restorations against geometry-matched restoration controls while keeping the original hybrid input. Evidence for mediation is matched-control excess restoration under predeclared cluster inference. If discovery contains no aligned direct reversals, report the causal evidence limit.
