# Ouro-1.4B Base 跨循环保留与重用的操作数信息

同一冻结模型、同一组六个加法示例、同一完整词表贪心解码。评估首个非空行完整整数。题组以中间整数隔离发现和确认。所有运算数无序对与先前两组加法试验及示例互斥。

## 同一 K1 错答能否向相反方向修复

确认集 200 个中间整数、1600 个严格配对。对内保持一个完整操作数及另一个操作数的低两位。原生 K1、K2 分别答对 3026、3151 道（每个深度 3200 道）。
两道 K1 都生成预定中间错答的有 **0** 个严格配对，覆盖 0 个中间整数。K2 在 0 对按各自正确方向完整答对，交换 K2 输出后为 0 对。严格门槛未通过。
低真值一侧、高真值一侧的入口计数分别为 14、7 次（允许重合）。允许跨题干按同一错答重配时，双方分别出现的中间整数共有 0 个。另有 0 对共享其他错误整数。跨题干与其他错答结果为描述性诊断。

## 保留 K1 读出，换入另一个第一操作数

原题 A+B 的第二轮输入只替换第一操作数到第二操作数之前的连续 H1 状态，供体是 A*+B*。受体的末提示位置及生成位置仍使用自身 H1。B 与 B* 相差 100，并核验在供体前缀的 H1 相同。植入内容未读到 B*。实验区分受体原答案 A+B、目标 A*+B 与供体完整答案 A*+B*。

确认集 200 个题组，200 个满足 token 对齐。主比较为两个方向都实际生成完整反事实整数，随机对照逐位置匹配替换向量范数与对原向量角度。

| 处理 | 生成 A*+B | 同组双向生成 A*+B | 生成 A*+B* | 生成 A+B | 原生 K1→K2 纠错题中生成 A*+B |
|---|---:|---:|---:|---:|---:|
| 原生复跑 | 0 | 0 | 0 | 396 | 0/14 |
| 整段自然状态 | 138 | 41 | 4 | 241 | 10/14 |
| 整段等几何对照 | 0 | 0 | 1 | 358 | 0/14 |
| 仅变化数字位置 | 134 | 40 | 3 | 251 | 9/14 |
| 数字位置等几何对照 | 0 | 0 | 1 | 392 | 0/14 |

双向生成的配对超额为 +20.50 个百分点，95% 区间 [+15.00, +26.00]，通过独立预设门槛。逐题原始 token 序列与控制范数检查见 results/。

按预先固定的首个题干取样后，确认集有 0/400 个方向涉及向百位进位。移植后的 +200、−200 正确切换分别为 47、91 次。本轮支持加数状态参与第二轮作答，结论限定在所测数值差与进位覆盖。原生 K2 修复子集的移植结果属于描述性分析。
