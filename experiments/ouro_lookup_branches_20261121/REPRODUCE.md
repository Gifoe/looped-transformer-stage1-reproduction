# Reproduce the branch-specific late suffix test

Use the archived inputs and runtime in results/VERIFICATION.json, and the previous experiment modules in env.sh. Leave the checkpoint frozen. Run branches_deck.py with the model and output paths, then branches_test.py. The first script builds both native baselines and defines the independent original and paired groups. The second script regenerates whole answers on every condition. report.py verifies the data, statistics and figure.

At every layer \(\ell\) in the late suffix, the raw output is its incoming residual plus normalized attention and MLP writes. For each choice of branches, replay that question's K1 write on the current emitted prefix at the selected positions. Normal operations in unselected branches recompute. Holding both writes fixed through layer 24 at the output position leaves the pre-normalization difference between modified K2 and native K1 equal to the difference between their layer-20 output states. A clean K2 identity and that additive relation are checked on the fixed diagnostic cohort for both spatial scopes.

The matched geometry displacements preserve each K1-vs-K2 branch-write change's Euclidean norm and radial projection on the native K2 write. Full-prefix arms change later attention inputs away from the output position as well. They are reported separately. Exact behavioral restoration requires the same wrong table value to be reintroduced and reversed under the specified corner of the factorial. Paired tables newly correct under K2 are separate, and any paired table already correct in K1 contributes only harm outcomes.
