# Factorial late attention and MLP replay in natural lookup correction

Use frozen Ouro-1.4B Base, native FP32 eager/no cache and the inherited four-key lookup prompt. Freeze 448 new independently drawn original tables. The primary cohort is every original with native K1 emitting a different table value and K2 emitting truth. Test the paired table (swap queried and original wrong values, keeping row order) separately if its K2 is correct; paired K1-correct cases measure harm only. Require at least 40 exact original natural corrections to run interventions. No conditioning on paired outcomes in the original cohort.

In each generation step record native K1 and K2 on the receiver and the same emitted prefix. Preserve all native computation through K2 layer 20. In layers 21–24 factor whether normalized attention writes and normalized MLP writes are allowed to recompute or replaced by the same question's K1 writes. Retain exact native K2 as the both-adaptive arm. Primary interventions act at the current output token only. Separately run the same factorial with the entire valid emitted prefix replayed, to detect effects from earlier positions in the late suffix. Preserve both phases' original K, V inputs and residual computations before the physical intervention site; subsequent native operations may adapt. The matched controls replace each true branch displacement with a deterministic randomized direction having the same norm and radial projection from its native K2 write per token and layer. Record complete generated integers with the original stopping rule.

For each branch require both directions on the same question. Replaying this branch alone must reproduce the exact K1 wrong value. Starting from both replayed, whose exact output must be that wrong value, allowing just this branch to recompute must recover truth. Compare to the same factorial of geometry controls. A positive joint-only effect requires that both individually restored cases remain wrong but the intact case is correct, starting from both-replay exact old error. Separately report cases with redundancy (either individual restoration is sufficient), each directional effect and the signed factorial effect on correctness. Require at least eight genuine extra-pattern candidates and positive lower paired 97.5% intervals versus geometry for branch or joint support. For each branch and joint pattern, prespecified exclusion requires single-sided exact 97.5% upper bound below 10% for any extra such pattern over geometry within an independent original target group, with complete coverage. Do not pool output-only with full-prefix or originals with paired tables.

On 24 fixed original questions at their common leading whitespace, audit exact unchanged K2 replay. With both branches replayed at the output token, check that the pre-normalization final hidden difference from K1 is the difference in the two phase inputs to layer 21. When a phase's own later writes are replayed, its baseline output must be reconstructed. These checks establish additive update isolation and do not replace whole-integer endpoints. Conclusions are constrained to this lookup distribution and fixed physical suffix.
