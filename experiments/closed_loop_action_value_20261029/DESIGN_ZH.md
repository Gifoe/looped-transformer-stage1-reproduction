# 第二轮：让中间动作价值参与状态更新

用户于 2026-10-29 澄清：中间变量能驱动继续计算或反馈修正，是核心研究问题；超越 LoopCD 仍是重要结果。第一轮 No-Go 保持原结论，但不将末端选择失败等同于所有闭环反馈机制失败。本轮没有已经发现有效变量的主张。

## 变量究竟是什么

定义概念上的动作价值

`V_r(a) = E[Q(rollout(T_a(h_r))) - Q(rollout(h_r)) | x, trajectory through r]`。

这里 rollout 表示从干预后的状态继续执行冻结的剩余循环；推理时没有真实答案。这个定义本身不是估计方法，也不是创新证明。与上一轮的区别在于训练或检验目标来自**状态干预后的后续轨迹**，不是从已经完成的轨迹中重新选读出。动作价值也不一定能被一个通用标量充分表达：先保留按动作区分的值与证据可用性。

先把控制问题限制在第 2 轮的一个决策点：`d2=h2-h1`，`T_a(h2)=h2+a*d2`。a=0 是原样继续；a=-1 撤回本轮状态更新；a=-0.5 部分撤回；a=+0.5 外推。这些是 norm 之后、真正送入第 3 轮的状态。保持官方剩余循环和最终 Adaptive LoopCD 读出一致，以隔离状态反馈的影响。撤回已计算的状态不节省已付出的计算。

## 第一个可执行估计器：输入证据的干预响应

只使用当前问题中已知输入 token，把原有因果位置探针按顺序交错分成 A、B 两组。各组至少两个 token。对各动作计算已知 token 的平均负对数似然 `L_A(a), L_B(a)`。先仅用 A 选择损失最小的非零动作，再让 B 对这个唯一候选进行否决：

`a* = argmin_{a in {-1,-0.5,+0.5}} L_A(a)`；

`v_A = L_A(0)-L_A(a*)`，`v_B = L_B(0)-L_B(a*)`；

`v = min(v_A,v_B)`，仅当 `v > 0.001 nat/token` 才执行 a*，否则 a=0。

该阈值只用于预先固定的数值容差，不是统计置信界。A/B 是同一问题的相关 token，不能称为独立证据；B 是一次性否决探针，不是未暴露的最终测试。全问题已知 token 用于选动作在条件预测中允许，但不保证代理损失与答案正确性一致。动作选择先在无候选答案的 prompt 上完成，同一动作随后用于所有候选的完整似然评分。候选答案、gold 和候选正确性不进入控制器。

这是标准有限动作搜索与输入自监督检验的组合，当前不主张新颖。它优先回答：输入证据是否能指导有用的真实状态干预，而不只是被动相关。

## 证据层级和失败含义

1. **可实现性**：零干预与官方计算逐 token 一致；非零干预真正改变后续状态；冻结权重；动作选择不读取 gold。这一级通过只说明实现正确。
2. **机制有效性**：在开发数据上预先记录每种干预的潜在结果，检查变量对真实后续收益的区分能力，并对照置信度、同触发率随机动作、固定干预、仅改末端读出。变量打乱后若效果不降，就没有选择性控制证据。
3. **算法有效性**：在未暴露的独立数据上，相对 Adaptive LoopCD 和等计算基线取得配对准确率或预先规定的准确率—成本优势。不能用第 1 级替代第 2 级，也不能用第 2 级宣称超过 LoopCD。

先运行 8 题已暴露 OpenBookQA discovery 的唯一实现试验，累计运行上限 20 分钟。记录所有动作及原始逐候选分数，不以这 8 题选择符号、阈值或参数。此试验不是统计筛选或方法性能证明。若实现成立，下一步需锁定开发干预实验，而不是立即启动全量确认。旧 ARC1172、Qwen600、SciQ1000、PIQA1802 全部不得充当新确认集。

真正的 early stop 暂不实现：不能把“代理证据不足”当作“后续计算无价值”。停止需要另行验证继续的边际价值及节省的实际成本。若引入小头，其监督必须来自冻结主干上的实际状态干预收益，并与训练免费版本分开报告；本试验不训练任何头。

## 与邻近工作的关系

- [TAPS](https://arxiv.org/html/2609.36653v1)：已经控制更新步长。仅把动作称为继续/反馈不构成区别。本候选要验证的是已知输入证据能否带来超出几何统计的动作价值信息。
- [Readout Feedback](https://arxiv.org/html/2608.24136v1)：已经将读出信息反馈进状态。必须证明自己的证据来源、干预方向和有效场景，不能仅以闭环为创新。
- [TaH2](https://arxiv.org/html/2609.35748v1)：已经用计算收益监督深度决策。冻结主干上的反事实动作收益可能是实现区别，不自动成为学术贡献。

因此本轮优先建立“可测量—可干预—可证伪”的变量；超越基线仍保留为算法成功标准，不预设为必然结果。
