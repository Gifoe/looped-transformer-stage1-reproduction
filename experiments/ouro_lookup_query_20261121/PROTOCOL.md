# Bidirectional lookup Q intervention on controlled tables

Keep frozen Ouro-1.4B Base in native FP32 eager/no-cache execution and use complete free generation under the existing parser. Freeze 64 development and 320 confirmation sources, with independent source answer targets. Source keys are balanced across four labels. Table order and association with three-digit values are independently randomized. Construct one permutation that moves the old answer to a different key while keeping physical layout, and a second that retains the new value mapping and moves the requested key's row to a different physical slot. Preserve each native K1/K2 result.

Select one physical layer and its full query-head group. In development only, for native K1 wrong-table-value to K2 correct transitions, find the natural shared whitespace continuation before the first generated digit. At the final position measure, for all layers and heads, the change in attention mass on the correct key/value field versus the earlier wrong-value field. Select the single layer with largest mean signed correct-versus-wrong routing gain. Freeze it before the confirmation interventions. Use the causal query at the final available token in each answer-generation step. A location-control query is the semicolon immediately preceding the Answer marker. It can see the table but is not the token being read out.

On the original confirmation prompt, replace only the selected layer's post-rotary Q at the current final position with the authentic other-loop Q on the same emitted prefix. Run K1 with K2 Q and K2 with K1 Q. Preserve K and V and all other unedited operations at that site; recompute native downstream layers. Reapply the edit at every generated token to measure complete integers. Direction matching at the target position preserves Q displacement norm and its projection on the incoming Q per head, giving matched final norm and angle. A second control transports the same displacement dose and radial fraction to the non-output semicolon query, retaining the normal output query. No candidate answer constrains generation.

For transfer, transplant original source K2 Q into the K1 recipient whose table values were exchanged, either with unchanged physical row order or with the requested row moved. The receiver retains its own native K/V and all current recipient tokens. Score the receiver's newly associated value, original source answer, original wrong receiver value, and other answers separately. Main transfer denominators require original source K2 correctly answering and variant K1 initially returning a different table value while variant K2 answers correctly. Do not require the original K1 to be wrong in the main transfer test. Separately report overlap with original natural corrections. This keeps ceiling cases from being mistaken for successful rescue. Report both layout-preserved and crossed transfer.

Preregister evidence gates. Main bidirectional support requires at least eight same-question exact paired successes, K1 rescue to truth and K2 reversal to that question's original wrong value, and positive lower paired 97.5% intervals against both controls. Include each direction independently. Address transfer additionally requires at least eight exact new-target answers and positive lower intervals versus both controls in both remappings. True Q copying of the donor's old value is tabulated separately. Test a large-effect exclusion for original bidirectionality using a one-sided exact 97.5% upper bound below 10% for any extra dual success within a target group relative to each control at complete cohort coverage. Scientific nomination uses only development, and no new layer or heads will be chosen after reading held-out results.
