# K1→K2 confirmation protocol

The source is Ouro-1.4B Base at revision 574fa66, running frozen BF16 native loops without KV cache. Corrected input manifest SHA-256 is 4a255369c16f6fdf52d4f2569f47097a10044f4379ae533d8fc21587f96f608d. Cohorts are inherited unchanged. Use four factorial worlds per group. Natural model inputs are five coordinate-aligned role means at K1 post-loop norm. No answer, semantic label, later-loop state, outcome or intervention metadata enters transition fitting or inference. Context-only uses a hashed token count vector from the unedited recipient prompt. Fit-time diagnostics may use labels, but are kept separate from transition models.

1. Fit shared, loop-agnostic random projection, PCA, role-structured PCA and residual autoencoding at total latent widths 32, 64 and 128. Each model sees only natural fit states. For each encoder compare identity, ridge residual, reduced-rank linear residual, residual MLP and a four-expert low-rank residual mixture. Report reconstruction and covariance effective rank. Select hyperparameters on the 100 discovery groups by K2 prediction of all held-in downstream coordinates (mapping, query, readout). Round 1 uses stored 96D role vectors and Round 2 refits the frozen configurations and all full-coordinate linear baselines on the new 2048D role vectors. A representation-specific result is identified explicitly.
2. Full-width natural acquisition uses all 3,000 groups and their four worlds. For each task, a double-hashed deterministic selection (exclude previously intervened IDs, then hash-sort) uses 60 confirmation and 60 structural groups. In each group, swap the receiver's K1 post-norm source tokens from the same-mapping different-initial-binding world in every direction. Source tokens include the full previously defined source region. Hold other receiver states fixed. Re-run the actual second loop. The selection has no dependency on outcome, effect or label value. Eight confirmation groups per task also receive two norm-matched random physical interventions. Record exact full-boundary replacement and self tests in a distinct technical run.
3. Primary comparison uses squared response error for mapping, query and readout, each normalized by its K1/K2 fit-coordinate RMS. Compute group means over four directions, then use paired group-bootstrap intervals for the ratio-of-means improvement. Also report response alignment, norm calibration, fit-only K2 diagnostic semantic-score responses, and answer-margin changes. Downstream answer preference uses the frozen native candidate-token head for the full-width readout. A random prediction uses independent seeded directions with radius calibrated from natural fit source-to-output changes. Context-only has zero predicted effect because recipient text is fixed.
4. A candidate advances only if natural error improves over the strongest discovery-selected simple baseline on both independent splits, and if full-width causal error improves by at least 10% versus every simple baseline with positive paired 95% bounds in both splits for at least one task. Also require positive agreement with true changes in downstream behavior and intermediate semantic contrast on the structural split, with a positive causal semantic-error improvement versus the best simple baseline. Treat task-specific successes individually. If none advances, stop before operator-chain or full benchmark expansion. Cross-task transfer fits frozen low-dimensional families on the two remaining tasks and evaluates post-loop changes in the third, holding all target-task samples out of fitting.
5. Raw full-width arrays are private compute-server artifacts with SHA-256 inventory. Git release includes group-level error/behavior records, frozen configuration, archived lightweight model weights, trajectories for fixed cases, source, runtime and audit logs.
