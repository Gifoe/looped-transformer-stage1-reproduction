# 实验 A · 共享控制方向与幅度

冻结 Rank‑8 T1 的实际写入在 48 个几何分层中的 47 个达到预注册共享性判据。唯一例外是 OpenBookQA 的 K1 候选续写，实际单位写入的第一未中心化主成分仍解释约 97.91% 的能量，Train 轴余弦中位数为 0.97898，低于 0.98 的阈值。ARC Validation 上，将冻结 Rank‑8 写入精确投影到 Train 轴，保留了 K2–K4 两项候选准确率中相对 Native 合计增益的 97.6%。本题剂量相对置换改善 K2、K3 的原始候选 margin，K2–K4 的贪心正确率相差 +0.11 pp [−0.33, +0.56]。 [预注册理论与判据](THEORY_HYPOTHESES.md) · [几何审计](results/A/A1_QUESTION_WEIGHTED.json) · [候选析因](results/A/A2_FACTORIAL.json) · [生成审计](results/A/A2_GENERATION_AUDIT.json)

## 协议

- 共享轴来自历史 ARC Train 产物 `mean_direction_rank1.pt` 的 `out.weight`，保留符号并归一到 RMS 为 1。Ouro‑1.4B Base 与 Linear Rank‑8 T1 全程冻结。K1 写入第 21 个物理层之后，K2–K4 写入最后一轮之前的原始残差。每次写入覆盖所有合格的因果预测位置。 [历史共享轴权重](https://github.com/Gifoe/looped-transformer-stage1-reproduction/blob/19889f317cc9ffde5cdc2ecb8f5d81eac15b8cf7/experiments/ouro_minimal_functional_feedback_20261123/results/CAUSAL_ANALYSIS/mean_direction_rank1.pt) · [代码与输入哈希](results/A/A_LOCK.json)
- A1 覆盖 ARC-Challenge Validation 299 题、OpenBookQA Test 500 题，分别沿答案文本候选前缀与历史 Rank‑8 实际贪心 token 前缀测量。候选协议在简洁题干后评分整段选项文本，生成协议在列出字母选项后开始解码。贪心轨迹几何用归档 token 教师强制回放。两个任务各深度的候选轨迹写入 6,770 和 6,676 个位置，其中分别有 5,576 和 4,676 个位置具有非空答案前缀。四深度的贪心轨迹写入分别为 ARC 956／1,004／1,002／1,385，OpenBookQA 1,542／1,822／1,961／2,645，包含每题生成首 token 的末提示位置。 [逐位置原始几何](results/A/A1_GEOMETRY.json)
- A2 使用 ARC Validation 的 1,194 个候选和相同写入点。原始候选分数为答案 token 对数概率之和，归一化分数再除以答案字符数。`acc` 与 `acc_norm` 分别按对应的最高分候选计算准确率。Margin 是正确候选得分减去得分最高的干扰项。表中置信区间采用 10,000 次按题重采样的名义 95% percentile bootstrap。Native 与 Rank‑8 的候选分数、真实生成逐题记录均沿用历史归档。 [候选分数与配对结果](results/A/A2_FACTORIAL.json)

在相同深度和位置分层内，ARC 与 OpenBookQA 候选轨迹未中心化主轴的绝对余弦至少为 0.99958。归档贪心轨迹的对应绝对余弦至少为 0.99996。候选续写中，等题权的跨题平均余弦为 0.96668–0.99657。按同一题、候选和前缀对齐后，K1 对 K2–K4 的候选续写余弦均值为 0.938–0.952，K2–K4 之间为 0.992–0.999。贪心续写的跨深度比较要求已生成前缀相同，每对深度覆盖 ARC 137–276 题、OpenBookQA 156–439 题。上述几何只刻画观察到的写入方向。它不直接估计固定上下文的可控维数或输出空间响应。 [跨任务及跨深度配对](results/A/A1_QUESTION_WEIGHTED.json)

有符号投影的反向写入只在候选续写少数位置出现，ARC K1 19／5,576，OpenBookQA K1 和 K4 各 1／4,676。末提示及贪心轨迹写入均为正。按题等权，K2 候选续写的限幅触发比例为 ARC 23.08%、OpenBookQA 11.08%，相对残差 RMS 的限幅后剂量中位数为 0.3215、0.2433。K2 的贪心末提示两个任务均无触发，中位数为 0.3337、0.3208。K1、K3、K4 的 ARC 贪心末提示均达到上限。工作剂量是否饱和同时取决于深度和提示协议。 [符号、原生残差与剂量分布](results/A/A1_QUESTION_WEIGHTED.json)

## A2 · 完整候选析因

对限幅后的原 Rank‑8 写入 $u$，以 $u=\alpha v+\varepsilon$ 分解。共享投影写入 $\alpha v$。同范数共享轴、翻转轴与一条固定的正交随机轴均使用原 Rank‑8 的向量 RMS，符号参照 $\alpha$。原生残余写入 $\varepsilon$，同范数残余把 $\varepsilon$ 放大到原写入 RMS。固定幅度始终写入 $+0.45\,\mathrm{RMS}(h)v$。置换幅度从同一任务、深度和预测偏移的其他题移入有符号相对剂量，并乘以受体自己的残差 RMS。末提示对同题各候选共用一个供体。每深度的 6,770 个位置中有 25 个超长尾部位置无法跨题置换（偏移 21–33），留在同题。 [各干预的逐题完整分数、范数与置换记录](results/A/A2_FACTORIAL.json)

**H1 · 共享方向承载主要候选收益。** 按 K2–K4 计算，共享投影保留 Rank‑8 在原始准确率上 125／126、归一化准确率上 157／163 的合计净增量。相对 Native，K2、K3、K4 的 `acc_norm` 分别增加 18.73 [13.38, 24.08]、18.39 [13.38, 23.41] 和 15.38 [10.70, 20.07] pp。与同范数正交随机轴相比，K2–K4 归一化准确率分别增加 20.74 [14.72, 26.76]、22.41 [17.06, 27.76] 和 17.73 [13.04, 22.41] pp。对照组与 Rank‑8 的 BF16 实际写入 RMS 逐位差的平均值为 $1.2\times10^{-5}$–$5.8\times10^{-5}$，最大不足 $2.75\times10^{-4}$。随机对照使用一条固定的正交轴，结论对应这组配对干预。 [配对结果](results/A/A2_FACTORIAL.json)

**H2 · 本题剂量改善部分连续分数。** 共享投影相对置换，在 K2、K3 的原始 gold margin 分别增加 0.339 [0.117, 0.571]、0.119 [0.026, 0.216]，归一化 margin 变化为 0.0079 [−0.0015, 0.0169]、0.0022 [−0.0009, 0.0053]。K2 相对固定 +0.45 的原始 margin 增加 0.520 [0.223, 0.845]，`acc_norm` 增加 2.34 [−1.00, 5.69] pp。K3 相对置换的 `acc_norm` 增加 2.01 [0.33, 4.01] pp（纠正 7、退化 1，精确 McNemar $p=0.070$，名义区间）。K4 的固定幅度比共享投影多答对 3 题（`acc_norm`）。本题幅度对连续分数的作用随深度、剂量是否饱和及评分口径变化。 [原始及归一化配对 margin](results/A/A2_FACTORIAL.json)

**H3 · 残余的平均作用主要体现在分数，其逐题准确率影响较小。** 与原 Rank‑8 相比，共享投影在 K2、K3、K4 的归一化 margin 差值为 −0.0086 [−0.0139, −0.0037]、−0.0057 [−0.0084, −0.0031]、−0.0046 [−0.0067, −0.0023]。三个深度的 `acc_norm` 纠正／退化为 2／6、3／3、3／5，说明相同答对数仍可掩盖逐题变化。原生残余单独写入时，K2–K4 分别答对 137、151、153 题，接近 Native 的 133、151、153。人为放大残余后，K2 达到 153，仍低于同范数共享轴的 189，K3、K4 的同范数残余为 151、148。原 Rank‑8 分数来自历史批量 16，新干预使用批量 32。对数分数的细微差别还可能受 BF16 批形状影响。 [逐题配对与残余范数](results/A/A2_FACTORIAL.json)

## 学习幅度与计算成本

`smooth_t2` 是实验 B 按 ARC Validation 规则锁定的自适应类代表，带 2,048 项训练系数及 2,048 项冻结方向，共保存 4,096 个标量。按 K1–K4，它的候选 `acc / acc_norm` 为 113／117、159／194、177／211、176／199。相对原 Rank‑8，K2–K4 的 `acc_norm` 纠正／退化分别为 9／8、6／1、4／6。K3 的净增量为 +1.67 pp [0.00, +3.34]，归一化 margin 差为 −0.0109 [−0.0162, −0.0053]。K2、K3、K4 的实际候选写入剂量中位数为 0.281、0.408、0.414。 [B 的选择规则与类代表](EXPERIMENT_B.md) · [学习幅度的完整候选结果](results/A/A2_FACTORIAL_learned_c947bf92db5a.json)

贪心正确率在 K2–K4 合计比 Rank‑8 T1 高 +0.45 pp [−0.33, +1.23]，比 Rank‑8 T2 低 −1.34 pp [−3.34, +0.67]。相比置换幅度，学习幅度的正确率差为 +0.22 pp [−0.67, +1.23]。由于自适应代表在 ARC Validation 选定，这些对照用于析因和标定，独立迁移表现由冻结后的全量基准检验。 [学习幅度的逐题生成汇总](results/A/A2_GENERATION_learned_c947bf92db5a.json) · [按题聚类区间](results/A/A2_GENERATION_AUDIT.json)
