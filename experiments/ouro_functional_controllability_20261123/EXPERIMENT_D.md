# 实验 D · 有符号剂量与干预时域

在 ARC-Challenge Validation 的 299 题上，Ouro 固定运行 K4。沿共享轴写入 +0.45 个受体残差 RMS 时，第 1、2、3 轮末写入分别答对 171、186、201 题（`acc_norm`），原生 K4 答对 153 题。第 3 轮写入时，一阶近似在留出的 +0.45 剂量上预测对 85.28% 的逐题效用变化符号，幅度的相对误差为 53.05%，超过预注册的 20% 阈值。二阶近似将相对误差进一步增至 567.19%。因此，工作剂量的效应以真实冻结后缀运行测得的有限响应为准。 [预注册理论与判据](THEORY_HYPOTHESES.md) · [实验汇总](results/D_FINITE_DOSE/D_SUMMARY.json)

## 协议与计算成本

- 使用冻结 Ouro-1.4B Base（模型修订 `574fa66cb8bf5abdc979642d01cf2b79b16bfab1`），BF16、SDPA、无 KV cache。共享轴取历史 Train 产物 `mean_direction_rank1.pt` 的 `out.weight`，归一到 RMS 为 1，保留原符号。每次在所选轮的输出 RMSNorm 前，对完整候选答案的每个因果预测位置写入 $a\,\mathrm{RMS}(h_{\mathrm{native}})v$。三种写入时点均逐位验证干预前残差与原生运行一致。
- 原生 K4 共用一次。第 3 轮扫描 $a\in\{0,\pm0.025,\pm0.05,\pm0.10,\pm0.25,\pm0.45,\pm0.70\}$。第 1、2 轮各运行 ±0.025 和 +0.45。±0.70 属于超出历史 0.45 上限的诊断剂量。一次完整运行覆盖 299 个唯一问题、1,194 个候选、19 个条件。
- 候选得分为整个答案的 token 对数概率和。归一化得分按答案字符数相除。实际 gold margin 是正确候选得分减去最强干扰项得分，平滑效用把最强干扰项换成全部干扰项分数的 logsumexp。本文用 $U_{\mathrm{norm}}$ 表示基于归一化候选得分的平滑效用。`acc` 和 `acc_norm` 分别按原始和归一化得分取最高候选。区间为 6,000 次按题成对重采样的名义 95% percentile bootstrap 区间。候选和预测位置的状态统计先在题内平均，再对问题等权求均值。
- GPU 账本记录 RTX 4090 D 单卡成功运行 **109 秒**（约 0.0303 GPU 小时）。每条件 38 个批次，每批至多 32 个候选，共 722 次 K4 解码器前向和 2,888 批轮。每条件对 6,770 个预测 token 打分。按补齐后的实际序列宽度，每条件 44,404 个输入位置，19 条件共 843,676 个输入位置，四轮合计 3,374,704 位置轮次。独立 CPU 审计逐项匹配了 38 个批次和汇总逐题文件中的候选分数，并校验了题序与代码哈希。 [运行清单](results/D_FINITE_DOSE/MANIFEST.json) · [逐题结果](results/D_FINITE_DOSE/PREDICTIONS.jsonl) · [GPU 账本](GPU_LEDGER.tsv)

对 $a=0.10, 0.25, 0.45, 0.70$，实测偶对称分量的两倍 $\Delta U_{\mathrm{norm}}(+a)+\Delta U_{\mathrm{norm}}(-a)$ 分别为 +0.00602 [0.00403, 0.00820]、+0.03297 [0.02368, 0.04294]、+0.07064 [0.04959, 0.09231] 和 +0.06161 [0.02595, 0.09732]。原始平滑效用的同一统计在 0.70 为 −1.09693 [−1.87539, −0.31780]，表明超限区间的平均非对称随效用定义改变。±0.45 的末轮 Attention 写入变化 RMS 分别为 0.03378／0.03421，MLP 为 0.06187／0.06326（正／负剂量）。同幅度、反符号所得分支 RMS 接近，任务变化方向相反。这里的分支观测描述扰动响应，路径因果干预由实验 C 提供。

逐题沿正剂量递增，在 +0.025、+0.05、+0.10、+0.25、+0.45 和 +0.70 首次由错转对的 `acc_norm` 题数分别为 2、1、5、25、23、13，首次由对转错为 1、1、1、4、4、8。负剂量沿绝对值递增时，首次退化为 3、2、8、12、18、23，首次纠正为 1、1、1、1、7、3。这里只观察采样网格的首次状态变化，连续阈值位置和翻转单调性未测定。

### 留出剂量检验

主估计从 0 与 ±0.025 的原生 BF16 分数构造中心差分斜率 $\hat g=[U(+\delta)-U(-\delta)]/(2\delta)$ 和曲率 $\hat c=[U(+\delta)+U(-\delta)-2U(0)]/\delta^2$。在留出剂量逐题比较 $a\hat g$ 与 $a\hat g+a^2\hat c/2$，并用 ±0.05 重新校准做敏感性检查。量化实际运行的切线和曲率近似误差时，BF16 舍入和有限步长共同影响估计。对 max 型 margin，最强干扰项切换还可能产生额外的不可微点。

| ---: | ---: | ---: | ---: | ---: | ---: |
| −0.70 | 107.89% | 1,322.88% | 70.90% | 50.84% | 99.41%／352.19% |
| −0.45 | 93.18% | 884.34% | 77.26% | 53.85% | 81.31%／229.85% |
| −0.25 | 63.10% | 467.88% | 86.96% | 55.18% | 50.85%／116.33% |
| −0.10 | 36.73% | 160.06% | 89.30% | 67.22% | 24.51%／36.77% |
| +0.10 | 29.37% | 137.59% | 91.64% | 74.92% | 22.86%／30.37% |
| +0.25 | 40.06% | 311.47% | 86.96% | 63.55% | 36.85%／75.58% |

表中相对误差为 $\sum_i|\widehat{\Delta U_i}-\Delta U_i|/\sum_i|\Delta U_i|$，符号匹配以实际变化非零的题为分母。$U_{\mathrm{norm}}$ 的两种校准斜率 Pearson $r=0.959$，符号一致率 92.64%。曲率的对应数值为 0.678 和 71.91%。±0.025 校准在 +0.45 的一阶／二阶 MAE 为 0.08632／0.92296。两组校准、两种阶数在全部留出剂量上的相对误差均超过 20%。最小一阶相对误差是 ±0.05 校准在 +0.10 的 22.86%。原始效用和两个 gold margin 的预测也全部超过 20%。数据支持小步差分提供有用的符号信息，工作剂量上的逐题效应大小仍需直接测量。二阶结果评估的是这一校准协议的外推表现，解析 Hessian 与 BF16 曲率误差各自的贡献在这里没有独立估计。 [完整误差表与逐题差分](results/D_FINITE_DOSE/D_SUMMARY.json)

在 $[-0.45,0.45]$ 的实测网格中，以 $U_{\mathrm{norm}}$ 逐题选优得到 239 个正剂量、58 个负剂量、2 个零剂量。214 题达到正端点、43 题达到负端点。二次拟合优化得到 236 个正、63 个负、176 个绝对值达到上限的剂量，符号与实测网格最优的一致率为 89.63%。使用金标逐题选剂量的网格最优相对统一 +0.45 增加平滑效用 0.02551 [0.01783, 0.03424]。这个差值量化同一方向下的题间剂量异质性和该网格的金标选优空间。可部署控制器的收益需由独立样本的固定决策规则验证。
