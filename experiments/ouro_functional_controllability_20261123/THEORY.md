# 冻结 Ouro 的功能可控性

共享循环允许同一个权重块在不同位置的状态上反复计算。以冻结 Ouro-1.4B Base 为例，研究对象是一个低维写入怎样改变实际执行的后缀，以及这些变化能否在独立问题上保留整答收益。参考研究给出三条出发事实。末提示位置的 Rank-8 写入高度共线，等范数旋转后收益消失，且同一轴在 K4 最后一圈前较早两圈前更有效。候选排序和真实生成已有分歧，故两类效用必须分别定义。 [固定参考提交](https://github.com/Gifoe/looped-transformer-stage1-reproduction/tree/19889f317cc9ffde5cdc2ecb8f5d81eac15b8cf7/experiments/ouro_minimal_functional_feedback_20261123) [首个 GPU 作业前锁定的预测及验收规则](THEORY_HYPOTHESES.md)

## 状态、控制和观察量

输入前缀为 $x$，完整因果残差状态为 $H_k\in\mathbb R^{T\times d}$。带原生跨圈归一化的所有共享层记为 $F_\theta$，$H_{k+1}=F_\theta(H_k;x)$。在选定实际位置，对一个或多个预测 token 做 $\widetilde H=H+a p_x$，其中 $p_x=\operatorname{RMS}(h_t)P_t v$，$P_t$ 把单位 RMS 的通道轴 $v$ 写到位置 $t$。剂量实验在接收状态固定尺度。记应用实际剩余层和原生读出得到的连续分数为 $G_{x,k,m}(\widetilde H)$。K2–K4 的部署含一个完整原生后缀 Loop。K1 在第 21 物理层后写入，仅余三层，属于不同的后缀。

连续效用取 $U_x(a)=f_x(0)-f_x(a)$，$f_x$ 可用平滑的正确选项负对数概率，原始和归一化候选分数分开。整答 acc、acc_norm 由对应候选分数独立计算。真实生成是逐 token 的闭环运行，离散选出的 token 会改变后续前缀；其正确率、合法率及成本独立测量。损失和答案标签供离线训练和评估使用，部署控制器仅读当前残差。

## A · 单一写入轴与跨上下文响应

固定前缀、写入位置和后缀，若 $G$ 在 $H$ Fréchet 可微，沿 $p_x$ 的实变量展开给出

$$G(H+a p_x)=G(H)+a D G(H)[p_x]+o(|a|).$$

单个位置至多有一个切向量。即使通道轴 $v$ 共享，受体状态不同会改变 $D G(H)$，两个问题的输出切向量可以指向不同的候选。对于不同 token 的 $s$ 个标量，局部响应矩阵有 $s$ 列 $D G(H)[\operatorname{RMS}(h_t)P_t v]$，其秩至多为 $s$，并可大于一。跨样本或跨生成步的输出几何不能给出单个固定上下文的局部维数。

预定将方向共线性拆为末提示、候选后续 token、历史自由生成各步，另用真实有符号投影、同范数旋转及残余检验整答。ARC Validation 上真实投影保留 K2–K4 两个候选指标合计 282/289 个 Rank-8 净增益单位。这个累加量每题每个深度、每个评分规则分别计一次。旋转及后缀钳制显示功能收益依赖轴和当前后缀。候选整答的因果保持和生成阶段几何由分层证据分别判断。 [方向分解](EXPERIMENT_A.md) [路径因果定位](EXPERIMENT_C.md)

## B · 传播范数和任务对齐共同决定时间范围

对原生轨迹的 $m$ 段冻结运算连续应用链式法则，末端切向量和初始效用斜率为

$$p_m=J_{m-1}\cdots J_0 p_x,\qquad U'_x(0)=-\nabla f_x(h_m)^\top p_m.$$

算子范数乘积约束 $\|p_m\|$ 的上界。效用还取决于末端梯度的大小与夹角。额外计算会改变三者，因此扰动可缩小而效用增加，或传播很远而对目标无益。监督中出现的最优注入位置取决于状态、任务和后缀，不能只从深度推出。

固定 K4、同一轴与 +0.45 相对 RMS 剂量，ARC Validation 三个入口得到 171、186、201/299 的 acc_norm，Native 为 153/299。对归一化平滑效用，带符号局部斜率相对仅范数预测，在中、晚入口的误差优势为 0.02865 与 0.04267，两者配对区间下界均大于零。早入口在该终点无有把握的优势，早入口原始正确选项 margin 对照更偏向范数特征。入口同时改变状态和后缀，支持具体轨迹上的时域效应。 [有限剂量和传播](EXPERIMENT_D.md)

## C · 有界剂量的状态依赖

令 $g_x=f'_x(0)$，$c_x=f''_x(0)$。在 $[-\rho,\rho]$ 上最小化 $q_x(a)=f_x(0)+g_x a+c_x a^2/2$。当 $c_x>0$，无约束驻点为 $-g_x/c_x$，严格凸性将约束解化为该点在闭区间上的投影。若 $c_x\le 0$，至少一个端点达到最小值，仿射常数时整个区间同值。局部斜率和曲率可以随受体改变符号或大小。若三阶导数沿轴的绝对值以 $L$ 为上界，则余项以 $L|a|^3/6$ 为界。设一致余项界为 $\epsilon$，$q$ 的最小点 $a_q$ 对真实最小点 $a_*$ 满足 $f_x(a_q)-f_x(a_*)\le2\epsilon$，由对两点夹逼和二次最优性得到。

这个结论给出有符号、受体条件化和有界的控制假设。固定、真幅、跨题置换和光滑标量分别测量题目特异幅度的作用。有限剂量上利用标签枚举的逐题最佳符号只诊断潜在增益。最终控制律从 ARC Train 学得，按独立 Validation 一次锁定。实际主方法是秩一残差映射，共享输出轴与状态系数。 [完整控制律](METHOD.md) [量化确认](EXPERIMENT_B.md)

## D · 有限幅度效用与计算通路

若 $a\mapsto G(H+a p_x)$ 在扫描区间绝对连续且链式导数几乎处处存在，实数参考计算满足

$$G(H+a p_x)-G(H)=\int_0^a D G(H+s p_x)[p_x]\,ds.$$

因此剂量可经过不同的响应区间。实际 BF16 下存在舍入跳跃，候选取最大值和生成解码包含离散决策。运行时用小剂量有限差分估计局部项，用真实有限幅度分数度量大剂量。事前阈值为相对误差 20%。在所留出的非局部剂量，线性和二次预测均超出阈值。晚入口 +0.45 的归一化平滑效用，线性和二次相对误差为 53.05% 和 567.19%。局部斜率对部分入口仍有预测价值，但该二阶估计不能外推到工作剂量。 [有限剂量分析](EXPERIMENT_D.md)

机制上比较学习轴和等范数旋转轴，各自将后续分支保持活动或换回同题原生值。差中差 $[U(L_{live})-U(L_{clamp})]-[U(R_{live})-U(R_{clamp})]$ 测量方向选择性通路贡献。选层只用 ARC Train 的哈希子集。Validation 晚层 Attention 与 MLP 的归一化连续效用差中差分别为 0.07962 与 0.06052；两者校正区间下界均大于零。原生 Q/K 与 V 回复分别支持读址和载荷通路的连续效用贡献。V 的离散整答证据较稳。分支回复在改写后的状态中诊断条件必要性及恢复，不能把同一效应无条件外推到所有上下文。 [通路干预与还原校验](EXPERIMENT_C.md)

## 理论进入方法的限度

匹配语义对照让同一候选集合 $(A,B)$ 在两条事实下分别以 $A$ 和 $B$ 为正确答案。一个只依赖候选词的固定偏置 $b$ 对两个正确项 margin 的改变量是 $b(A)-b(B)$ 和 $b(B)-b(A)$，配对平均严格为零。固定轴相对 Native 的配对 margin 提高，加上方向 × 锁定晚段 Attention 回复的交互，排除了这种纯加性词偏置对连续结果的解释范围。在 512 个 canonical 行上 Native 已正确 510 行，固定轴正确 512 行。相对原生、词偏置和等幅旋转的双向整答改进，其区间下界均为零。此对照无法确定共享轴是否能让模型可靠地完成原本未完成的语义计算，也未排除上下文依赖的决策放大或格式偏置。 [语义反事实](EXPERIMENT_E.md)

低秩轴解释为什么将历史 Rank-8 压缩到 4,096 参数仍能保留完整候选排序。输出通路的条件性预测通过了 ARC 的钳制检验。生成前缀会改变状态和目标，合法格式与内容都要在实际任务上验证。OpenBookQA 贪心主方法相比冻结 Rank-8 T2 正确率下降 6.07 个百分点，超过事前五点界限。候选受益和后缀中介证据无法推出通用生成控制。 [生成与跨任务证据](REPORT_ZH.md)
