# Shared Direction Control

固定 Ouro-1.4B Base。令 $s=\mathrm{RMS}(h)$，$v$ 的 RMS 为 1，写回为 $h + s\,a(h)\,v$。从先前 Rank-8 的 ARC Train 更新投影提取一次共享轴。格式采用 `mean_direction_rank1.pt` 的输出列，重新归一化只改变表示约定。模型选择和端点门槛见预注册。

| 家族 | 相对剂量和写回 | 可训练标量 | 保存标量 |
|---|---|---:|---:|
| M0 | $a$ 固定为 0.25、0.35 或 0.45，读受体的 RMS | 0 | 2,049 |
| M1 hard | $a=\operatorname{clip}(w^\top (h/s)/\sqrt{2048},-0.45,0.45)$ | 2,048 | 4,096 |
| M1 smooth | $a=0.45\tanh(w^\top (h/s)/\sqrt{2048})$ | 2,048 | 4,096 |
| M2 | $\Delta h=u(w^\top h)$，再限幅到 $0.45s$ | 4,096 | 4,096 |
| M3 | 先前 Rank-8 T1/T2 反馈 | 32,768 | 32,768 |

M1 的标量保持符号。硬限幅版本从先前训练集投影的线性系数初始化。光滑版本把该系数除以 0.45，使零点斜率与初始硬限幅形式一致。M2 从同一训练集导出的秩一权重初始化。两条向量在实际标量计算中的数目分开记录。M0 多出的一个保存标量是固定剂量。

K2–K4 在倒数第二圈末端、RMSNorm 之前写入实际残差后执行一个完整原生后缀。K1 在第 21 物理层后写入并执行最后三层，属于层内干预。写入位置限于当前已有前缀里的因果预测位置。控制器的推理路径每个位置增加一次尺度、点积和向量变换，原生 Loop 与 LM Head 调用次数维持固定预算。

可训练方法每个用同一完整 ARC Train 1,119 题、相同种子和 280 次更新。T1 平衡完整候选原始与字符归一化排序。T2 通过真实后缀优化 $0.35 L_{content}+0.65 L_{letter}+0.30 L_{rank}$，字母项使用公开呈现选项的训练提示。推理使用固定评测题面，所有方法只看当前模型状态。

主方法及各类对照代表由 ARC Validation 的两个候选指标、真实贪心正确率和有效率一次确定。训练代码、模型哈希、所有探索权重、两种准确率、生成 token 和实际成本随结果归档。 [事前理论与选择协议](THEORY_HYPOTHESES.md)

锁定主方法为 `rank1_t1`，固定轴和光滑标量的类代表为 `fixed35` 与 `smooth_t2`。主方法推理执行一次 rank-1 内外积，由受体的相对 RMS 上限约束更新。ARC Test 执行 4,687 个候选，293 个 batch，每个预算 293 次冻结模型和 LM Head 调用。K1–K4 的模型占用峰值约为 3.0 GB，K4 的批中位延迟为 76.97 ms。生成运行时间、实际循环调用与 token 账目单列。 [模型和权重](results/FREEZE.json) [运行环境](results/MODEL_CONFIG.json) [候选成本](BENCHMARK_RESULTS/COST.json) [生成成本](GENERATION_RESULTS/COST.json)
