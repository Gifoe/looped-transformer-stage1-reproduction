# 完整 ARC-Challenge 上的 Semantic Amplification

冻结 Ouro-1.4B Base，使用一张 NVIDIA GeForce RTX 4090 D。实际台账累计 13 分 59 秒。官方 Test 全部 1,172 题、4,687 个完整候选，核验 187,480 个新候选分数。
按 Validation 的四预算 `acc_norm` 总正确数，三种方法中选出的整体配置为 **Semantic Completion**。其 Test 四个预算 `acc_norm` 净变化依次为 +3.67 pp, +3.41 pp, +6.66 pp, +7.59 pp。

## 方法与证据来源

借位先前在第 15 层找到了对整答有作用的轮间交互项，且等幅匹配表明幅度可决定写入作用。先前的查表结果显示有效位置可随任务改变。ARC 采用历史原生终态和分支写入接口，在物理第 19–24 层分别汇总 Attention 与 MLP 两支路，两段各三层。当前位置取完整候选每个需预测 token 的前一位置。 [借位与写回](../ouro_causal_semantic_completion_20261122/REPORT_ZH.md) · [原生状态计算](../ouro_native_state_computation_20261121/REPORT_ZH.md)
令末六层实际写入和为 $w_k$，当前归一化前残差为 $h_k$。编码器把当前残差、两段 Attention、两段 MLP 和历史残差差值各投影到 8 维，输入共享门控。深度作为一个数值特征。写入为 $h_k^prime=h_k+d[g_phi(x_k)w_k+u_phi(x_k)]$，$gin[-0.5,0.5]$，$uperp w_k$ 且 $|u|leq0.5|w_k|$。$d$ 是跨预算共享的验证剂量。修改后只用一次原生 RMSNorm 与词表头。
Magnitude-only 约束正交更新为零。Direction + Magnitude 从训练标签的完整候选排序目标学习正交分量。Semantic Completion 在相同架构和参数量上加入下一轮与本轮的分支写入差监督，先投影至当前写入的正交空间，并匹配尺度上限。此监督只用于 Train 的 K1–K3。打乱教师保持轮次和目标范数，在不同题之间置换监督方向。正式推理只运行指定深度，读取当前及已经运行的轮次。
训练把 80% 权重给字符归一化候选交叉熵，20% 给未归一化的候选交叉熵。训练和评分沿用完整词表归一化，再求每个候选的 token 对数概率总和。`acc_norm` 除以原候选字符数。模型参数始终冻结。

## Q1–Q5

**Q1　是否提高四预算准确率？** Validation 锁定的 Semantic Completion 在 `acc_norm` 的净增益为 +3.67 / +3.41 / +6.66 / +7.59 pp，在 `acc` 为 -0.68 / -0.94 / +3.16 / +2.73 pp。

**Q2　幅度还是方向？** 方向学习相对仅幅度变化为 +2.99 / +3.16 / +6.14 / +6.14 pp。相对等几何的旋转方向为 +2.47 / +4.27 / +7.51 / +6.83 pp。

**Q3　同一个方法能否跨深度？** 四个深度使用同一参数和剂量。`acc_norm` 正增益覆盖 4/4 个深度，`acc` 覆盖 2/4 个。

**Q4　是否超过 LoopCD？** 与历史同深度最强 LoopCD 配对时，`acc_norm` 正增益覆盖 3/3，`acc` 覆盖 2/3。K1 比较历史原生。前沿和同卡限制见上表。

**Q5　下一轮监督是否识别了可迁移计算？** 真实下一轮监督相对打乱教师的 `acc_norm` 净变化是 -0.26 / -1.62 / -0.77 / -0.26 pp。只有在这一控制下仍有准确率增益时，才可把结果归因于同题跨轮目标。

逐题分数在 `TEST_PREDICTIONS.jsonl` 与 `GEOMETRY_PREDICTIONS.jsonl`，逐题配对选择在 `TEST_PAIRED.jsonl`。验证迭代轨迹与冻结签名同时发布。

## Astra 独立复核

Validation 锁定的 Semantic Completion 在官方 Test 的字符归一化指标上四档均超过 Native，四深度 Holm 校正后均达到 0.02。同时，K2–K4 的配对区间支持超过历史同预算最强 LoopCD。K3 超过历史 K4 最佳分数 56 题。未归一化 `acc` 在 K1、K2 分别少 8、11 道，测得的四档收益依赖候选评分口径。

学习的方向在相同原生幅度、更新范数和残差范数约束下保留收益。去掉幅度分支的四档区间均包含零。真实教师在四档逐题正确数低于等范数打乱教师，K2 的负差区间排除零。现有实证支持可改进解码的低秩方向，尚无法归因于同一道题的下一轮计算。改进和退化组的正交更新中位数相近，较大更新本身不能识别哪些题会获益。

下一轮优先在新留出集上保持方向读出器和推理成本固定，把未归一化与字符归一化的候选损失改为等权。预先要求 K1、K2 的 `acc` 同时提升，并给四档 `acc_norm` 设定非劣界。本次官方 Test 已完成确认，后续配置从新的开发样本选择。
