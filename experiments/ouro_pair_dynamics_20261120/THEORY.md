# 原生 pair 的连续有效场

用 \(a(x)\) 和 \(m(x)\) 表示第 \(l\) 层 Attention、MLP 的真实残差输出，包含写入前的分支归一化。完整带因果位置的有效序列是状态。原生单层族为 \(T^\alpha=(I+\alpha m)\circ(I+\alpha a)\)，\(\alpha=1\) 是实际运行。求解步数独立记为 \(m_{\rm grid}\)。

\[
T^\alpha(x)=x+\alpha(a+m)(x)+\alpha^2 J_m(x)a(x)+O(\alpha^3).
\]

令 \(C=J_m a-J_a m\)、\(D=J_a a+J_m m\)。积分时长 \(\alpha\)，用
\[
v_\alpha(x)=a(x)+m(x)+\tfrac{\alpha}{2}(C(x)-D(x)).
\]
流的二阶项是 \(\frac{\alpha^2}{2}[(C-D)+(J_a+J_m)(a+m)]\)，合并得到 \(\alpha^2 J_m a\)。交换原生顺序后该项变为 \(J_a m\)，可通过翻转 \(C\) 得到。实现将四个 Jacobian 方向项合并为两个 JVP，即 \(J_m(a-m)-J_a(a+m)\)。同一输入上的离散二阶 Taylor 直接计算 \(\alpha^2J_m a\)。阻尼系数小于 1 时，误差中重新出现二阶项。\(\alpha=1\) 的证据需要直接测量，截断展开不提供跨输入统一的单位步误差界。

## 前缀因果性

固定掩码、位置和等长布局下，\(a,m\) 对 token 是下三角映射。若方向 \(u\) 对前缀因果，则 \(J_a(x)u(x)\) 和 \(J_m(x)u(x)\) 也是。固定网格显式积分由这种映射的有限组合构成。全序列 Anderson 的最小残差权重让后缀参与混合，可能让预测前缀变化。为每个 token 单独对其前缀的残差 Gram 矩阵求系数，能移除这一条依赖。共享误差门控也需独立审计。

## 末端 RMSNorm 的两阶段构造

令 \(q=\operatorname{mean}(x^2)\)，\(\lambda=-\log\epsilon\)，\(c=\lambda/(1-\epsilon)\)。径向场 \(x'=\tfrac12(\lambda-cq)x\) 给出 logistic 方程 \(q'=\lambda q-cq^2\)。解的缩放因子为
\[
S_t(x)=x[\epsilon^t+q_0(1-\epsilon^t)/(1-\epsilon)]^{-1/2}.
\]
当 \(\epsilon\to1\)，第二项的系数趋于 \(t\)。代码使用 \(\mathrm{expm1}(t\log\epsilon)/\mathrm{expm1}(\log\epsilon)\)。在 \(t=1\) 后，以第二单位时段积分坐标场 \(x'_j=\log(\gamma_j)x_j\)。当 \(\gamma_j>0\)，端点等于实数 RMSNorm。这个定义固定了先径向、后对角增益的参考时钟。BF16 和 FP32 各用固定 math SDPA，分别报告原生尾部的舍入差。

## 四世界与时间尺度

四世界初态由同一接收状态的两个互不重叠编辑相加，\(I_H(0)=0\)。沿同一场分别推进，混合状态差 \(I_H=(H_{11}-H_{10})-(H_{01}-H_{00})\) 的导数等于四个场值的混合差。若 \(q\) 是相同尺度的固定候选 logit 对比，且读出仅为线性 lm head，后归一化边界有 \(I_q=c^\top I_{H,\mathrm{answer}}\)。动态最大对手会产生额外非线性，未作为主要分数。测量读出不写回轨迹。

残差幅度 \(\alpha\) 改变原生离散靶标。积分网格改变数值近似。移植幅度 \(\beta_S,\beta_R\) 改变初始条件。两个时钟 \(\phi(s)=s/2+s^2/2\) 和 \(3s/2-s^2/2\) 都从 0 单调映到 1。变换为 \(dh/ds=\alpha\phi'(s)v_\alpha(h)\)。精确端点相同，中途记录要在相同 \(\phi(s)\) 比较。沿四条有限轨迹的 \(I_H\) 和微分混合项 \(D^2v[u_S,u_R]\) 在有限幅度通常不同。交换子描述 A/M 向量场的顺序差，四世界响应描述对两个输入干预的混合差。

## 访问权限

局部验证从真实 pair 输入出发。短段实验和干预以真实前缀与共享原生后缀为条件。独立预测的 PairOps 只运行一次自然 K1 以捕获位置和 no-cache 掩码，接口不持有未来边界。后续三轮均用自己的输出推进。真实施加干预前，写出预测与 SHA-256。
