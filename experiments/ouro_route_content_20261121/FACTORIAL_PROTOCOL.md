# 自然反事实的联合分量复核

在读取联合分量结果之前固定以下比较。上一轮研究与本轮单独路由检验保留自己的主判据。本复核直接检验早期 A 与早期 V 进入真实 K2 前缀时的联合效应，以及真实 K1 写入去除后的清洁 A、V 恢复作用。两者来自实际运行，所有修改限提示 token 并使用完全相同的接收方原生后缀。另在开发前已经确定的 L1 MLP 比较真实早期 Gate 与 Up，均为整层操作。

每种分解由原接收方的两个因子、只换第一因子、只换第二因子、同时换两因子构成。交互是两次单独交换与共同交换的有限差。分别以冻结的原生 K2 最强错误候选为对手计算正确答案 margin。基线和各处理均保留完整候选逐 token 分数。额外比较 L6 四头与 L6 全 16 头，不选择表现最好的头组。OpenBookQA 和 ARC 全体与四种行为状态均进入主展示。结构化检验的确认分母和门槛不使用这组结果。
