# 固定路由与受体内容交叉实验

上一轮候选固定为物理 L6、从零计数的头 1、7、11、14。配对控制头为 0、2、3、4。模型始终冻结，执行原生 full-context eager FP32，不训练或者校准权重。第一主线检验固定 A 是否在两种实际受体内容上挑出不同的规则答案。第二主线直接在第一次真实答对的 K2 回拨同题的 K1 路由，独立拆分位置 0 与其余键，并同时检验第一层 Attention 写入去除后的路由复位。

结构实验预先生成四个彼此不同的受体答案和两个与受体答案不相同的供体答案。供体两条原生注意力图由一个查询键的变化产生。两种受体共享第一次映射，第二次映射不同。六个答案以完整候选 token 平均 log likelihood 评估，全部原始 token log likelihood 保留。第一版跨完整受体上下文。第二版仅交叉 L6 所选四头的 A 与 V，保留同一个前缀和余下算子。互换仅在提示 token 生效。所有 donor/receiver 的提示 token 数必须相同，供体及两个受体里改变查询键的 token 位置必须一致。对照是按行随机交换同一对原生 A 的行，保持完全相同的两图距离和有效支撑。其他头按距离匹配，无法放大时记录未配平。两种模板各 12 个先导、64 个确认。先导不选择方向或改确认集。

令 ΔA d[r,c] 表示 A1 对 A0 改善受体 c 中第 r 套答案对比 y1r−y0r 的效果。匹配特异性 I=0.5*(ΔA d[0,0]+ΔA d[1,1]−ΔA d[0,1]−ΔA d[1,0])。固定前缀 V 因析的分布、两个正确匹配对比、跨头对照及 I 相对等剂量对照全部以组配对报告。支持通用语义路由需要两个正确匹配对比和 I 的配对 95% 下界均为正，且 I 对随机增加至少 0.02 nats/token。完整受体估计须同向，供体答案命中同时报告。所有预设组留在分母。题型结果分别报告。

自然队列为 320 OpenBookQA 和 192 ARC 题，按题干、ID 与既有暴露记录剔除并在接触行为前固定。ARC 历史整划分曾被评分。主协议沿用上一轮完整候选平均 LL。K2 回拨同题早期 A，等物理深度自然后缀，和 K1 写入删减、等范数坐标移位扰动、恢复实际 K2 路由的 2×2 背景组合按题评分。位置 0 条件保持其余键的相对注意力分布，非位置 0 条件保持位置 0 的注意力质量。报告完整所有四个行为转换及相对基线 margin。未发现稳定自然纠正或无先验目标的相容效应时，不能用小子集或对齐量宣布答对机制。置信区间按世界组或题目自举，不能用于声称单条路线或读出是唯一依赖。
