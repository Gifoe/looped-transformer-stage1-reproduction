# 第一层生产写入的 token 支持

在首遍结果发现 L6 多数注意力转向位置 0 后，固定一个新的判别实验。只删除 K1 第 1 层 Attention 实际写入中位于位置 0 的分量、其余提示位置的分量或两者。原生输出、处理后 K2 L6 位置 0 注意力质量与全答案评分均保留。两个支持各自增加完全同范数的坐标置换干预。分析目标是区分形成下一轮锚点注意力的写入支持与影响候选答案的支持。处理在提示位置生效，K2 尾部保持原样。

样本使用更正后各自然队列前 128 道，全部保留。二者也参与路由比较，所以这是同队列的机制判别。另在前 48 道将提示首部的 “Question” 换为同长度单 token 的 “Problem”。保持语义任务和对齐 token 数，各提示独立运行，使结果能区分位置和单一文本身份。四个主要消融组均先冻结，且任何符号、剂量或样本未见本实验结果后选择。
