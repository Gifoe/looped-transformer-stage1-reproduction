# 原生分量协同的乘积项与后续非线性

自然 K2 受体固定，取真实 K1 和 K2 分量。对 L6 冻结四头，记 q 为从实际输出投影输入出发复跑到末端得到的完整答案对比。四角输出 Z_LL、Z_EL、Z_LE、Z_EE 分别对应清洁、早路由、早 Value、共同介入。直接定义线性加和对照 Z_add=Z_EL+Z_LE−Z_LL。真实 Z_EE 与 Z_add 的差正好等于 (A_E−A_L)(V_E−V_L)。另测 Z_add 加上等范数坐标置换的交互项，保留真正的输出投影、norm 和剩余网络。

任务边际的四角交互可用下式精确拆开：

I = [q(Z_EE)−q(Z_add)] + [q(Z_add)−q(Z_EL)−q(Z_LE)+q(Z_LL)]。

第一括号隔离原生乘积项，第二括号反映后续网络和评分的非线性。L1 的 Gate/Up 在真实 down 输入处使用同一拆分，其中交互为 (G_E−G_L)⊙(U_E−U_L)。非加性强并不自动表示自然高轮状态答对的机制，实际正确率、退步/救回和贡献大小分别报告。

这是见到前一轮析因效应后制定的机制定位。每个已纠正自然队列前 128 道，组内配对并保留所有接收方情况。在运行本实验前冻结代码、输入、权重和对照。已见队列用于定位，后续任务层机制需要新的独立确认。
