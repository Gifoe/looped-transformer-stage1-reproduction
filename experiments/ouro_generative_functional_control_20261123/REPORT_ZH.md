# Ouro-1.4B 生成控制重训

这是在 2026-11-24T00:22:43+08:00 归档的快照，含 432/576 个确认单元。其余确认评测已由用户暂停。 [快照范围](SNAPSHOT.md)

冻结 Ouro-1.4B Base 后，只训练 4,096 个参数，可以让固定的 Rank-1 在完整选择题上更可靠地生成答案。锁定权重同时保留了部分候选评分收益，但四套选择题上的 `acc_norm` 均低于历史排序组。GSM8K 过程生成也明显退化。这两项结果限制了该权重作为通用控制器的适用范围。

在完整 ARC-Challenge K4 的 1,172 道题上，锁定权重的完整答案生成正确率为 78.07%，Native 为 74.32%，匹配的历史排序权重为 42.24%。对 Native 改对 124 题、改错 80 题，净增 44 题，95% 配对差区间为 +1.37 至 +6.14 个百分点。候选 `acc_norm` 为 55.97%，Native 为 52.82%，历史排序为 59.90%。与历史排序相比，四套选择题的完整内容正确率提高 27.44 至 43.89 个百分点，候选 `acc_norm` 下降 3.03 至 5.90 个百分点。四套题的宽松字母差值区间均包含零。严格格式的改进远大于宽松字母正确率变化。

在 360 道 SQuAD 保留题上，锁定权重的生成 EM 为 72.22%，Native 为 45.56%，历史排序为 63.06%。锁定权重的两段训练只使用选择题，因此这组抽取短答案数据没有参与该权重训练。GSM8K 过程题的宽松数字正确率从 Native 的 36.46% 降到 17.71%，配对差区间为 −30.21 至 −8.33 个百分点。严格数字正确率从 22.92% 降到 0%，有 22 条退化。输出长度中位数由 192 个 token 降到 5 个 token，重训组全部在长度上限之前生成 EOS。Native 有 80 条达到上限，实际观察到的长度差为下界。更早终止与过程答案退化同时出现，按停止原因计算的结束率无法代表推理完成。

与历史排序严格匹配训练题和更新顺序后，生成监督改善了短答案内容和格式。加入原候选辅助项恢复了部分排序增益。等计算量条件下，混合数据可改善抽取式问答，但通用指令数据进入同一训练预算后减少了短答案的练习。完整池提高了小池的语义正确率，仍未在开发集超过仅生成训练。实验只识别这些数据配比和监督的效应。控制器大小、注入位置和限幅在各组相同，容量和注入位置是否构成瓶颈仍无法从这一轮判定。

所有方法在同条件使用完整词表、冻结提示和解码。控制器在最后一圈之前写入，不添加循环。ARC-Challenge 的 K4 内容生成总耗时为 82.61 秒，Native 为 143.95 秒，候选评分约为 19 秒。序列变短可降低实际延迟，GSM8K 过程题也表明序列变短可能损失任务能力。

本轮确认属于重训实验，主要对照是本轮同题复测的 Native 与历史排序 Rank-1。LoopCD 与七项外部 Benchmark 的统一协议比较属于后续评测。数据去重、训练以及消融细节分别见 `DATASET.md`、`TRAINING.md` 和 `ABLATIONS.md`。

上一版部署的 T1 和 T2 也已在原始回执上完成逐题核对。旧 T1 在 ARC-Challenge 的候选准确率优势大于匹配训练消融里的排序组。旧 T2 与新权重的 OpenBookQA 宽松正确率接近，新权重显著改善严格格式。 [部署对照](LEGACY_DEPLOYMENT.md)
