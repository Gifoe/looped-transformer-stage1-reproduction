# 生成 Rank-1

控制器由两个长度 2,048 的 FP32 向量组成。Ouro-1.4B Base 的主干为 BF16，全部冻结。训练只更新 4,096 个控制参数。使用原来的相对 RMS 0.45 限幅。在 K2–K6 将更新写在最后一圈之前。训练轮换 K2、K3、K4，所有任务及测试深度以同一个权重前向。

设 $r(h)$ 表示带数值下界的 RMS。预测位置 $i$ 的控制先用 FP32 计算，再转回原生 dtype 写入循环边界。

$$
d_i=u(w^\top h_i),\qquad
h_i'=h_i+d_i\min\left(1,\frac{0.45\,r(h_i)}{r(d_i)}\right).
$$

对回答前缀的每个因果预测位置写回控制。已有答案前缀的 logits 由与 teacher forcing 相同的位置掩码计算，并用真实解码的打包代码逐位置校验。训练损失在单条回答的所有目标 token 上平均，再对问题平均。EOS 属于目标序列。候选辅助损失使用原仓库的完整候选原文 likelihood、原始分数值与长度归一分数值的训练权重。

令 $s_j$ 为候选 $j$ 的整段 token log likelihood，$c_j$ 为其字符数，$a$ 为正确索引。辅助项仅用于带官方候选的例子。

$$
\mathcal{L}_{\mathrm{gen}}=-\frac{1}{|y|}\sum_t\log p_\phi(y_t\mid x,y_{<t}),\qquad
\mathcal{L}_{\mathrm{rank}}=\tfrac12\operatorname{CE}(s/3,a)+\tfrac12\operatorname{CE}(16s/c,a).
$$

优化器用 AdamW、学习率 0.001、weight decay 0.03、梯度范数裁剪 1，初始化与历史排名基线相同。仅生成不包含 ranking loss。复合训练权重为生成 1、原候选排序 0.25。中间训练失败和硬超时保留每百步断点，原生主干权重与部署模型保持一致。

确认时按完全相同的提示、完整词表贪心、循环预算和停止规则比较模型。选项文本判分接受能明确解析出的完整文字，同时保留原文本严格端点。自由字母生成分别报告历史解析、大写严格格式和仅大小写放宽。候选准确率单独保存。一般指令输出使用描述性参考重叠与明确可自动检查的规则。
