# 生成 Rank-1

冻结 Ouro-1.4B Base，Rank-1 仅 4,096 个 FP32 参数，主模型 BF16、无 KV 缓存。原生前向的预测位置和 RMS 0.45 限幅保持一致。训练和自由解码均写完整已出现回答的因果预测位置。先做断点式 teacher forcing 与真实逐前缀 scorer 一致性核验。训练只用答案 token 和 EOS，按答案平均。

CSQA 对照使用前轮对应固定从零排序模型的同 1119 道训练题、同种子、同主要循环深度、匹配 282 次更新。比较仅生成及生成加排序。历史和 native 按同一生成评分程序做配对。数据来源实验先使用等实际骨干 padded token-loop 预算及同一辅助损失，在开发生成后再决定完整训练池训练。所有开发权重、日志和已出现的失败保留。

最多单卡 18,000 秒。开发和确认数据分开，候选指标仅作独立保留门槛。先看真实生成语义和完整性，再看有效率和严格格式。MC 内容、历史大写字母与大小写宽松结果单列。评测深度 K2–K6，K5/K6 未训练。任何缩减评测只能在确认结果之前依据生成成本冻结并报告。无需以同一确认输出反复调参。
