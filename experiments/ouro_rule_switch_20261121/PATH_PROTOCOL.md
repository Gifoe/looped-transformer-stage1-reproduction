# Find a common K2 V path for the two arithmetic rules

Run only if the locked primary rule-switch gate passes. In discovery, retain the first qualifying orientation per stem where the fixed natural graft made both rules produce the exact counterfactual and both native K2 recipient outputs were correct. This selection is deterministic. In confirmation use the same rule, then take a fixed-seed sample without replacement of at most 64 stems. The results apply to this conditional population and do not estimate natural K1→K2 mediation.

For both rules enumerate the actual vocabulary token continuations for the recipient integer and the counterfactual integer. For the discovery screen only, replay their shared token prefix and measure the recipient-minus-counterfactual logit margin at the first difference. Record natural and grafted K2 key and value vectors at the early operand positions and verify invariance across rules. After that, restore the natural recipient V at only these positions in a single four-layer window of K2. Screen the six nonoverlapping windows. Pick the window with largest minimum of the two mean margin gains, using earliest index on ties and requiring the minimum to be positive. Within the selected window separately screen its four single layers by the same criterion. Freeze at most one window and one physical layer before examining confirmation intervention outcomes.

In confirmation compare native re-decode, original graft, all-layer K reset, all-layer V reset, and all-layer norm-/angle-matched V placebo. If selected, also compare the local V window/single layer against its own same-support geometric placebo. All runs produce full-vocabulary exact integer outputs. No candidate prefix in confirmation. Record both rules' original/counterfactual/donor/other outputs, dose controls, paired recall and corresponding intervals. Replay exact native and graft sequences. Prespecified primary path endpoint is exact restoration of both original correct integers under all V versus placebo, with an ordinary 95% paired interval. For localization use 97.5% paired intervals for the candidate window and layer. This experiment isolates a value-mediated path under intervention. The recipient rule can act through downstream attention queries, other context positions, MLPs, or later readout.
