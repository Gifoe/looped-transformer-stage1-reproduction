# Same-prompt test of native K1 to K2 repair

This prospective assay asks whether the prior operand-value pathway is implicated in actual native corrections. It uses all confirmation rows with a parsed wrong K1 integer and an exact K2 integer, with a cap of 72 oriented prompts selected using a fixed seed before any intervention. For each corrected prompt choose one disjoint all-correct prompt with the same rule and magnitude band, excluding all selected repaired stems where possible. Score raw complete sequences. No test label is used to alter a mode's model inputs. Native repair incidence and selection flow are reported.

At the same prospectively defined early operand positions as the cross-rule graft, restore the value projections actually computed in the first pass of that same prompt, in place of their second-pass projections, at every layer. H1 is the native recipient's. Carry both the native trace and intervention through each greedy token generation step; value rollback is adaptive only to the actual generated prefix. Compare against same-position random vectors matching the replacement vector's norm and angle relative to the affected K2 vector at each layer. A native replay must reproduce exact K2 tokens. No intervention is carried out at an answer position. If a discovery-only V window has been selected, compare it with its own identical-support matched control as a secondary endpoint.

The primary estimand is matched excess reproduction of the exact native wrong K1 integer under all-layer V rollback on naturally repaired problems, using a two-sided paired 95% cluster interval by original stem. Prespecified support requires at least 12 originally repaired independent stems, at least five exact reproductions above control, a positive lower interval bound, and a higher raw excess of newly wrong outcomes among repaired recipients than among K1/K2-correct controls. Report exact K1 integer, original correct integer, other values and unparsed outcomes separately. Generic accuracy damage does not establish a causal path for the natural repair. Cross-loop compatibility or absence of exact reversal limits interpretation even when the graft effect is strong.
