# Prospective same-answer carry and borrow confirmation

This separate behavioral holdout was specified after descriptive tests of the earlier rule deck. It tests whether the native error is associated with a needed transfer into the hundreds under a fixed correct integer. Use the unchanged rule prompts and exact complete-integer scoring. Sample 128 distinct target integers per rule. For each target select one fresh operand pair needing the transfer and one fresh pair needing none. Use the same true numeric answer and same signed omission foil in each matched pair. All unordered input pairs are excluded from the previously scored decks and from the demonstrations. Selection uses arithmetic and randomness only. The addition foil is the true total minus 100, and the reverse subtraction foil is the true difference plus 100. A visible carry uses (A mod 100)+(B mod 100)>=100. A visible borrow uses (B mod 100)<(A mod 100). All variants are in the three-digit regime.

Primary endpoint is the same-pair excess of exact K1 foil followed by exact K2 target in needed versus no-transfer conditions. Evaluate both rules with 97.5% paired bootstrap intervals to account for two comparisons. Require at least 12 cases in the needed condition and a positive lower interval for each rule to claim a cross-rule association. Report exact K1/K2 counts, both correct/incorrect transitions and parse outcomes. Correct-output matching controls the numeric output and its tokenization. Operands still differ, so the assay supports an arithmetic error pattern rather than proof of an internal transfer operation.
