# Reproduce bypass replacement and downstream write replay

Use the same public experiment dependencies as env.sh and the exact checkpoint and runtime from results/VERIFICATION.json. Copy DECK.json into a fresh results directory, or regenerate it against the archived parent manifest. Run residual_deck.py followed by residual_test.py with model and results paths. The first script saves the original native measurements before forming any conditional swaps, then scores all swapped and unrelated tables. Use report.py to recompute the tables and execute archive consistency checks.

For final-position raw layer-20 input \(x\) and true receiving writes \(a\) and \(m\) under the rolled-back Q, its output is \(x+a+m\). Adding \(x_\text{donor}-x_\text{receiver}\) after the block replaces the identity contribution while preserving both computed writes. For a fixed bank \(W=\{a_\ell,m_\ell\}_{21\le\ell\le24}\), the last pre-normalization state is \(x_\text{donor}+a+m+\sum_\ell(a_\ell+m_\ell)\). The code tests the resulting difference on both table directions. Replay is performed only at the final position, because preceding positions cannot attend to that later token in the same masked forward.

Each native table supplies its own normal K2 writes at the same emitted prefix. The paired residual control uses swaps of the two unrelated values with identical presented key, row order and low-level integer vocabulary. It is matched to the true bypass displacement in norm. The geometry control additionally preserves the radial projection relative to the receiving bypass. The extra write-reference conditions expose when fixed writes themselves carry enough content to redirect the complete answer.
