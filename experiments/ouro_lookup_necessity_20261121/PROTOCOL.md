# Does untransplanted K2 depend on the native route–content interaction?

Use the frozen Ouro-1.4B Base checkpoint, FP32 eager, no cache. Lock 512 new questions per layout, distinct from all earlier lookup studies; targets are unique within each layout. Collect K1 and K2 under native greedy generation. Study all questions where K1 emits a wrong value from the same table and native K2 corrects it. Also study all native K1/K2-correct questions to test specificity and collateral errors. Require at least 48 qualifying repairs per layout to launch the causal stage.

At each generated prefix capture clean native K1 and K2 A/V operands in physical layers 12–17. Calculate D = P_linear[(A2−A1)(V2−V1)] with the actual grouped-query expansion and output projection. The edited pass starts from native K1's complete normalized output. Run K2 dynamically on its actual prefix. At each target layer in this edited pass subtract D from the **current** projected attention output at all valid positions, before the native post-projection normalization. The reference operands define the deletion. They do not replace the edited pass's current attention, value vectors, residuals or any other writes. Layers 1–11, all MLPs and the final seven layers use their normal computations. The two companions subtract either a geometry vector with the same norm and radial component relative to the clean K2 projected vector, or zero. Score full unrestrained generated integers. Audit the applied subtraction against the live output, clean factorization against the native four-corner identity, uninterrupted layer-12 entry, and independent suffix recomputation. All zero-deletion runs must recover the native full output.

For repair cases, the foil is the observed K1 table error. For stable cases, choose the non-target table value with the smallest clean K2 target-minus-foil logit gap at the first token divergence from the factual native answer; ties use the smaller integer. Tokenize a structural continuation that substitutes only the first numeric answer, with its native spacing. Reject a comparison when the factual generation and tokenization do not align through that token, without excluding it from repair or stable any-error scores. Match repair to stable within layout, without replacement, by maximum number of pairs with a logit gap difference no greater than 2.0, then smallest summed absolute gap. Freeze all cases and matches before any deletion. Report selection and balance. Stable exact-foil and any-error effects are reported separately. A matched set of at least 48 pairs per layout is required to claim specificity.

Primary directed effect is the paired difference in exact foil generation under true versus matched geometric deletion. Specificity compares those within-question differences between matched correction and stable questions. Use 40,000 problem- or pair-level paired bootstrap draws and 95% simultaneous Bonferroni intervals over two effects across two formats. Support native reliance only when all four corrected lower bounds exceed zero, each layout has at least eight true exact reversions, and the match gates pass. Separately bound the probability of any extra exact foil success among repairs using one-sided exact 97.5% upper bounds simultaneously across layouts, conservatively ignoring losses. If both bounds are below 10 points, exclude that scale of effect for this deletion. Otherwise a nonpassing result remains unresolved after this fixed sample. Report all deletion arms and failure modes. Even a positive result identifies a controlled path in these lookup formats rather than a universal mechanism.
