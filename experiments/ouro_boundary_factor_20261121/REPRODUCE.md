# Reproduce K1 boundary context and K2 operand reads

Use the frozen checkpoint and software in results/VERIFICATION.json, and the public experiment modules enumerated in env.sh. Copy the archived DECK.json into the new results directory. Run boundary_deck.py and then boundary_test.py with the local model and new results paths as positional arguments. The shell entrypoints lock the experimental source and start native inference before the interventions. report.py verifies arithmetic, every receiver and donor, historical overlap, aggregate outcomes and archive hashes.

For each generated prefix \(p\), the intact start of K2 is the native receiver state \(H_1(r,p)\). The swapped state is \(H_1(r,p)\) on the six operand positions and the common pre-operand prompt, and \(H_1(d,p)\) elsewhere. Only common continuation tokens are supplied to the two K1 passes. Copying back the common pre-operand positions preserves exact receiver activations under harmless cross-batch floating-point differences.

In each edited K2 attention row, set weights at causally accessible operand positions to zero and renormalize the row. The unrelated stream uses previous template positions. Its paired experimental stream suppresses the smaller common available mass at the same head, layer and query. Grouping identical prefixes is a batching optimization; quotes, punctuation, digits and termination are generated under the selected arm. Decode explicitly continues after the first differing digit, because the original foil and the opposing donor share a leading digit.

The joint intervention tests the selected direct operand-read edges and the particular mixed boundary state. Alternative contextual keys, same-position residuals and other routes remain present. A whole-donor replay verifies the decoding path and is reported separately. Same-borrow donors match low-digit edit magnitude but not the edit direction. The native diagnostic subset at physical layer 15 uses a fixed whitespace prefix and is never used to classify complete integer outputs.
