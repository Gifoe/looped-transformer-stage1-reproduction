# 恢复 Ouro-1.4B 原生计算的连续描述

**存在可验证的局部构造与可复验的算子关系。现有证据无法识别原生 Ouro 的唯一连续计算规律。**

冻结检查点 574fa66，单卡 RTX 4090。FP32 前向关闭 TF32 和 autocast，权重由同一 BF16 权重数值精确提升，参数哈希核验一致。正式先导通过 3 个 BF16 batch 的 48 边界及完整词表逐位对齐。新状态比较在 24 道独立留出上运行两个原生轮界。权重无训练，普通 ridge 只作端点对照。

## 1. 原生映射能否连续嵌入？

对局部可逆的残差图，时间依赖场可以精确恢复该图。实验由真残差函数、固定时间与当前状态近似求逆，并在新提示和编辑起点上测试。全轮同维自治光滑嵌入仍未建立。形式上的混合模型可沿分段局部流，保留必要的原生离散步及末端 Norm。 [数学可行性](MATHEMATICAL_FEASIBILITY.md)

## 2. 阻碍来自哪里？

分支从小幅扰动到单位步出现高阶项和局部反演误差。终末 RMSNorm 在实数像内可逆，但径向几乎被压缩，有限精度使部分输出的反解判别式失效。限制维数的谱估计无法认证整个 F 的最小奇异值。

## 3. 哪些修正有效？

α=.125 时，一阶、BEA2、BEA3 的单分支中位相对误差依次为 0.00072487、4.3053e-05、3.3935e-06。单位步 BEA3 的最坏误差仍为 0.15981。开发 hybrid 的平均末态误差为 8.2536e-05，但原生回退达 85.9%。BF16 留出的 K1→K2 回退比例为 100.0%。端点很准的混合构造依赖大量原生步骤。 [修正方程](MODIFIED_EQUATION.md) · [重建](CONTINUOUS_RECONSTRUCTION.md)

## 4. 顺序与非交换性扮演什么角色？

两个轮界上经真实后缀传输的 bracket 方向余弦中位数为 0.87833 和 0.90954，明显高于剂量匹配控制。实际改选率与等剂量替代层接近。数据支持本层交换对应的因果状态方向。 [算子实验](OPERATOR_INTERACTIONS.md)

## 6. 因果预测能否超过旧连续化和端点拟合器？

在 K1→K2 的真 FP32 新状态上，纯 Anderson 的平均 L2 为 0.13002，ridge 为 0.53612。同一轮界，纯 Anderson 与 branch flow、ridge 的语义干预 logit 响应 RMSE 中位数分别为 0.056885、0.27101、0.2665。补充的跨 token 前缀 ridge 在相同轮界为 0.29268。完整报告含跨轮、真实 ARC、聚类配对和未发生答案变化的样本。 [因果验证](CAUSAL_VALIDATION.md)

纯 Anderson 对严格可判的原生改选分别复现 10/12 和 13/13。这里匹配原生的干预响应，语义供体的正确答案仅用于评分。

K1→K2 的 ARC 选项重排命中 10/10，两个受控结构族合计命中 0/2。早轮合并结果由 ARC 主导。

## 7. 哪些现象具有机制价值？

小幅交换的符号和后缀传播方向能被同一组真实导数预测。这提供了比曲线平滑性更具体的原生机制证据。局部修正无法自动解决 48 个单位分支的误差传播，而高回退混合只能展示何处要保留原生离散更新。端点和编辑预测不能鉴别真实中间时间的轨道。

四轮依次审查局部 BEA/可逆性、全层交换、开发求逆对照、独立及反事实验证。每轮由 Astra 复核已完成的实测后决定继续或限定主张。GPU 时间、显存、调用数和失败先导日志均随结果保留。
