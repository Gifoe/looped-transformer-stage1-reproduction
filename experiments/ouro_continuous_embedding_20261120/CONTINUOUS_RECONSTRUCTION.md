# 连续重建与自然留出

原生 F、整轮场 F−x、逐分支无修正场、BEA2，以及普通 token 共享 ridge 都纳入对照。主近似是时间依赖分支场 v(z,t)=rᵢ(x)，其中 x 解 x+t rᵢ(x)=z。从分支起点做显式中点积分，在 t=.5 以当前中点状态为输入，用 6 次 Picard 或 Anderson 迭代求近似逆。Anderson 用有效 token 上的残差 Gram 矩阵求权重，系数和为 1。两者各有 8 次真实分支函数调用，包括初始斜率和最终残差。Anderson 另有矩阵求解开销。

Hybrid 的逆残差相对 L2 门槛预先固定为 2×10⁻⁵。失败处保留原生离散步，打乱控制在每个样本保持相同离散步数并置换其物理位置。回退执行原生残差加法公式，Attention 复用候选求解器的 math SDPA，与原生默认后端可能存在数值差。

纯近似路径全程无原生回退。图的分支曲线直接用候选自己的状态推进至下一分支，原生分支边界只用于评分。终端 RMSNorm 对所有分支构造单独应用。

Ridge 以 12 个开发提示的 K1 token 拟合原生一轮状态增量。权重共享，固定后用于两个轮界。它在开发集的结果是训练重代入。原生线性插值依赖真实 K2，作为可视化的 oracle 中点对照；其已知终点不参与预测排名。

逐 token ridge 无法把早期 token 编辑传到答案位置。第四轮看到这一结构性缺口后，补做了一个固定输入为本 token 和因果前缀均值的 ridge。它只用同一开发组拟合，保留同一惩罚比例，单独作为补充对照。纯 chart 和混合方法的结果保持原样。
