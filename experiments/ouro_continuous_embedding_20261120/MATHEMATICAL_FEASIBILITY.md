# 连续嵌入的可行性

固定因果掩码和 RoPE 后，原生整轮在实数模型中是 F=N∘R₄₈∘⋯∘R₁，Rᵢ(x)=x+rᵢ(x)。光滑同维 ODE 的有限时流在有可逆解的区域内是局部微分同胚。其导数沿轨迹满足变分方程，行列式是散度积分的指数，故方向保持。局部退化、非单射或反向不可延拓都会对相应的精确嵌入形成限制。自治场还有额外的流半群约束。

即使已有一个非自治嵌入，也可用端点固定的光滑递增时间重参数 φ 替换它的时钟。新场 φ′(t)v(z,φ(t)) 保留单位时映射，所以仅有离散端点无法确定内禀时间。

若所有 γ 非零且 ε>0，N 在实数算术下有像内逆。令 z=y/γ，则 x=√ε z/√(1−mean(z²))，像是 mean(z²)<1 的区域。N 的像有界，因此含 N 的 F 无法成为整个无界 Rⁿ 上一个正反向完备流的单位时双射。这并未排除限制到较小域的光滑嵌入、允许有限反向域的流或混合模型。去掉 γ 的逐坐标缩放后，径向与切向导数的比是 ε/(mean(x²)+ε)。
