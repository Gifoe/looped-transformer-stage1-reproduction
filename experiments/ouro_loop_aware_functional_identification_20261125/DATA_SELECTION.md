# 数据来源、预测和训练对照

原始数据来自固定的官方 Train。`build_pools.py` 逐批读 Parquet，保留全部合格题。无上下文题与既有确认和完整测试的题干比较 NFKC 归一化后的精确匹配及词三元组 Jaccard ≥0.8。有上下文题额外排除验证集和既有保留题的完整篇章。每个来源记录原始与清洗后 SHA-256、排除题号和原始行数。同一阅读篇章只进入一个交叉折。该规则可以发现文本复用，无法认证未知的预训练暴露或改写型近重复。

## 冻结顺序

1. 四折按题号或篇章键固定，全部合格池参与功能矩阵采集。
2. 只读 0–2 折矩阵拟合方向和数据价值预测，保存 `FORECAST.json`、方向及源哈希。第 3 折只用题数核对，在拟合脚本中不读取其结果。
3. 在独立第 3 折重放不同方向及剂量，比较预测排序、误差和最弱环境选择结果。
4. 先做等题数单源训练对照，再按相同的题、顺序和批次比较均匀权重、普通梯度权重、循环权重。权重在来源及原生正确转移、长度分组内构造。另比较 T1 初始化下的均匀权重和循环权重。
5. 只按独立开发集锁定最终检查点。MMLU 开发使用 57 学科的全部 285 道开发题，完整 MMLU Test 供最终确认。

截至可核验的最后一次服务器连接，首批候选池正在采集。跨来源预测文件和第 3 折干预结果尚未核验，当前数据表记录完整合格人群，不能当作全部矩阵已跑完的证明。新模型综合性能待完整测试。
