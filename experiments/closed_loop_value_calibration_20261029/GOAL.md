# Research objective

Discover whether a measurable intermediate response can be calibrated into the value of actual recurrent state actions while keeping Ouro frozen. Prefer the training-free rule; use only the bounded lightweight heads justified by its failed sign gate. The user prioritizes an informative variable that drives continuation or feedback, while independent superiority over LoopCD remains an important part of the full objective.

This stage tests generalization from different training questions to head-held-out development validation. It does not redefine the goal as fitting a regressor, obtaining an AUC, changing hidden states, or passing implementation checks. Those are intermediate evidence only. The overall goal stays unachieved until useful control and independent efficacy are verified.
