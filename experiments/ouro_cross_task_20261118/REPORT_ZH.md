# Ouro-1.4B 的跨任务潜在计算

## 问题与可检验结论

实验检验原生循环是否把输入中第一阶段的变化写入早期位置，并让后续计算依照接收方的第二阶段规则读取它。第一阶段结束处使用同一个标点 token。同最终答案反事实供体更换第一阶段信息，同时在后段更换映射以保留供体真实答案。干预只替换接收方 pre-map 位置的一个 post-layer 向量。预期答案由供体第一阶段与接收方第二阶段的新组合确定。每个组还提供同第一阶段异映射供体、普通异答案供体、原值替换和两种配幅方向对照。

模型权重、原生循环、词表与验证方法来自已有研究。当前任务使用统一的零样本选项标签计分。移植的激活为 2,048 维 BF16 整向量。不同轮的 post-layer、post-loop norm、输出头 logits 和两条残差分支分别记录。运行及来源细节见 [README.md](README.md)。

表中分母为基准样本或每组固定 base 世界。共记录 1,560 个世界。最高分并列计入分母。派生逻辑 base 世界的 36/60 会夸大任务能力。四种因子世界合起来平衡了真实 Yes/No 标签，K4 只有 120/240 正确，且 60 组里没有一组同时答对 base 和第一阶段改变的异答案世界。受控两跳在同一配对检查中为 61/80。算术为 3/80。这两个对照决定了自然行为证据的强弱。

读出位置 post-loop norm 的余弦中位数在 K3→K4 为 0.888–0.962，六类输入均高于该类此前两次变化的中位数。这个几何收敛特征也见于 HellaSwag 和最终正确数几乎持平的算术。ARC 则仍有净改进，K4 相比 K1 救回 52 条、损失 6 条。后续轮的状态变化分布随数据和位置而变，几何趋稳本身不能判断模型是否完成了组合。完整层与转移统计见 [轨迹图](figures/latent_trajectories.png)、[语义演化图](figures/semantic_evolution.png) 与 [轨迹数据](trajectory_results/)。

算术提示诊断在 80 个旧组、160 个有向世界上保持候选顺序。K4 原题答对 69/160，直接给出正确的中间和后为 106/160，换成反事实中间和并相应重标后为 96/160，直接给出乘积后为 148/160。提供第一步结果仍留下 54 个未正确选择的方向，其中包括 16 个并列。这个模式将瓶颈范围缩到第一步结果的使用及后续乘加。提示删去了原始第一步文本并改变了表述，模型内部各步骤的损失贡献仍待识别。[完整算术诊断](arithmetic_diagnostic/summary.csv)

## 单位置因果确认

开发集包含每任务 16 个独立组、双向替换和六个候选点。按开发选择冻结了 K2 的零基 L5（两跳与算术）和 L11（派生逻辑）。确认集每任务 30 个独立组、60 个方向。每组双向平均后的主要指标为 K4 反事实目标相对原答案的 log-prob 差变化。区间按组 Bootstrap，K4 主要对比使用 98.33% 区间，并要求三个对比的下界同时为正。

| 任务 | 同答案供体相对原生，nats | 相对配幅无关方向 | 相对配幅随机方向 |
| --- | ---: | ---: | ---: |
| 受控两跳 | −0.008 [−0.030, 0.014] | +0.004 [−0.012, 0.022] | −0.014 [−0.031, 0.006] |
| 派生逻辑 | −0.002 [−0.022, 0.017] | +0.004 [−0.016, 0.024] | +0.004 [−0.015, 0.023] |
| 受控算术 | +0.016 [−0.009, 0.042] | −0.001 [−0.029, 0.027] | −0.008 [−0.038, 0.021] |

三个任务均未通过。全部 180 个方向的首个可测读出差都出现在被编辑位置的下一个物理层（L6 或 L12）。原值替换和仅第二阶段改变的早期供体均为零效应。在稍后的同轮读出位置恢复自然状态，也没有检测到对 K4 语义效应的稳定削弱。三个任务在独立中间问题上的移植效应相对随机方向区间均跨零。因果证据支持这些位置的扰动能到达读出端，语义传递的窄假设没有获得确认。[逐深度效应](causal_effects.csv) · [读出与分支见证](confirmation/causal_rows.jsonl)

### 单位置病例

1. **两跳 `multihop-024/base`。** Morgan 的箱子本为 copper，接收方映射将 copper 送往 Hanoi、white 送往 Rome。供体让 Morgan 拿 white，并互换目的地，所以供体的真实终点仍是 Hanoi。将供体预映射标点的 K2/L5 向量移给接收方，若携带可用箱子身份，应把答案推向 Rome。L6 读出的首个非零 L2 差为 0.0117。K3 的 Rome−Hanoi margin 从 +0.625 变为 +0.500 nats，K4 同为 −0.1875，答案仍为 Hanoi。
2. **逻辑 `prontoqa_derived-039/same_answer`。** Sam 是 grimpus，接收方经 yumpus 推出 red。供体通过 shumpus 推回相同的最终命题。接收方 shumpus 规则意味着 not red，故移植期望推向 No。K2/L11 移植使 L12 读出变化 0.0182，K2 的 No−Yes margin 从 −0.500 升到 −0.438，K4 同为 −0.625。这个例子的瞬态与全组 K4 空结果相符。
3. **算术 `arithmetic-040/same_answer`。** 接收方先算 34+48=82，再算 3×82+23=269。供体中间值 85，供体第二步补偿到同样的 269。使用接收方规则，预期反事实得 278。K2/L5 单点移植令 L6 首次变化 0.0122，K2 的 278−269 margin 从 +0.8125 变为 +0.875，K4 两种运行均为 −0.5625。中间结果可被另设问题读出，并不保证这个位置具有能驱动最终运算的表示。

三个病例按各任务确认集中语义效应排序的中位方向选取。完整面板和位置见 [病例 JSON](case_witnesses.json)。

## 新组前缀移植

单点确认失败后，沿用各任务冻结的物理层，移植第二阶段之前的全部 token。每任务使用 30 个新组及双向世界，派生逻辑使用与前一批不重合的官方源条目。第二阶段文本和选项保持接收方原样。完整前缀中未变的 token 也单独移植，以检查上下文影响是否保存在字面相同的位置。随机方向逐 token 配幅，无关方向按整个前缀的 Frobenius 范数配幅。两项主要配幅对照的最大实际 BF16 幅度偏差为 0.108%。

| 任务 | K2 整段相对原生，nats | 相对配幅无关 | 相对配幅随机 | 主要判据 |
| --- | ---: | ---: | ---: | --- |
| 两跳 | +3.339 [2.767, 3.900] | +3.342 [2.777, 3.903] | +3.000 [2.473, 3.542] | 通过 |
| 派生逻辑 | +0.009 [−0.019, 0.036] | +0.011 [−0.040, 0.060] | +0.006 [−0.032, 0.044] | 未通过 |
| 算术 | +0.029 [−0.023, 0.091] | +0.047 [−0.024, 0.129] | +0.039 [−0.015, 0.101] | 未通过 |

受控两跳的供体与接收方原生都正确的 46 个方向中，整段移植让 36 个方向从共同原答案变为接收方规则下的反事实答案。移植位置限于 token ID 发生变化的前缀位置时，K4 效应为 +3.228 [2.774, 3.683] nats。只移植 token ID 未变的位置时为 +0.027 [−0.021, 0.074] nats。两个区间为描述性的 95%。在 K1 使用同一物理层移植整个前缀，K4 效应为 +3.786 nats。K2−K1 的配对差为 −0.448 [−0.608, −0.309] nats。因此这个可干预的来源端在第一轮已经足够影响后续答案。较晚轮的自然正确数提升仍可来自下游读取或组合质量的变化。这个试验的干预效应没有随 K1→K2 增强。[完整前缀效应](prefix_followup/causal_effects.csv)

## 两跳机制定位到被查询记录

进一步在 30 个新组固定 K2/L5，只移植被查询对象的箱子词位置，并以同时发生替换的另一条记录、同位置随机方向作配幅对照。三个 K4 主对比均通过。同原生相比反事实 margin 增加 **1.961 [1.461, 2.550] nats**，相比非查询记录增加 **1.578 [1.026, 2.231] nats**，相比随机方向增加 **1.903 [1.431, 2.468] nats**。区间为 98.33%。供体和接收方自然答案都正确的 42 个方向中，目标记录移植产生 14 次反事实决策，非查询记录和随机方向各为 3 和 1 次。非查询记录也产生较小的平均效应（+0.383 nats，95% 区间 [0.203, 0.582]），所以“排他读取”不符合结果。施加幅度的最大误差约 0.032%。

把该条件下 K2/L11 的最终读出 token 恢复到原生受体值，K4 只减少 +0.005 nats（95% 区间 [−0.005, 0.016]）。因此可以把受影响的记录来源定位到该箱子词，后续传递的具体多位置路径仍未定位。读出直接从该记录读取，或经其他记录与映射 token 间接传递，都与这次局部恢复结果相容。[逐深度效应](record_followup/causal_effects.csv) · [汇总图](figures/source_record_transfer.png)

**代表性正例 `multihop-204/base`。** Sam 拿 yellow，Quinn 拿 white。接收方的 yellow→London、white→Paris，供体交换 Sam 和 Quinn 的箱子并交换两个映射，使供体和接收方天然都答 London。只将供体 Sam 记录的箱子词（token 26）的 K2/L5 状态移给接收方，后续仍使用接收方映射，因而预测 Paris。读出在 K2/L6 首次发生变化（L2 0.0123）。到 K2/L11，读出处注意力输出与 MLP 输出差分别为 0.1202 和 0.0037，K2/L23 分别为 0.3038 和 0.1381。Paris−London 的 K1–K4 margin 原生为 −0.3125、0、−1.6875、−2.9375，移植后为 −0.3125、−0.0625、−0.5000、+0.3750。只移植配幅后的 Quinn 记录或随机方向，K4 仍为 −2.6250 或 −2.3125。此例按发生反事实决策的方向中位效应选取。该输入把“保留共同答案”和“转用箱子身份”两种预测分开，结果支持模型在后续读取与 Sam 绑定的箱子，并使用接收方映射得到目的地。[完整病例](record_followup/case_witness.json)

## 结论的范围

- **已支持的具体计算**是受控两跳文本里的查询相关记录复用。前缀作用可从 K1 或 K2 进入，操作的效果主要由箱子身份被改写处的状态提供。更高轮的读出可以按接收方的后续映射产生新的目标答案。现有数据支持两跳任务中的功能解释，仍待区分箱子词的局部词汇痕迹、关系绑定以及读取端进一步的计算。
- **跨任务结果**是单标点假设在三个任务均未获得确认，前缀复用在当前两个非关系任务未得到确认。逻辑由派生配对条件下的低自然能力限制。算术在直接中间问题上为 80/80，但默认完整题只有 33/80，显式给出乘积后才高达 148/160。这说明中间问答的可读性与其在完整任务中的使用可以分离。两项负结果适用于这里的提示、物理层、干预与成绩范围。
- **相对早期研究的新证据**是具体的同答案供体，以及被查询和非查询记录的配幅对比。新结果重现了关系任务的语义前缀影响，来源可在 K1 生效。旧研究中 K2 较强的结论针对不同的读取端算子。新试验无法把来源端效应与旧 L11 理想配对消息算子或 ARC 注意力中介直接合并。跨任务的共享计算和 Ouro-2.6B 的迁移验证仍缺少证据。

## 运行与校验

使用一张 RTX 5090。七个 GPU 阶段模型加载后合计 755.54 秒（约 12 分 36 秒），最高 PyTorch 实际分配约 2.70 GiB。首次系统环境的 CUDA 版本不支持 Blackwell，本次在独立环境安装并校验了 PyTorch 2.7.1+cu128，已核验固定权重的 SHA-256。结束后 GPU 占用为 0 MiB。CPU 审计对齐了 1,560 个自然世界、756 条因果记录中的原生分数、220 个组中仅改后段的前缀身份，以及两个新组干预的互斥样本。[运行日志](logs/) · [执行审计](execution_audit.json)
