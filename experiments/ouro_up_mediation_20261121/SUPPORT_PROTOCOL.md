# Up 的 token 支持诊断

冻结两个自然确认队列的前 128 道。在不调整其他假设的情况下，独立分开 Up 跨世界增量在最后一个提示 token、早于最后一个的提示 token 与整个提示上的作用。首 token 由原模型因果掩码保持且不受非首位写入删除，所以划入早段不引入实际新增差值。两种背景均在真实 Gate 上注入。每种支持另在真实 down 输入处注入逐 token 同范数的坐标滚动作为对照。

如全提示复位的作用由最后一 token 承担，不能据此把 Up 解释成此前 token 的证据传播。若早段成立，才允许将效应定位在共同提示上的上游传播范围，语义内容仍需独立干预。总响应与两个支持的先后包含潜在的非线性相互作用。该诊断不改变两数据集的主中介判据。
