# 自由生成复核

两个确认队列各取按预先顺序排列的前 128 道，全部运行 K1、K2、K2 删写、K2 Up 正向复位、K2 Up 反向替换及正向等乘积范数对照。对所有情形，在 Answer: 前固定加入 Give only the short answer. 指令。不会将候选选项送入模型。每轮至多生成 12 个 token，贪心从完整词表选取，遇 EOS 或完成首行即停止。评分用早已发布的第一非空行完整答案精确匹配。拒绝模糊匹配并同时报告榜样外、未匹配以及不解析分母。

自然清洁和删写前缀共同计算 Up 和 Gate。自由生成时仅修改共同提示上的写入及 down 的实际分量，生成 token 仍执行原生。沿真实候选无关前缀预取的乘积被逐次重用。干预场调用没有教师答案。未达到足够自然纠正时，不能以候选似然的结果刻画开放输出的修复。
