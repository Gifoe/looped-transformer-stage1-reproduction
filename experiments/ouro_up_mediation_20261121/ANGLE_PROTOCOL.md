# 前文方向的同范数同角度复核

前一批前文交换发现完整状态差会显著改变部分 token 的范数。另在此前所有队列之外冻结 192 道 OpenBookQA 和 96 道 ARC。第二阶段不修改此前的前文判据。这组实验检验同一角位移的具体方向是否影响 K2 对答案的选择。

对每个提示前文位置分别取接收和自然供体向量方向 u、v，令 c=uᵀv，s 为 v−cu 的范数。在原接收范数上比较 v 和 cu+s·r，其中 r 为与 u 和真实转动方向均正交的单位随机方向。两组随机种子固定，真实方向另做半角插值。所有条件保持逐 token 接收范数；两个随机对照与真实方向逐 token 匹配欧氏距离。接收方最后提示 token 和所有候选续写位置逐位保持。因此第一次答案读出严格相同。

比较删写背景的真实方向复位和清洁背景的反向替换。每个数据集，各方向相对原生接收和两个同角距对照的完整候选分差 95% 下界均需为正，且在自身自然纠正被删写破坏的同题中，出现至少两例正向救回、反向致错、两个随机对照均无同样影响。报告没有足够纠正分母的情况，所有原始题保留。仅一边或一组成立时，结论限定为条件作用。
