# Ouro-1.4B 的早期前文状态与第二轮答案纠正

## 结论

K2 第 1 层 Up 未通过预登记的双向中介门槛。只恢复清洁 Up 对 OpenBookQA 和 ARC 的全样本正确答案分差作用依次为 +0.023 [-0.053, +0.098]、+0.054 [-0.007, +0.117] nats/token。
独立前文交换保持了所有 K1 候选评分位置。下面报告它对 K2 连续分差、同题恢复、反向损伤和对照的检验。
