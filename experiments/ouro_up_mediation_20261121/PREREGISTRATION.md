# K1 非首位注意力写入经 K2 L1 Up 的因果检验

模型为冻结 Ouro-1.4B Base 574fa66，原生全上下文 eager FP32，候选与层来自前一轮已经报告的结果。确认题 OpenBookQA 与 ARC Train 各 384 道，按题干、ID、已知历史记录和两次前期样本排除，再哈希排序。先筛题、冻结输入和代码，再运行。ARC 更早曾有全划分项目评估，独立性限于当前干预队列。运行不把题目标签交给干预代码。

上游干预删除 K1 L1 原生注意力写入的非首位提示 token。在同一支持上以原写入向量的固定坐标滚动作为精确等范数扰动，并保留半剂量去除。所有干预只改排除候选续写后的共同提示 token。保留原生下游计算。每题测清洁、删写入、半删和滚动情况下的 K1 与 K2。K2 的自然错误候选上最高分者固定为对手，K1 比较也用同一对手。主评分是完整候选的每 token 平均自然对数似然。总分另行记录。正确为唯一分数最大者。

主中介实验固定真实接收前缀和有效 Gate，交换 K2 L1 Up。上游清洁、删除两个背景各包含自体和相反 Up。在删写背景换回清洁 Up 是正向复位，在清洁背景换入删除 Up 是反向替换。原始 Up 剂量对照在相同位置注入滚动坐标的相同 Up 差。乘积剂量对照在 down 输入处滚动原始 Gate×ΔUp，同位置、同范数。Gate 单独互换及 Gate/Up 联合互换用于区分通路，所有结果均报告。不得以全状态复位代替中介证明。

计算两种现成分量的增量 U(h,a)=W_up Norm(h+a)，其中 h 是 K2 Layer 1 进入状态，a 是该层实际归一化的注意力写入。清洁和删除两个自然事实保存，交叉清洁 h 与删除 a、删除 h 与清洁 a，分别通过本地真实 norm 和投影，在删写受体保持 Gate 且仅放入得到的 Up。此诊断区分上一轮携带状态和下一轮重新计算的注意力写入。另报告清洁、删除 Gate 对真实 ΔUp 的乘积贡献不同程度和数学恒等式检查。

主判据按两个任务分别满足。全样本正向复位相对于不恢复及两个配平对照对正确分差的配对 95% 下界为正；反向相对于不改变及两对照均显著损伤。两集各至少有 12 个 K1 错 K2 对且删写变错个例。正向复位在这些病例中救回多于两个配平对照，至少观察到两个同题反向变错的双向个例；全体报告错误修复、原本正确的损伤和组间互换。K2−K1 的删除差须支持对新一轮增长的影响，才讨论纠正而非两轮共享的分差损失。若配平对照或 Gate 产生同等作用，具体中介结论降级。未经新队列的方向修订不能当作独立确认。

次要结果按全样本、自然错→对、对→错、对→对、错→错报告。区间按题配对自举。生成审计是同队列前 128 道的独立无约束读出，用冻结早停与严格匹配，不代替完整候选门槛，也不根据生成结果选题。
