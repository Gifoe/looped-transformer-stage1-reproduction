# 仅交换前文状态，原生答案边界保持逐位固定

本实验通过另一批自然题直接检验早期写入提供的前文状态能否影响真实第二轮计算。使用原生 K1 清洁与删除非首位注意力写入后的两种完整状态。OpenBookQA 和 ARC 各 192 道新题，排除本轮 Up 题、两轮先前自然题及已知历史 ID 和题干。先冻结输入，再评分。ARC 历史整划分曾被评分。追加实验源于 Up 正向复位在第一个确认数据集未获证实，当前队列尚未观测。

接收第一轮状态采取两种真实背景。前文只交换位置 0 到最后提示 token 之前的状态，逐位保留最后提示 token 及每一个候选续写位置。对每题在评分头之前检查这些状态相同。因此 K1 完整候选分差不可能直接被交换改变。随后仅执行一轮真实 F，按同一固定错误对手评估 K2。反向在清洁受体置入删写供体前文，正向在删写受体置入清洁前文。

另比较只交换最后提示 token、交换整个提示、精确等范数前文特征滚动、只匹配供体 token 范数及仅匹配供体方向且维持受体范数。分差和答案更改均以实际完整候选评分。复位和反向损失需各自超过配平，两个数据集均单独报告。确认行为需要每个数据至少 12 道原生纠正且删写变错的题，至少 2 道同题双向且两个对照无相同变化；若只见幅度结果则只报告跨位置传播。该路径若成立可在固定清洁或删写前缀下定位“早轮前文证据经原生后续计算改变答案”的作用，仍需独立识别读出子算子和语义内容。
