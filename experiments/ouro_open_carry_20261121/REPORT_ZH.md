# Ouro 无候选整数加法的进位可测性

256 个组共 512 道可自由生成题。K1/K2/K3 分别解析出 [512, 512, 512] 道，答对 [488, 508, 508] 道。K1→K2 共纠正 21 道、回退 1 道。符合错值恰好差一个进位且随后正确的有 **0/256** 组，未通过 24 组的冻结门槛。

该标准只确认此类错值修复是否有足够样本。完整机制测试须用不同组和受体迁移对照。两种长度的原始结果见 SUMMARY.json。

重跑需要原生计算实验目录加入 PYTHONPATH，并运行 python carry.py PINNED_MODEL_DIR OUTPUT_DIR。
