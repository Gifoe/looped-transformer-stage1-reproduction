# Natural trajectory and L18 swap figure

Run `python build_inputs.py` followed by `python plot_results.py` (Python 3.9+ and matplotlib). The first script reads the supplied source summaries, checks layer alignment and swap arithmetic, and writes `layer_curves.csv`, `l18_swaps.csv` and `source_sha256.csv`; the second writes PNG and vector PDF.

`sources/geometry-summary.json.gz` originates from `research_plans/natural_r_geometry_20261111/summary.json.gz`; each `branch-{split}-summary.json.gz` originates from `research_plans/natural_branch_{split}_exploration_20261111/{split}_summary.json.gz`. Each `l18-{split}-summary.json` is the independently reviewed summary for the named split. The CSV source manifest identifies the exact bytes used. Layer curves use the mean of the within-question equally weighted gold-versus-wrong-option difference; train excludes demonstrations. The geometry source uses zero-based layer indices and branch summaries use one-based layer numbers; the displayed ordinal is 1–24. The L18 swap results report actual candidate-score replay counts, which are separate from the offline lens measurements. Open points are baseline and filled points are swaps. Correct-to-wrong and wrong-to-correct counts include the summary's scoring/tie conventions; consult the underlying review and coverage files for full definitions.
