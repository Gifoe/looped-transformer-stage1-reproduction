## Stage A: first-site versus later-bundle competition

For each factor E and L, add six conditions on all64 discovery items:

1. P plus that factor's fixed reference differences.
2. N minus those differences.
3–4. The corresponding per-site norm-preserving versions, exactly as the running bundle protocol.
5–6. The corresponding equal-reference-dose unrelated-direction versions, using the frozen rule and the same selected sites only.

These are12 new conditions. N, P and the full E+L conditions/controls are the already frozen anchors; exact reuse is permitted after source binding. The intervention at each site remains BF16(FP64(current output) ± fixed d_l), with one cast, effective delta and cast residual recorded. It is not a claim that later outputs equal the original reference trajectory. MLP and the rest of the model recompute normally.

For restoration use H00=F(P), H10=F(P+E), H01=F(P+L), H11=F(P+E+L). Report both conditional effects of each factor and H11−H10−H01+H00. Construct the analogous removal factorial using N, N−E, N−L, N−E−L. Do not divide by the full effect or rank site importance from unmatched vector norms.

Before treating E as an actual Q-read operation, verify on the fixed technical cases that N/P at L9 have bitwise identical R input, post-RoPE q_R, P/R keys and values, positions and effective attention arguments. At that station, restoring N K_Q and V_Q through the actual full-shape SDPA and replacing only its R output row must reproduce a8(N) in P, and the reciprocal operation must reproduce a8(P) in N. Their downstream full logits must bridge the corresponding E-only difference intervention. Non-R SDPA rows remain those of the receiver background. These endpoint identities establish the operation being tested; by themselves they are not a writer discovery.

## Stage B: only if the first-site E qualifies

Apply the running protocol's discovery qualification rule separately to E and L: restoration, natural-context loss, their norm-preserving versions and both unrelated-adjusted effects must have strictly positive means in fresh natural-rescue items, with no mean sign reversal in fresh natural-no-tie sensitivity. Report undefined controls and all other groups. No accuracy-based winner selection.

If E qualifies, add at most eight conditions to the same64:

- In P, restore only K_Q or only V_Q to N at L9: two conditions.
- In N, roll back only K_Q or only V_Q to P: two conditions.
- Repeat each of those four with the donor K or V rescaled per token/head to the corresponding receiver's norm before its single BF16 cast: four controls.

Use the actual q_R of the receiver, which must match across N/P at L9; keep P/R K/V fixed. Q/K are already post-RoPE. Use the original full SDPA shapes, scale, mask and GQA, and write only the resulting R output row into the receiver. Later layers and the MLP recompute. Handle zero donor norm explicitly as in the accepted source controls; do not fabricate a direction.

Together with the existing unchanged and both-KV endpoint conditions, this is a true K_Q×V_Q factorial within each receiver background. Report candidate scores and interaction after the actual local norm and suffix. Key changes can redistribute attention over all legal positions; they are not synonymous with reading new Q value content. V-only changes identify an effect of Q value updates, including their possible amplitude component; passing the norm-preserving control is needed for a stronger direction-sensitive statement. Neither result establishes semantic reasoning or answer content.

If E fails but L qualifies, validate the fixed L10–L16 bundle as a feedback-conditioned distributed candidate; do not open Stage B or automatically split more layers. If both fail while the full bundle passed, retain a cooperative/context-dependent bundle explanation and reject a single-factor writer claim. No automatic combined-bundle or recurrent alternative is added.

## Optional bounded routing test, only for a supported key factor

If Stage B finds bidirectional key effects that persist under the K norm control, perform at most four further discovery conditions to distinguish routing to old R from the rest. Do not select heads or individual Q tokens.

For each receiver background B∈{N,P}, hold its actual values V_B fixed and reconstruct the L9 R attention row for K_Q=N versus K_Q=P using the original global R position/mask/scale/GQA. In FP64 define r_R=(A_N−A_P)_R V_R. Let d_B be the difference of the two actual native BF16 SDPA_R endpoints, expressed in FP64; define c_B=d_B−r_R. Thus c_B contains P/Q routing plus the explicitly recorded native-versus-ideal numerical residual. It is not a pure semantic Q component.

In P add r_R alone or c_P alone to its actual SDPA_R; in N subtract r_R alone or c_N alone. Cast once and run the real suffix. Verify that adding/removing the full d_B reproduces the actual key-only endpoint exactly, and verify bytewise restoration using the actual cast delta. Report ideal component and numerical-residual magnitudes separately. Four conditions maximum; their standalone causal effects/interactions do not linearly decompose final scores. If the residual is comparable to the component being interpreted, report the test as numerically unresolved rather than assign it to information flow.

This directly tests an old-R-value routing contribution. A key-only effect alone cannot distinguish old-R gain, prefix routing and Q routing. An effect in c_B does not uniquely identify Q content because it also includes prefix routing and numerical residual. No further region/head expansion is authorized here.
