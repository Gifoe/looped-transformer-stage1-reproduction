# E2 v3 independent code and data-isolation audit

Scope: read-only examination of local `e2_fit_probe_v3.py`, `e2_extract_states.py`, `e2_posthoc_audit.py`, saved audit receipt and remote `E2_PROBE_FIT_ORDER_v3.md`; read-only aggregation of source candidate sets and a separate synthetic finite-difference check. No model inference, probe retraining, or executor-file edits. This is not an independent re-run of the complete 10,360-tensor audit.

## Findings

1. **Test-once path not yet verifiable.** v3 filters rows to train/validation for fitting and outputs only train/validation predictions; it does not implement frozen test evaluation. No probe test-evaluation script was found in the searched E2 project paths at audit time. Frozen selection JSON/NPZ exist, but their existence does not demonstrate a single locked test evaluation. Require a separately reviewed evaluator that verifies hashes of frozen selection, model arrays, source states/rows and order; loads train-derived classes/transforms; performs no refitting or validation-driven reselection; records all test predictions, OOV coverage, model identities, and immutable output/receipt. Do not call test independent or unseen: the ARC test outcomes and E2 descriptive extraction were already exposed.
2. **Label shuffle is conditional, and rare masks cannot be shuffled.** Exact target tuple bucket sizes for non-demo train are 1092, 1, 1; deterministic seed changes 820/1094 targets. The two singleton masks retain their original labels necessarily; accidental unchanged labels also occur. Report this coverage, and interpret as a within-candidate-set label permutation control, not unconditional random labels or a guarantee every label changes. Selection on same-loop validation real labels is performed separately for the shuffled control as written; report it as an independently selected control, not the same frozen hyperparameter.
3. **Unit-L2 interpretation needs care.** `unit_l2` first normalizes each vector by its own L2 norm, then fits shared train-only per-coordinate mean/std from pooled K1+K2 and applies that affine transform to both loops. This eliminates each sample's overall scalar norm before the transform, but the resulting coordinates are not unit length and the classifier is not a pure angle-preserving spherical probe. Both raw and unit variants use separate pooled-train transforms; no validation/test feature affects those estimates. Zero vectors map to zero, zero standard deviations to one.
4. **Prior validation exposure.** Order v3 records unsuccessful earlier fitting, including partial validation selection in attempt2, before correction. Thus train/validation selection is usable as development evidence but validation is not a pristine, previously unseen selection set. The corrected v3 uniformly refits all settings. Record old attempts; don't claim v3 is the first validation exposure.

## Checks passed with stated limits

- Counts: train 1119 including 25 demonstrations, 1094 after their exclusion; validation 299; test 1172. Fitting code filters out test rows before feature extraction, labels, model fitting and hyperparameter selection. Extraction and post-hoc audit had already processed test for descriptive purposes; test items and outcomes have prior exposure.
- Train-derived candidate vocabulary has 5 token IDs, including rare token 414 once in train as candidate and zero times as gold. Across all three splits no candidate is OOV and no item has duplicate target token IDs. Masked logits are negative infinity for invalid choices. The robust implementation excludes a whole validation example if any candidate is OOV, but current supported validation count is 299; test support was assessed only by candidate-set membership, not model results. The source rows were parsed in full for this audit, though test gold values were not used.
- Objective is mean masked cross entropy plus lambda/2 times all squared coefficient entries, including the appended bias row; analytic gradient adds lambda times every entry. This matches amended order v3 and makes all bias coefficients regularized. Independent central finite differences on an unrelated masked toy dataset yielded maximum error 4.66e-10, including bias row. Original initial order had unpenalized intercept, but its explicit v3 correction supersedes it. Toy script `e2_gradient_toy.py` is retained; it verifies the mathematical expression, not execution of the production function.
- Two sites, raw/unit variants, two independently trained source loops, real/permuted label controls each select a penalty using same-source-loop validation logloss. For each selected model exactly the same coefficients and pooled transform are applied on both K1 and K2, supporting transfer comparison for that model; separate source-loop models are not the same model. Optimizer success, finite values, and uniform 4000 iteration budget are asserted.
- Source post-hoc receipt states all four stored BF16 probe states per question were checked against hashed original branch data, including split/id source linkage. It explicitly does not prove that collection checked source hashes at execution time. Extraction uses only saved answer-readout R states; intermediate LM-head projections are diagnostic lenses, not natural predictions.

Future execution gate: distinguish frozen training/validation artifact from a separately timestamped locked test evaluation, record every model/metric and prior exposure, and require Astra to judge inference from decodability to natural use. No claim that a learned probe proves the model uses the decoded information.
