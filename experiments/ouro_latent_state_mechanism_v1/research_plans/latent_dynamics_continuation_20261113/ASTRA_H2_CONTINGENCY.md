# H2 之后的科学分支：持续目标，不持续搜特征

状态：H2 执行中的前瞻分支准备；尚无 H2 科学结果。本文件不改变其预注册定义，也不授权新的 GPU 实验。Astra 只指挥；Sol 执行所有分析/实现/数值复核。当前 Goal 是机制理解与实际无 gold 推理收益，不能因一个 family 失败就标记整个 Goal 达成。

## 当前必须先做完的实验

Sol 完成既定技术2、精确 native full-vocabulary endpoint 桥接、预算核验和自然 H2 采集。真实逐层 x、实际 attention residual-add 后状态、a 与 FP32 final-norm lens；target L10–16，control L2–8；只 Train/dev，不新增 Test。通过技术/预算门槛后实际运行固定 nested group-CV，而不是再写一份计划。原 Brier 主指标、对照、16维定义和 G1 门槛保持不变。

Sol 的一次结果包应包含：技术覆盖/失败；实际成本；各 fold 配对预测损失与 interval；与 output-only、低层、shuffle 的比较；固定动作闭环结果；标签/未来信息可用性审计；以及符合与违背假设的逐题记录。不得用 Test 或事后筛选的成功组重定义 H2。

无论哪一分支，E6C 内部状态控制都不自动解锁。可预测性、特定计算的因果作用和可部署收益是三个不同证据层级。

## 若 H2 失败，优先判别的新问题

不再先问“还有什么内部特征能预测对错”，而问：**循环纠错中有多少现象依赖答案符号/选项位置的读出绑定，而不是对相同题意稳定的候选区分？**

两种竞争解释：

1. 循环主要增强对候选内容的区分，故把等价候选重新排序、对答案符号作一致重命名后，映射回语义候选的状态变化与纠错大体可对应。
2. 相当部分收益或损害来自协议相关的符号/位置/上下文绑定；相同语义任务的合法重编码会系统改变循环转移、早停和读出稳定性。

这是一个可用**原模型自然前向**检验的输入层因果问题，不是把 E6C 改名后继续 hidden-state patching。失败的被动 feature classifier 不禁止研究输入重编码对真实循环的影响；但结果只能定位协议依赖，不能凭输入敏感性宣称已定位内部 writer。

收到 H2 失败证据后，Astra 才决定是否下达具体小范围指令。候选最小设计是预先固定 Train 非示例题上的2×2自然前向：题目候选内容顺序不变/确定性循环置换，乘以答案符号不变/在演示与待答题中一致双射重命名。所有版本保留语义答案，当前 gold 仅供离线映射评价，不参与置换选择；必须结构化处理演示答案和候选标签，不能用字符串替换污染题干。对各深度将预测映射回原候选身份，保留原生 identity 与评分/token长度审计。

该设计必须先通过语义等价性审计：例如“以上全部”“A和C均正确”、选项间引用和题干中的图示字母可能使朴素重排/替换改变题意。不能把这种改变算作模型不等变。Sol 需在查看新 outcomes 前固定可执行的 eligibility/引用处理规则，保持科学内容中的字母不变；无法保证等价的样本显式排除并报告覆盖。排除依据是任务语义，不是 gold、效果或运行时长。

应预注册且一并报告：配对自然纠错/损害的变化、候选身份一致性、全部候选 gap/ties、不同 nuisance 因素及其交互、实际成本。样本不按效果挑选，同一题的多个版本不能当独立样本。完整 counterbalance、预算和判据须在那一轮的 outcomes 前冻结；现阶段不启动采集。

解释边界提前明确：重命名改变许多 prompt token、重排改变内容位置；它们检验的是整个自然系统对合法任务重编码的依赖，不是某个 attention/MLP 的纯效应。如果效果小，说明该 nuisance 解释受限，而不是证明完成了语义推理机制。如果效果大，需区分协议脆弱性与可利用的多视角互补，不能只展示有利排序。

## 与实际推理目标的连接

若自然重编码存在稳定互补，才考虑冻结一个无 gold 的双视角 K2 聚合，与单视角 K4 及同实际预算强 output-only 比较；它是 output-only/输入多视角策略，不得冒充 latent-aware 方法。要计入第二份 prompt 与所有前向成本，不能仅以“2+2=4 loops”宣称同延迟。若没有互补，不启动该方法分支。

这条备选路线刻意检验一个可反驳的协议层解释，并可能揭示可利用的多视角信息；它不预设正结果，不越过当前 H2，也不承诺最终超过 K4。若它也被否定，Astra 必须依据两轮实际结果重新定位计算问题，不能把持续 Goal 变成无限规则/特征搜索。完整研究目标仍未达成，直到有相应机制证据和实际增量，或已经明确需要用户/外部条件才能跨越的实证障碍。
