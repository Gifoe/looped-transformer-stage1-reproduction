# E6-A execution protocol

Executed by the current agent model; Astra was not invoked, as requested. Ouro weights remain fixed. Primary historical ZL method weighted4=[0,1,1,2] was fixed before development labels were evaluated. Cal uses the small predefined14-item grid, Validation correctness, then lower depth/name ties; its frozen winner is cal_early_0.99. Candidate count32 includes native baselines. New Test method outcomes were evaluated in one frozen batch after writing method/source/data hashes; previous ARC Test exposure is explicit. No Test-result-dependent parameter revision is permitted.

Score fusion subtracts each loop candidate mean, preserving predictions and removing common offsets. Candidate probabilities are softmax over only offered options, not correctness probabilities. Log-probability averaging and raw-score averaging with the same weights are algebraically equivalent up to a common offset; do not count them as independent discoveries. Rank ties receive average ranks; output first-index ties are preserved. Voting ties fall back to K4 when among tied winners. Confidence-only selects from K2–K4, ties choose later depth. Early exits use only adjacent already-computed predictions, current candidate confidence/entropy at K2/K3; the offline evaluation does not claim observed speedup.

Paired percentile bootstrap:10000 question resamples, seed20261113; whole Test comparisons are exploratory except the two declared primaries. Intervals are not multiplicity-corrected; no significance claim follows from the best posthoc Test row. Macro-F1 is not treated as a semantic-class metric because answer indices are question-local. Exact raw production ties and the all-native+method-no-tie subset are separately reported. Native Oracle is an evaluation-only ceiling, never an inference input.

Hardware refresh: all5090 comparisons require a complete new same-device native baseline. They are stored separately from the historical A6000 comparison. Full-answer transfer is independently frozen in FULL_ANSWER_PROTOCOL_FREEZE.json: question-only prompt, same25 demonstrations with complete answer text, full candidate continuation likelihood, character normalization primary, token normalization/sum secondary. Letter-scoring gains cannot be relabelled full-answer gains. The input/gold separation, source attestation and causal prefix/native identities are checked before collection.
