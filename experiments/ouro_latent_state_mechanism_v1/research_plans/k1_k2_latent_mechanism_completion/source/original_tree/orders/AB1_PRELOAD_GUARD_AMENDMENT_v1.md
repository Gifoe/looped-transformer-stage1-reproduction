# AB1 pre-model-load resource guard amendment v1

Preparation for the next safe restart only. The active v4 collector is not stopped or edited. It checks resources before a potentially long completed-pair verification and again before each question, but may reach model loading several minutes after the former check. The proposed v5 adds a fresh A6000 free-memory >=20 GiB and remaining-batch disk-reserve check after strict resume verification, immediately before `load_model`. A low resource result writes and fsyncs a controlled pause event with `model_loaded=false`, then exits75 for the existing safe retry logic; it does not allocate the model. The threshold, 16-case incremental reservation, per-question guard, BF16 model, SDPA, controls and scientific conditions do not change.

The new freeze must bind the prior incremental freeze SHA `1b9221b61b2474b928f2d448f9521cd07e7b4571ca99724366829f84ee9fb89d`, contain every prior frozen source with exactly the prior SHA and append only the separately named preload-guard collector/supervisor/coverage/analysis/quarantine files and this amendment. Train/Validation ID order, inputs, prefix, checkpoint/model state, original order, correction, E2 heads and all scientific fields must be byte-identical to the parent freeze. An independent source/field diff receipt must verify the complete binding before any use. Original freeze and files remain immutable.

Already saved v4 pairs and STARTED receipt have the parent freeze SHA. A v5 resume may accept exactly the current new freeze SHA or that exact parent SHA, never arbitrary prior versions; it must still recompute every source/condition/control tensor and saved score for each pair, verify ID/split/R/targets/prefix and archive/raw SHA, and recheck sources. Coverage auditing applies the same exact two-version rule and records the new freeze, while preserving the original per-case freeze fields and files. Orphans and partials remain fail-closed and are quarantined only by the existing explicit receipt-preserving method. No scientific data is discarded or overwritten.

When the main supervisor is restarted at a safe idle/controlled-pause boundary, its actual unit invocation and PID change. Any exact-invocation-bound future bridge technical coordinator must fail closed and be separately re-bound to the new invocation before use; the CPU-only E2 postprocess sidecar must likewise bind the new execution freeze. No route or scientific sampling decision is changed. This amendment is not evidence of model execution or scientific result.
