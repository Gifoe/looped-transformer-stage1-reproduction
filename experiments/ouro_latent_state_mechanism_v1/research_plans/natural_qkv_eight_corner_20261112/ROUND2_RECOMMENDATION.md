## 已有证据与未解之处

两个 Query 背景下，K2 与 V2 的终端候选 gap 配合在 Train 非示例、Validation、Test 均重复：I1 均值为 .309396/.285187/.292795，I2 为 .336266/.324676/.317713，且各分区均有超过半数题的精确 BF16 gap 交互为正。Key-only 与 Value-only 不是可脱离背景排列的两种独立贡献；平均 gap 排序随 Query 和自然分组反转。Validation 的 Q1/K1 背景 Value-only 净救回为 −1，是必须保留的失败。

理想实数 attention 在固定 Q 下的内部 KV 有限差可写成 `(A2−A1)(V2−V1)`，其中 A 是由 Q、K、mask、scale 决定的注意力权重。该代数结构提供了配合的计算候选，但本轮没有直接观测 A，BF16 运算和局部 norm/后缀也使终端 gap 的交互不能直接归属于它。保存的 SDPA_R 与 attention increment 八角向量是可复核的中间结果，不是已经完成的自然因果路径证明。
