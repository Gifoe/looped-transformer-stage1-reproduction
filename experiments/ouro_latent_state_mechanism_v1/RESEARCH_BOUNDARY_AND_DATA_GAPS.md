## Fixed checkpoint forward graph

The inspected file is `/home/luansiyu/loop-latent/model/modeling_ouro.py`, SHA256 `c5c68fbb368ce2909c257ae2afc50719be8c91539333d3295e19312c4316f413`, matching the fixed [official revision](https://huggingface.co/ByteDance/Ouro-1.4B/blob/574fa66cb8bf5abdc979642d01cf2b79b16bfab1/modeling_ouro.py). Line numbers below refer to this file. For fixed input IDs, eval mode, no intervention, `use_cache=False` **and no supplied past_key_values**, let X0 be the full sequence embedding tensor and let M and P denote the fixed causal mask and RoPE positional embeddings. Each X is the full sequence state; attention couples positions, so this mapping cannot be applied to the isolated readout vector alone. Then

`X_(t+1) = N(L_23(...L_1(L_0(X_t; M,P); M,P)...; M,P))`.

This is one shared mapping applied four times, not 24 identical layers: each physical layer has its own parameters and those same 24 modules are reused in each iteration. The fixed revision and runtime numerical path still require actual GPU parity.

- Lines 535–536 embed once; lines 551–588 construct positions, causal mask and RoPE before the loop. Lines 592–608 execute all 24 modules each loop, apply the shared output norm and feed its output to the next loop. No new token embeddings are injected between loops.
- Each layer has pre/post attention and MLP RMS norms with residual connections (lines 368–423). The outer shared RMS norm computes variance in FP32 and returns in input dtype with its learned weight (347–362). The residual after physical layer 23 and loop-post-norm state are different sites.
- Q/K/V projections and the same positional cos/sin are used at each physical attention layer (lines 292–312). `current_ut` is passed through the layer; in this implementation its explicit use is the cache-slot index inside the `past_key_value is not None` branch (314–322). Thus it does not explicitly change the no-cache/no-past-key-value mapping. `use_cache=False` alone is not a proof if a non-null cache is passed manually. Attention dispatch is at 324–340; the historical contract requests SDPA, eval mode gives zero dropout.
- The gate is computed from each normalized loop state (606–608) but is not fed into the next state. All requested iterations execute before output selection. For `labels=None` and valid zero-based `exit_at_step`, that state is passed through the full LM head (773–779); threshold/weighted branches are bypassed. With labels, the code uses weighted expected logits (762–771), a different path. `exit_at_step` alone does not reduce loop computation; true independent K execution changes `model.model.total_ut_steps` and restores it afterward.

## Related primary evidence and limitations

- [Zhu et al., Scaling Latent Reasoning via Looped Language Models](https://arxiv.org/abs/2510.25741) introduce Ouro, latent recurrence and learned depth allocation and report controlled behavioral analyses. Their interpretation of knowledge manipulation is a paper-level claim; it does not identify which computation causes the ARC joint-letter decisions studied here.
- [Blayney et al., A Mechanistic Analysis of Looped Reasoning Language Models](https://arxiv.org/html/2604.11791) analyze attention patterns, cyclic trajectories and stages across multiple architectures, including Ouro-1.4B. Their results show architecture-dependent dynamics; notably, their Ouro results do not justify assuming a strict shared fixed point. Their stated limitations include not analytically explaining why observed stability occurs or whether it helps reasoning. Attention/trajectory correspondence alone does not establish a causal ARC decision mechanism.
- [Monitoring latent reasoning in looped language models](https://arxiv.org/html/2610.18127) reports trajectory, next-token and attention observations across several model families, including Ouro-1.4B. Its Ouro experiments use six iterations although trained depth is four, with generated-token and other prompt sets, and the authors explicitly do not test early-cutoff generation. Its §4.5 also applies Gaussian noise interventions at latent entry states, providing non-structured causal perturbation evidence about output sensitivity. It does not isolate the local layer/token computation responsible for an ARC decision. These are close prior art and a novelty constraint, not evidence that K1→K2 drives this frozen four-loop ARC scoring or that an attention pattern causes a correction.
- [Brinkmann et al., A Mechanistic Analysis of a Transformer Trained on a Symbolic Multi-Step Reasoning Task](https://aclanthology.org/2024.findings-acl.242/) combine correlations with causal interventions in a synthetic symbolic setting and report intermediate results at selected token positions. This is methodological precedent, not direct evidence about Ouro or ARC.
