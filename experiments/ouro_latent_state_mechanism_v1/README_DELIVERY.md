# Scientific code and analysis snapshot

This snapshot contains selected local copies of completed and exploratory research code and analysis records. It is not a complete raw-artifact archive; no model weights, credentials, helper keys or original large activations are included. Some draft scripts were never run: use collector receipts and per-file hashes, not filename alone, to determine what ran.

The original Linux project root was `/home/luansiyu/loop-latent`; prior audited repo HEAD `1d1f8c0fcaa7aadf5aece910b159f2f920ebb8f0`, branch `research/ouro-latent-mechanism-20261107`. Three-case QKV probe recorded PyTorch 2.5.1+cu124, CUDA 12.4, NVIDIA RTX A6000, BF16, SDPA, batch1, no cache; actual kernel was not captured. Original project conda Python: `conda-env/bin/python` (Python 3.11). The scripts rely on pinned source, checkpoint/config/tokenizer, demo/data and prior evidence; they are not standalone.

QKV production core is `natural_qkv_intervention_draft_20261111/full_qkv.py` (SHA256 3098b8255d948bc5c3b3466f53a804c660ae7577088bdbafcd5926f0250500d8), `qkv_runner.py` (9f4f74e83df5eaa1deb26c1a310e5b65998392b27ac108c8cb2349ac9ccb0cac), `qkv_observer.py` (0f644143e57e037f1430c3c1059808ea1dca0576ec76ac0ccb35255a6e6def5c), probe/replay and CPU split audit/analysis files. Python imports also require `natural_l18_hook.py`, `natural_sources.py`, and branch `technical.py`, `full_input.py`, `state_capture.py`, `source_input.py`; these appear in sibling snapshot directories and must be resolved with an explicit PYTHONPATH.

In QKV results, F11/F21/F12/F22 means Q1KV1/Q2KV1/Q1KV2/Q2KV2 on the fixed K1 receiver, respectively. Train, validation and test summaries and rows are stored separately. Source/endpoint CPU audits link to the independent 2590-question CUDA logit replay, which reused the collector check implementation; natural whole-tensor SHA was not rehashed in the lightweight validation/test re-analysis. This was an exposed ARC project, not independent blind validation. Joint KV does not distinguish K versus V, and a transferred K2 attention output does not establish a unique natural mechanism.

`round3_*` directories contain prior result snapshots; this selection is not a complete ROUND2/ROUND3 source reconstruction. Local small snapshot manifest records file hashes.
