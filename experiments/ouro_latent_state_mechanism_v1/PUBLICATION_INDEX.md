# Research artifacts and reproduction index

This directory is a preparation snapshot derived from frozen source commit `1d1f8c0fcaa7aadf5aece910b159f2f920ebb8f0`; the publication commit is a curated export and does not claim to reproduce the full server Git history. The Chinese [research report](FINAL_RESEARCH_REPORT.md) supersedes older status notes and remains a work in progress until the final QKV analysis. The original experiment code, input manifests and earlier reports are in this directory. `research_plans/` contains analysis plans, analysis code and selected summaries, including the train/validation/test exploration. `figures/` contains the natural trajectory and L18 swap figure, source data, source hashes and scripts for reproduction.

The repository snapshot is only one part of the full record. Large raw experiment outputs and per-question data are staged separately as release assets with portable SHA-256 manifests. Their release URLs, exact scope and final coverage will be added only after all required assets have been uploaded and verified. Current experiment status and results require the final scientific audit; incomplete or failed runs must remain identified as such.

Model checkpoints, machine environments, authentication materials, temporary locks and caches are excluded. The original underlying data and source provenance are documented in the included manifests and reports. Run the figure instructions in `figures/README.md` to regenerate the figure from its checked source summaries.
