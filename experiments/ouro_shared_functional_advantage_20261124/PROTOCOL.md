# 共享功能优势实验协议

Ouro-1.4B Base 使用已核验权重、BF16、SDPA 和无 KV cache。控制器保持两个 FP32 的 2,048 维向量，沿用相对 RMS 0.45 限幅以及最后一圈之前的共同写入位置。基准前向与真实生成保留原生循环数。

新的训练数据由 ARC-Challenge、CommonsenseQA、SQuAD 和 GSM8K 四个官方 Train 来源组成。每个来源分别固定 48 条拟合矩阵、48 条独立矩阵确认、96 条独立开发和 840 条优化训练。开发和矩阵确认都排除已知旧 CSQA 排序、40K 权重的训练输入，同时排除可查的前项目开发、确认及测试输入。正式 Test 不用于配比、阈值或权重选型。提前 EOS 以实际生成及终止原因为准。

共同度量是正确决策相对竞争集合的对数优势。候选使用完整候选字符归一分数和对应错误候选的 logsumexp。生成使用当前 gold token 相对最佳错误非 EOS token 及 EOS 的优势，允许多个竞争 token 的 logsumexp。EOS 作为正确终止时只与最佳错误非 EOS 竞争。在 GSM8K 的题内早期过程、后期过程、最终答案以及应停位置分别取题内均值。ARC/CSQA 的候选与直接内容、SQuAD 的全文本 span 分开成组。生成轨迹另存正确答案、终止原因和早停频次，用来判定 teacher forcing 优势能否外推。矩阵尺度只从 Train 拟合折的原生优势标准差估计，最小值为 0.25。

一阶发现拟合共享方向时同时保留平均目标和最弱组目标。用未参与拟合的同任务和深度样本测其投影及有限剂量差值。数值结论区分有限样本的可行下界和谱上界。支持符号外推需要在 K5/K6 及真实贪心上另行确认。跨边界传输比较同一终点、同一控制器及受控剂量。

训练比较原始排序、原始生成、普通混合以及低温最弱组优势，同一数据和循环调度。统一优势从随机、已发布匹配的 CSQA 排序及完整混合三个检查点继续。训练后只用预留开发折选择一个部署权重，按完整生成和官方候选协议保留所有正负结果。预算单卡 18,000 秒，包括加载、分析 GPU 作业、训练、验证、测试与失败尝试。之前重训项目的公开评测保持暂停。
