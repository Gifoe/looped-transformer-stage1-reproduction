# 循环 Transformer 的共享功能优势

四轮研究使用单卡 RTX 4090 D 完成 GPU 验证。GPU 作业累计 4 小时 51 分 59 秒。全部 210 项正式条件已通过逐题回执、冻结配置和指标重算校验。仅用开发集选择 anchored_policy，冻结 Ouro-1.4B Base 并保留一个 4,096 参数检查点。

## 共享方向在参考轨迹上成立，作用范围取决于干预剂量

在 27 个训练阶段与深度组合上，经验 maximin 的可行值为 1.9119，谱上界为 3.0353。独立的训练保留样本上，同一 4,096 参数方向在 K2–K4 有 27/27 组一阶平均优势为正，训练未覆盖的 K5/K6 有 18/18 组为正。只用候选任务拟合的方向分别为 18/27 和 12/18。各组灵敏度来自实际反向传播，使用训练集的原生优势离散程度归一化。

沿同一方向做真实 BF16 写回，剂量从 0.1 到 0.5、1.0 时，优势为正的组数从 45/45 降到 30/45、19/45。一阶预测的平均绝对误差从 0.0489 增至 0.9896、3.6694。K4 的 GSM8K 终止阶段把写回从较晚圈移到较早圈时，一阶预测有利，剂量 1.0 下实际平均差为 −1.8391，95% 配对区间为 [−2.0579, −1.6161]。这些结果给出了共享方向的局部证据，也给出了深度传输的具体反例。 [功能矩阵与传输](MECHANISM.md)

## 候选排序为什么更容易迁移

每个候选任务只取 8 个拟合样本时，独立样本上的 10 个候选组斜率已全部为正，扩大到 48 个样本后，最弱斜率从 0.468 升到 1.500。生成组只有 18–20/35 为正。六个候选矩阵中，群体均值的外积项相对平方 Frobenius 能量为 0.558–0.979。零写入初始化的首步梯度恰为组矩阵乘随机读出方向，均值结构因此能帮助找到候选共享方向。256 个模拟的随机读出中，用完整矩阵得到 141 个全部候选组正收益方向，用均值外积得到 132 个，使用中心化矩阵得到 79 个。完整生成组在这项初始化检验中没有全正方向。

生成组的冲突随阶段和预算改变，GSM8K K2 最终数字与终止阶段的矩阵余弦为 −0.494。真实前缀干预发现，历史 Retention 既能通过改变前面已经生成的词元间接提高 EOS 倾向，也会在相同前缀上直接提高 EOS 倾向。过程早停只是失败的一部分，弱剂量固定方向在 GSM8K K2 使过程联合正确由 13/64 降至 2/64，其中 11 道变错题有 10 道触及长度上限。 [前缀干预与矩阵汇总](MECHANISM.md)

## 统一训练目标的实际表现

同一冻结 Ouro-1.4B 主干、同一 4,096 参数写回结构，用 3,360 条四域平衡训练样本对比排序、生成 NLL、普通混合和归一化功能优势。排序基线在适用的两个选择题域消耗 1,680 条。归一化最弱组的排序、完整混合热启动与随机启动均完成。训练后段，最弱组方法的 ARC K4 训练平均优势由均匀目标下的 −0.268 提至 +0.230。在实际 K4 开发集上，最弱组方法的 ARC 候选准确率为 44/64，Native 为 39/64，普通排序为 48/64。它的 GSM8K 过程联合正确只有 3/64，Native、普通混合和纯生成分别是 14、26 和 33/64。统一训练在这些可比结果中没有同时改善候选评分、短答案和长过程生成。

第三轮的同初始化、同 336 步、同样本序列对照中，利用真实提前 EOS 前缀使 GSM8K K3 标记前 EOS 从 64 降到 61/64，过程联合正确从 0 增到 1/64。第四轮从普通混合权重初始化，以它作唯一离线参考。现有 GSM8K K2 的过程联合正确从普通混合的 24/64 降至 1/64，提前 EOS 从 15/64 升至 43/64。第四轮同时改变了起点、参考和学习率，当前对照只支持该方案整体的比较。 [开发结果](results/PAIRED_DEVELOPMENT.csv) · [训练消融](ABLATIONS.md) · [方法与参数](METHOD.md)

随后对 14 个实际控制器进行了离线投影。普通混合与第四轮权重在 45 个条件都保留正的一阶组均值，两个方向余弦为 0.935。第四轮在 K2 的早段、中段和最终数字斜率都更高，同时真实联合正确率仍下降 35.94 个百分点，95% 配对区间为 [−48.44, −23.44]。组级一阶正号不足以作为上线标准。它不约束真实前缀上正确 token 与 EOS 或错误 token 之间的有限竞争间隔。 [离线投影审计](MECHANISM.md) · [逐前缀间隔条件](THEORY.md)

## 目前可得的结论

同一个 Rank-1 方向能在参考轨迹的局部范围内推动多种正确决策。可部署的统一生成增益还要求有限幅度下的有利传输、生成后访问的前缀分布仍然受控，以及正确停止和正确续写在风险样本上都得到保护。本轮的模型和目标对照尚不能确定 Rank-1 的容量上限。下一项有区分力的比较是固定同一混合初始权重、学习率和参考，用真实生成轨迹同时约束提早停止与无效续写，再观察同题同深度下是否保住普通混合的 GSM8K 表现。

GSM8K 的联合正确采用结构阈值和严格最终数字，程序未验证数学推导。开发模型选择排除了 28 道与训练段落重合的 SQuAD 题，保留共同的 36 题，逐题档仍保存原始 64 题以供审计。正式测试在选型、评测配置、输入和权重指纹锁定后运行。 [复现说明](REPRODUCE.md)
