# 冻结顺序与主判据

模型固定在 Ouro-1.4B Base 的 574fa66。研究比较真实输入在同一权重、mask、位置下引发的计算。先导 n=24 和开发图谱 n=96 均只给操作代码提示、题目标识和候选内容。正确答案单独保存在评测文件。物理层和 Attention 头组按 K1→K2 对应层的真实激活变化冻结。保留所有有效 token。门控采用整个 MLP 的分布式 gate，而非单神经元选择。

开发互换用预先排序前 48 题。K1 接受 K2 成分，K2 接受 K1 成分，接受方物理层、真前缀和剩余预算固定。主要的操作性响应是去均值全词表浮点 logits 在原生两轮差向量上的有符号投影。预测对齐方向在开发批次决定。主分析同时保留首 token 并列和决定读出与完整候选的独立协议。未中心化词表回放作为工程诊断。

进入 48 写入筛选的路径须在两个供体方向同时胜过零、同剂量随机和位移位置对照。Attention 还须胜过其他头同剂量输出。14 个单侧配对比较用 Bonferroni 0.05/14 自举下界。其他层的实际交换单列为未配平对照。没有通过的路径仍作确认性失败范围核对，不以结构发现替代因果验证。

若路径通过，用预先固定的前 16 开发题遍历 48 条真实写入，按去除一次写入后下一轮候选因子的自然变化损失冻结一条写入。独立题先写冻结预测，再比较移除、同剂量扰动、实际其他写入及恢复对应的自然 Q、K、A 或 SwiGLU 因子。只有经匹配对照且在任务读出上有意义的移除和恢复，才支持跨轮中介。仅有对齐改善支持状态敏感性。完整 backup 调用、组和非有限数据保留。

独立确认包括未参与本轮开发的 96 ARC Train 题、96 OpenBookQA Train 题和 48 个新生成结构组。ARC 过去已被项目评分。OpenBookQA 排除 432 个历史记录、归一化重复题干或近邻。固定分母，不根据结果筛选。结构组内多个世界不作为独立题组。报告 K1→K2、K2→K3、K3→K4；正确性分层只在冻结后执行。自然生成、完整候选 token 平均/总 log-likelihood 和字母辅助各由单独程序评分。

离分布指标为干预后相对清洁原生的最大逐 token RMS 范数倍率。超两倍单列，全样本主结果保留。此诊断只识别大幅范数异常。候选几何、对比和论文范围不从成功子集事后重选。
