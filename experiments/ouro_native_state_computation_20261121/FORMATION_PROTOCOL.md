# 上游形成诊断

双向交换未过主归因门槛，因此不把受控组件互换用于证明答对的充分性/必要性。保留一个单独问题：真实 K1 写入是否形成已经在自然轨迹观察到的 K2 注意力图与门控变化。这是形成机制的诊断。它允许被独立否证，即使行为归因失败。

在同一物理层和提示下，从前 16 道无标签 ARC 开发题枚举 48 个实际残差写入。一次只去除一条真实分支输出，回放随后所有原生算子。以目标因子朝真实 K1→K2 差向量的投影损失中位数选一次。候选 Attention 层及 heads 和 MLP 层沿用既有冻结。独立样本限定为每自然任务族前 48，生成结构每族前 12。在运行任何对应写入干预前锁定开发来源、样本、代码和方向。

主要形成指标是编辑后自然因子损失，对比同剂量随机扰动、沿 token 位移的同剂量方向及其他层真实写入。单独将清洁中介放回去除写入状态，测量剩余真实计算中词表和任务条件性读出的恢复。再保留真写入，单独放入删除状态中的对应因子。测完 K1 写入→ K2 后，使用不变的候选在 OpenBookQA 同一独立组的 K2 写入→ K3 重测。任何效应都需要在报告中按全分母与不确定性解释。
