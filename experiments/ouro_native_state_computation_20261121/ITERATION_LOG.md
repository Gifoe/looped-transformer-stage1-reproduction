# 研究迭代

| 轮次 | 实际执行与决策 |
| --- | --- |
| 1 | 对齐固定模型。用 24 道先导、96 道无标签开发题做原生四轮图谱。在所有有效 token 的真实比例中冻结 L6 四个头和 L1 门控。 |
| 2 | 在固定 48 道开发题以原生等预算交换因子及内容。中心化全词表投影消除了公共 logit 平移，原始实现数据保留。两候选均未通过双向及匹配门槛。更改后的度量和检验在任何确认前锁定。 |
| 3 | 把行为归因和因子形成拆开。独立诊断在 16 道无标签开发题扫描全部 K1 真实写入，冻结两个候选生产者；在新的自然输入、结构和 K2→K3 上运行删除、匹配控制、实际中介恢复和反向替换。 |
| 4 | 在 96 ARC、96 OpenBookQA 和 48 个独立生成组确认主失败范围。两个自然任务各取固定 24 题用完整 teacher-forced 答案分数查互换效应，另用两跳同桥/异桥受体规则测试及配平方向核对。冻结的因果函数响应分析之外，没有训练控制器或改模型权重。 |

Astra 在第一轮结束后审核候选筛选与门槛。本轮全部实现和实验以 Sol 工作流执行。最终的独立科学审阅发生在工程验收后。
