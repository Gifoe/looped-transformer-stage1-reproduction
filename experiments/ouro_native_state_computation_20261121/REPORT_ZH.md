# Ouro-1.4B 的自然状态如何改变共享算子

## 结论

Ouro 的共享权重与循环调用本身保持不变。真实状态改变后，同一个算子对相同有限扰动给出不同方向和增益，说明变化超过了直接把不同状态送入 lm head。开发候选能改变下一轮内部计算，但两条互换都未通过双向、同剂量对照的判据。当前证据能定位部分自然计算变化的来源，尚不能把 K1 错误到深轮答对归因给某个可重复的路由或 gate 开关。

ARC-Challenge 的同 δ 响应 K1→K2 余弦 0.152，K3→K4 升至 0.867。K1→K2 完整候选纠正 17，回退 5；严格自由生成纠正 1，回退 0。OpenBookQA 的同 δ 响应 K1→K2 余弦 0.138，K3→K4 升至 0.814。K1→K2 完整候选纠正 6，回退 4；严格自由生成纠正 0，回退 0。

## 2. 信息积累、路由与答案边界能区分到什么程度

因子变化在投影及原生后置归一化前后均可见，直接运行有限扰动证明响应随状态而变。因子的互换不能单独和双向地复现原生行为。开发筛选按分量相对实际差的比例，抵消会抬高比例，所以只对冻结候选和剂量给出阴性结论。信息积累与决策边界依然是行为变化的竞争解释，H1、H2、H3 在本设计中并不互斥。

## 3. 哪些隐藏状态成分控制了变化

盲选全 token 比例在物理 L6 达最大，四个 0-based heads 为 `[1, 7, 11, 14]`。在 FP32 保存 RoPE 后 Q/K、V、softmax 后 A、A@V、实际输出投影和写入前后需用状态。先精确分解 Δ(AV) 为 ΔA·V₁、A₁·ΔV、ΔA·ΔV。输出投影是线性的，三项通过同一投影后仍相加。post-RMSNorm 另以单项替换和剩余量核算，剩余来自归一化非线性。L2 比例允许超出 1，项之间会抵消。

同样准则冻结物理 L1 的完整分布式 gate。投影前差为 ΔG⊙U₁ + G₁⊙ΔU + ΔG⊙ΔU，G=SiLU(gate_proj(Norm(h)))，Up 读取相同输入。down 投影与实际 post-attention 第二 norm 都保留。SiLU gate 是带符号连续乘子，符号变化也已记录。整层 gate 的结果不能分配给某个单独神经元。

## 4. 形成这些成分的前轮写入

独立形成诊断锁定 K1 的 `1/a_write` 和 `1/m_write` 两个实际写入，同一套冻结测试也执行 K2→K3。这两个来源是删除实验定位到的候选，报告与随机、位移、其他写入之间的配对效应；mediator-only、清洁恢复与删写入的实际组合都已记录。

## 6. 可以推广什么

在 ARC 和排除历史记录的 OpenBookQA 比较同一锁定候选，并在新生成表格/两跳结构检验受体规则预测。强主张需要读出、下游响应和任务行为同时复现。各协议、K2→K3/K3→K4 和对照详见对应附件。

## 7. 相对既有研究的增量

近邻已经在训练得到的图任务网络上对 Attention pattern 做干预，也已有 Ouro 的自然状态/注意力回拨与激活互换。这里的可复核增量是冻结自然样本上的 A/V 与 SwiGLU 全层精确分解，同一扰动的跨状态响应，以及既定门槛下向前追踪真实写入的反事实范围。现有结果支持在冻结 Ouro-1.4B 上的具体边界结论，无普适算法切换或隐藏语言推理链主张。[近邻核查](NOVELTY_AUDIT.md)
