# Preserve K2 attention and exchange first-operand values

Use frozen Ouro-1.4B Base in native FP32 eager/no cache, the fixed subtraction prompt and complete integer decoding. Freeze 40 development and 300 confirmation stems across 120 within-run distinct answer targets. Exhausted operand inventories are replaced from the seeded queue before inference. All operand pairs are absent from the checked historical ledgers. Select natural exact K1 +100 to K2 correct repairs prospectively. Match same-answer no-borrow receivers by the established two-margin protocol.

For each borrowing receiver B−A=y, donors share A'=A−d and use B+e or B−e. Positive e keeps their truth distinct from the predicted mixed B−A'. One donor flips borrowing, the other retains it. Donor B differs in both and is never used as the B source in the generated receiver output. The four required answers (receiver, +100 foil, mixture, opposed donor) are distinct, as is the second donor truth. No-borrow controls use A'=A+d and symmetric balanced B changes restricted to remain no-borrow. Numeric A magnitude d is matched, the edit direction differs. Both donor A fields precede B, so donor K2 V at A should be invariant to the donor B choice.

Use receiver boundary, opposed donor context or same-borrow donor context in K2: copy donor nonoperand states after the common pre-operand prefix from native K1, preserve all six receiver operand positions, and obtain the actual unedited attention weights A and V for that background in K2. Cross each background with native V, natural donor V at the three first-operand positions, or norm-matched shuffled displacement at those same positions. Replay that background's physical K2 attention probabilities on all queries from A onward, without re-estimating them from counterfactual states. Earlier queries cannot see the edited locations. At each layer keep B's three V vectors at their unedited receiving-background values in all edited arms. Other values and nonattention operations are computed by the actual shared layer. The shuffle preserves the norm of each K2 KV-head/token operand displacement and its projection on the original operand V, so resulting value norms also match. Verify unchanged replay and the invariance checks on a locked subset.

Reapply the same procedure for every generated token using only each branch's own emitted continuation and the two actual prompts. No candidate number is passed to the generation. Track exact y, y+100, B−A', both donor truths, other integers and parsing failures. Separately report native whole-donor predictions. In a fixed 24-repair diagnostic subset at the native pre-digit pivot, record state changes in the K2 layer-15 attention write, MLP and block output, and check A-source invariance across contexts and B-owner invariance across value arms.

Primary endpoint is the complete mixed integer. Composition requires at least eight mixed integers under each of the original- and opposed-context donor interventions and positive target-cluster paired 97.5% lower bounds against each corresponding shuffle. Compare the original-versus-opposed difference of these increments for contextual competition. A positive supported interaction must exclude zero; also report the same-borrow context as a same-A, symmetric-B control. To close a large-effect test require a one-sided exact 97.5% upper bound below 10% for the probability of any extra mixed response within an independent answer cluster relative to shuffle, separately per context, at complete cohort coverage. Do not infer equivalence from failure of significance. Continue to an independent key-value composition experiment if robust general operand composition is observed, with only that task's structural truth used for scoring. This arithmetic experiment cannot alone establish task-general reuse.
