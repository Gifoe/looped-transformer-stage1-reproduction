# Conditional independent lookup confirmation

Run only if the frozen arithmetic trial supports composition in both main contexts. Freeze 128 receiver/donor pairs on an independent four-key lookup task. Receiver and donor tables have nonoverlapping three-digit entries within each pair. They query distinct digit keys. The sole mixed endpoint is the value associated with the donor's key in the receiver's table. It differs from both complete native answers. The query key precedes the table, and is one token at a verified position. No model family or statistical threshold is tuned on lookup outcomes.

Run native K1 and K2 on both prompts. Retain the full native counts and only launch the intervention if at least 64 receivers answer correctly in K2. Analyze those native-correct receivers. Keep each K2 layer's actual receiving-prompt attention weights. At each step separately replace the query digit's V with its naturally computed donor V, or with the same radial and norm-matched shuffled displacement as in arithmetic. Retain every table digit V from the receiving prompt at each layer, and use the naturally recomputed remaining values. Decode complete numbers. Test the whole mixed endpoint against shuffle with a paired 97.5% answer-target interval and at least eight mixed hits from the genuine V. Record K1 accuracy, K2 accuracy, unchanged replay and erroneous whole-donor copying separately. This tests whether content recombination can transfer under the same operation, with one frozen checkpoint and controlled prompt.
