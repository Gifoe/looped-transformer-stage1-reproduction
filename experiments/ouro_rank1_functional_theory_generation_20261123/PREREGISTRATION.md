# Rank-one recurrent control · 选型和验收

参考提交 `e2b21c95c1e5ff37ac9be7d9cbc73d0aead8f26c`。单卡累计硬上限 28,800 秒，范围优先冻结 Ouro-1.4B Base。上一轮作业及其参考基线不复跑。新方法以已发布 Rank‑1 T1 的 4,096 参数为起点。控制时机和权重均可改动，任务标签、标准答案、未来状态均不得进入部署决策。

候选评分沿用旧 Rank‑1 T1 的模型哈希、checkpoint、计分入口和输入协议。历史逐题记录直接继承，同一入口用于新候选评分。新生成模块与候选路径独立，按显式调用模式选择，生成规则对各数据集相同，允许依赖 Loop 预算和自身生成步。若提出同一权重适用两种模式，必须另外确认该版本完整候选指标。

第 1 轮在 OpenBookQA 官方 Validation（500）与 ARC Train 按 ID 哈希固定的 256 题开发组测量时机和剂量。ARC Validation 299 和 OpenBookQA Test 500 只在冻结后用于最终确认，ARC Validation 是已在旧研究使用过的协议集合。第 2 轮可在其余 ARC Train 和实际模型自身前缀上轻量训练，比较当前 Rank‑1 T2、对输出格式阶段有自回归监督的 Rank‑1、稳定性损失所约束的 Rank‑1。开发集冻结后仅提交一个跨数据集方法，或预定各深度回退原 T1 的同一控制策略。开发数据集的正确率和有效率均不得低于原 T1，至少有一个目标深度提升；从合格方法最大化跨开发集的最小正确率增量，再按平均增量和方案简洁性排序。完整确认中每个数据集、预算和主指标相对原部署参考的净正确数必须非负。另报同协议历史最强基线。历史无 Rank‑1 记录的生成协议先测同 checkpoint 自身对照和历史最强方法。格式合法和内容变化分开，不由一个数据集的改善抵消另一个的下降。主方法确定后测试结果只作验收，不用于调参或替换方法。样本外逐题不退化没有由实验建立的绝对保证，报告逐题救回退化和区间。

## 事前预测

固定已冻结的接收上下文与后缀，将轴 $v$ 的有限输出签名定义为完整候选中心化分数差 $S_x(v,a,m)$。原生前一圈状态差与 Rank‑1 的签名将在同题同剂量同后缀与等范数旋转相比。若所谓“原生计算加速”成立，较深/正确的原生更新与 Rank‑1 应有同向功能签名，且交叉验证提取的原生敏感轴在独立题上可复现部分有限效用。若只改变排序或使用同一后缀，结论只到任务监督选出的控制轴。原生有限剂量预测用独立数据检验，比较小剂量响应、状态范数和有限轨迹的拟合，按题统计。几何对齐与任务效用分别判断。

对贪心前缀策略 $\pi$ 和原 T1 策略 $\pi_0$，若两者共享确定性停止协议，且状态包括影响后续的缓存，那么 $J(\pi)-J(\pi_0)=\mathbb E_{s\sim\pi}\sum_t[V_0(s_{t+1})-V_0(s_t)]$。有限和望远镜相消，$V_0$ 是回到原策略后的最终严格效用。某步两种策略输出同一 token 且状态相同，则单步贡献为零。这个命题预测同前缀分叉后回到原策略可以检验早期控制对内容的独立效用。工作幅度的局部 Jacobian/Hessian 误差不影响等式。只在从当前状态可预测的组中验证幅度或时机，单次成绩变化不作普遍因果主张。

内容机制优先做匹配事实反转，要求直接输出内容词，并在已知晚层 Value 只回复目标源行，匹配无关行、等范数方向和原生恢复。双向整答、路径移除及路径恢复均须获得按匹配组统计的证据，才把结论推进到生成内容计算。只改善分数或合法格式按实际端点报告。扩展模型和七项追加复评取决于首要性能验收及剩余预算。
