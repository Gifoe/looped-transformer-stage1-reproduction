# Rank‑1 的内容路径检验

在 128 组两跳事实反转题上，冻结的 Rank‑1 T1 将原始整答金标分差从 1.90381 提高到 6.90331，均值差 +4.99950，校正区间 [3.58196, 6.41192]。但在开发集锁定的第 4 轮最后一个物理层，交换目标源与交换无关源造成的分差损失接近，Rank‑1 对这一位置差的交互为 +0.00616，校正区间 [−0.01700, 0.03109]。自由生成只正确输出 9/64，相比原生的 3/64 多 6 个，所有失败都在首步输出换行。此次检验未通过预注册的内容路径确认。 [预注册](PREREGISTRATION.md) · [候选汇总](results/B_CONTENT_PATH/heldout/SUMMARY.json) · [生成汇总](results/B_CONTENT_PATH/generation/SUMMARY.json)

## 事实反转、路径与开发锁定

- 两类任务分别查询「货站 → 库位 → 双词口令」和「旅客 → 班车 → 双词口令」。模型读到四条第一跳映射和四条终点事实，以及要求直接输出双词口令的查询。每题的目标源和一条结构无关源在同一世界中含有相同口令，以控制源端词汇。成对反转在原位置对调两个口令，保留词频、第一跳、查询、行顺序及候选词集合，金标随查询对应事实翻转。提示不展示答案标签或候选列表。
- 开发集 24 对、留出集 128 对，两个子集的实体和候选词配对均不重叠，各自两类题等权。一对由两个反转方向组成，对内两个世界的源位置和分词长度相同。两个口令各为两个 token，三个源位置覆盖口令词与其后的句末标点。生成子集预先按种子分两类各取 16 对，共 64 个提示。
- 使用历史冻结的 4,096 参数 Rank‑1 T1 和原生 Ouro-1.4B Base，均实际运行 K4。Rank‑1 在第 3 轮输出归一化之前写到各答案预测位置，使用原训练的 0.45 RMS 上限。方向对照对真实 Rank‑1 更新做固定种子的带符号坐标置换。自然状态对照取相同 token 的原生第 3 轮减第 2 轮原始残差方向，并逐位置对齐 Rank‑1 的实际申请范数。留出集三个方向的 BF16 实际更新 RMS 均值为 0.21384、0.21385、0.21384。

在选定层只修改第一个答案预测位置的 Attention 输出投影前向量。对源位置集合 $S$，交换向量按头计算 $\sum_{j\in S}a_j(V_j^{\mathrm{donor}}-V_j^{\mathrm{receiver}})$，其中 $a_j$ 是从受体运行重建的 Attention 权重，供体来自同组的反转世界。四个组合是原生或 Rank‑1 背景各自交换目标或无关源。各受体的四个申请向量缩放到其中最小的 RMS。反向恢复将选定 span 的 Rank‑1 读取贡献替成该世界的原生贡献，另做目标与无关精确恢复向量等 RMS 的版本。恢复使用相同受体，供体交换使用相反事实世界。其余位置与分支继续运行，Rank‑1 直接编辑逐位保持相同。 [实现](b_content_path.py)

## 留出集的交换与恢复

Rank‑1 目标与无关交换均降低 margin，相对未交换的 Rank‑1 分别为 −0.46783 [−0.52900, −0.41005] 和 −0.48437 [−0.55550, −0.41899]（名义 95%）。预期目标交换比无关交换更损害金标分差，这一预测未通过，两类题的点估计也均为反向（−0.02552、−0.00757）。原生背景同样出现相近的目标与无关交换损失。这里观察到响应可被反转世界的来源值移动，来源角色的选择性缺少支持。

两种精确恢复都提高 margin，相对未恢复的 Rank‑1 分别为 +0.25281 [0.18255, 0.32676] 和 +0.25912 [0.21705, 0.30748]。这与「目标原生恢复应削弱 Rank‑1 获益」的预测方向相反。精确恢复的目标／无关实际 RMS 为 0.01019／0.00747，等幅恢复同为约 0.005527。等幅后出现显著的目标／无关 margin 差，两个操作自身仍提高 margin（+0.12208、+0.19644），双向整答差为 +1.56 pp、校正区间 [0.00, 4.69]。等幅结果表明局部读取贡献对连续分差有不同影响，其方向和离散端点未建立预设的路径依赖。所有源操作的二词 margin 效应与首 token margin 效应在记录精度下相同。由于编辑位于最后物理层、仅发生于首个答案预测位置，第二词在同次 teacher-forced 前向中没有再经过一次消费该位置的 Attention。

留出集重建读取向量相对实际 SDPA 读取的最大 RMS 误差为原生 0.2272%、Rank‑1 0.2043%，低于 2% 技术阈值。交换四组的共同申请 RMS 中位数为 0.009064，逐受体把四组的已实现 RMS 极差除以申请 RMS，BF16 后中位为 0.0913%、最大为 2.07%。记录中没有零剂量。第 23 层目标 span 的平均读取权重由原生 2.976% 升至 Rank‑1 3.689%，无关 span 从 2.270% 降至 2.126%。权重变化与来源角色相关，但与受控交换和恢复的检验结果并列后，证据仍不足以确认目标来源驱动了 Rank‑1 纠错。 [逐题候选分数](results/B_CONTENT_PATH/heldout/PREDICTIONS.jsonl) · [读取与范数审计](results/B_CONTENT_PATH/heldout/INTERVENTION_AUDIT.json)

## 真实双词生成

全词表逐 token 贪心解码，每条最多六个新 token，遇换行或特殊 token 停止。来源操作只作用于首个答案步骤。严格匹配要求整段文本为其中一个完整双词口令，允许首尾空白和句点。宽松匹配允许口令后的额外文本。在本批样本中严格、宽松和有效输出的计数一致。

| 生成条件 | 有效且严格正确（/64） | 反转两侧都严格正确（/32） |
| --- | ---: | ---: |
| 原生 | 3 | 0 |
| Rank‑1 | 9 | 2 |
| 等范数旋转方向 | 0 | 0 |
| 等范数自然轮间方向 | 0 | 0 |
| 原生，目标／无关交换 | 0／0 | 0／0 |
| Rank‑1，目标／无关交换 | 8／7 | 2／2 |
| Rank‑1，目标／无关原生恢复 | 9／10 | 1／2 |
| Rank‑1，目标／无关等范数恢复 | 9／10 | 2／2 |

Rank‑1 相对原生逐题从空白恢复 8 条，另有 2 条从正确退回空白。两种方法同时正确的只有 1 条。12 个条件共 768 条实际生成，65 条合法口令全部正确，703 条无效输出全部是首 token 为换行的字面空行。没有模型生成有效但错误的候选口令。Rank‑1 相对原生的严格双向正确率差为 +6.25 pp，校正区间 [0.00, 18.75]。交换的 Rank‑1 × 位置交互为 0，组内统计也无非零对；精确恢复的位置差为 +3.13 pp [0.00, 12.50]，等幅恢复位置差为 0。这一批观测中的整体正确率变化来自输出完整口令的覆盖变化。原始输出保留换行，读者可核对这种首步退出。地板效应限制了本生成协议区分两条来源的能力。 [逐题生成文本](results/B_CONTENT_PATH/generation/PREDICTIONS.jsonl) · [完整生成对照](results/B_CONTENT_PATH/generation/SUMMARY.json)

## 结论与适用范围

此次实验在同一题、同一位置比较两种真实来源值，区分了 Rank‑1 的整体分差增益与可定位的来源角色效应。Rank‑1 明显改变整答分差和末轮读取权重；单一锁定层的目标交换对照、原生恢复方向和双向自由生成未能共同确认「Rank‑1 依靠该目标源纠错」。实验对同词汇的目标／无关来源控制得很严格，两个 span 本身重复同一个有效口令，模型可能从另一位置及更早层获得同一内容，且当前操作只覆盖末轮一个层的首个预测位置。这些结果不能外推到其他层、后续自回归时点、独立 Query/Key 或特定 MLP 功能。上一轮对整段 Attention／V／MLP 的因果结果仍属于其原有范围。当前受控路径没有建立预注册要求的可重复内容生成因果证据。 [旧分支与路径结果](https://github.com/Gifoe/looped-transformer-stage1-reproduction/blob/e2b21c95c1e5ff37ac9be7d9cbc73d0aead8f26c/experiments/ouro_functional_controllability_20261123/EXPERIMENT_C.md)

GPU 账本记录本实验成功占用单卡 RTX 4090 D 178 秒（约 0.0494 GPU 小时）。开发筛选 54 次、留出排序 192 次、自由生成 164 次，合计 410 次 K4 前向、1,640 批轮和 1,529,073 个补齐输入位置。CPU 独立审计核对了源码 SHA、开发锁定规则、开发／留出实体与代码配对不重叠、源 token 位置、完整逐题记录和每批成本。候选和生成汇总都由逐题原始记录重算并逐项匹配。运行清单、开发与留出题面、每阶段的成本和各批次数据都随完整原始证据发布。 [GPU 账本](GPU_LEDGER.tsv) · [完整原始证据](results/B_CONTENT_PATH/RAW_EVIDENCE.tar.gz)
