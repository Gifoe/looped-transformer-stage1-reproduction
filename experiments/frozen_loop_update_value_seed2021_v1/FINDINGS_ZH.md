# 冻结循环模型更新价值：研究结论

**结论：当前控制器 No-Go，尚不支持完整方法论文。** 这不是“所有中间信号都无效”的结论：新增信号质量头在 PIQA 上具有一定排序信息，但没有转化为可靠的准确率收益。

## 完整测试结果

主指标为官方评测框架支持的 `acc_norm`，全候选答案似然一致计分，均为零样本。SciQ 保留官方 support；PIQA 在推理前排除36个重复问题，使用1802个合格样本。

| 方法 | SciQ /1000 | PIQA /1802 |
|---|---:|---:|
| Original Ouro | 946（94.60%） | 1423（78.97%） |
| Fixed LoopCD | 953（95.30%） | 1422（78.91%） |
| Adaptive LoopCD | 951（95.10%） | 1425（79.08%） |
| 输入损失代理 | 947（94.70%） | 1411（78.30%） |
| 新增信号正确率头 | 951（95.10%） | 1426（79.13%） |
| 组合正确率头 | 949（94.90%） | 1425（79.08%） |
| 组合 log-weight 头（未被验证集选中） | 951（95.10%） | 1430（79.36%） |
| 双格式集成 | 947（94.70%） | 1428（79.25%） |
| 标签 Oracle 上界 | 955（95.50%） | 1490（82.69%） |

## 为什么不能判定成功

新增信号正确率头在 PIQA 上只净增加1题：7次纠错、6次损害，+0.055 pp，95% CI [-0.333, 0.444] pp。六个头中最高的 PIQA 点估计净增5题，但其95% CI仍跨零，而且该头未通过验证选择门槛。不能事后挑选它宣布成功。

验证集800题中，最佳训练自由规则净增5题；最佳质量头净增4题，均未通过预设的多重比较校正。因此最终策略在测试前锁定为 Adaptive。所有其他方法的最终结果属于诊断。

## 有限的正结果与边界

新增信号正确率头的 PIQA AUC：keep=0.638 (40 beneficial/42 harmful events), forward=0.670 (19 beneficial/22 harmful events), rollback=0.595 (55 beneficial/67 harmful events)。这些数字使用非零收益事件，不能等同于整体分类准确率或可部署收益。配对 AUC 差值及置信区间见统计附录；部分区间仍包含机会水平。

SciQ 中 Adaptive 已达95.1%，四动作 Oracle 仅能再净纠正4题；这个动作集合留给控制器的空间很小。PIQA 的 Oracle 尚有65题空间，但当前选择器没有稳定获取这些收益。

SciQ 保留 support 相比移除 support：91次纠错、4次损害，净增87题，+8.70 pp，95% CI [6.9, 10.6] pp。这支持“现有证据有用”，不证明额外证据是任何成功控制器的必要条件，也不等价于复现 CoDR。

## 监督、成本与下一步边界

只训练96/345/435参数的岭回归头，Ouro骨干完全冻结；3200训练题、一个固定训练规模，未建立“最小充分监督量”。没有通过移动阈值、翻转符号或扩大模型来追逐最终测试结果。

新增计费：**1.6964 GPU小时**；从历史起点加总：**11.7701 GPU小时**。费用包含加载、失败任务和恢复边界重算。回退发生在四轮计算完成后，不节省循环计算。

当前实现的几何特征、收益监督和动作定义分别与TAPS、TaH2、LoopCD有明显重叠；尚无足够的机制新颖性及匹配计算量的准确率收益。停止本轮方法扩展，不启动条件未满足的Qwen迁移。任何后续校准或新机制都应另设开发数据和新的确认集。
