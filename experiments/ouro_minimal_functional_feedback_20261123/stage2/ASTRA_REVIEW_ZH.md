# Astra 阶段一复核

保留 `linear8_t1` 为唯一锁定主模型。它是 32,768 参数限额内的 ARC Validation 八端点综合优胜者，在 ARC Test 和 OpenBookQA Test 的 K2–K4 共 12 个候选端点上高于原六路反馈。OpenBookQA 贪心生成合计正确率下降 2.20 个百分点，95% 区间为 [−3.93, −0.47]，仍在预定 5 点容差内。ARC 生成数据为 Validation 299 题。

证据支持跨题可复用、经原生后缀起效的方向。在最后提示位置，第一未中心化主成分占单位更新能量的至少 99.918%。等范数换题在 K2–K4 的归一化正确数只改变 +1、0、−1；学习方向相对旋转方向的后缀开放×钳制差中差为 +20.40、+19.40、+12.04 pp。结论限于经过干预的位置、预算和评测任务。Attention 与 MLP 的各自中介贡献和表示内容尚待定位。

后续科学问题是本题幅度是否有独立作用。固定从 ARC Train 提取的共享方向，比较本题幅度、按深度和位置匹配后跨题置换幅度、固定幅度，并预先锁定新任务上的完整候选评分和贪心生成非劣效界。现有 4,096 参数秩一及 2,048 参数固定上限仅完成 ARC Validation 诊断。
