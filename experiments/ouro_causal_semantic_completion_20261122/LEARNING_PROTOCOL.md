# Current-state deployment and parameter-matched controls

Use the Oracle confirmation gate before optimizing an operator. All encoders and projections are fitted on training rows. Read two low positions per operand, a pooled rule span, a context pool and the response marker or its current leading whitespace. Four feature groups use PCA width 24. Path A reads the physical layer-15 input. Path B uses the normalized final K1 state and writes into the selected location in K2.

Fit the linear, bilinear and gated families at ranks 16, 32, and 64. Target the selected Oracle update in exact naturally repaired training cases and a zero update for other training cases to preserve stable outputs. Include a latent coordinate loss and match pairwise update similarities within same-target different-operand cases. Compare variants by unrestricted development exact output, with lower parameter count resolving ties. Refine the selected model using the actual frozen downstream loss at the first trained answer-bearing token while retaining update regression. Freeze the deployment site and gain using development, comparing residual, attention, and MLP insertion. The resulting deploy function constructs no future state, donor state, target labels, forced answers or teacher tokens.

The equal-parameter answer-only baseline uses the same topology, features, budget and allowed gain/sites. It learns from downstream answer supervision from a random orthonormal decoder initialization. The state-distillation baseline fits the native K2-minus-K1 layer-boundary state change at the same sites and budget. Both share the actual autoregressive runtime. Record raw integer answers, paired net accuracy, exact rescue, degradation and batch-one end-to-end no-cache latency. Require a positive borrow holdout grouped lower bound against native, a positive point estimate against both trainable controls and nonnegative borrow-format-shift and carry holdout net gains before using compute for ARC.
