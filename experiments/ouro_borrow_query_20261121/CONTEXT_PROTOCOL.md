# Partition the natural layer input into readout and earlier context

This secondary assay tests where the native cross-loop state supports a correction even when a query edit alone does not. For a naturally repaired case and its matched no-borrow counterpart, use the same verified greedy prefix and exact first-divergence actuation as the query experiment. A fixed physical layer input can be decomposed into the readout token and its earlier causal context. Swap each subset separately from the opposite loop, and jointly. Inputs to all later shared layers remain native to the resulting hybrid. The other loop's whole input at that layer must reproduce its native trajectory exactly, independently of current iteration bookkeeping. No training or selected token completions are used.

In discovery inspect only layer inputs 1, 5, 9, 13, 14 and 17, all before the late readout. On naturally corrected examples score exact activation interchanges by the smaller of the two correctly signed mean true-minus-foil margin changes. Freeze one site for context-only and one for readout-only, each using the earliest tie. Discovery also records the difference between the joint margin effect and the sum of the two separate effects. Interactions in diagnostic margins are distinct from effects on fully generated integers.

Confirmation makes the selected two substitutions, with their own matched random geometric replacements at every intervened token, and a full-input positive control at the selected context layer. For each, test both directions and retain exact natural matched no-borrow controls. On each partial substitution the other input subset remains bitwise equal to native. Report exact twice-opposite outcomes (K1 correct and K2 exact foil), paired uncertainty clustered by target, and harmful switches on matched safe controls. A positive context-only result must have at least eight exact joint switches and a paired lower 97.5% bound above zero. The same statistical criterion is used for readout-only. An exact readout-only success transfers a native internal state and can copy a candidate already formed. A context-only success implicates information supplied to the unchanged readout by earlier prompt positions without isolating a particular attention head. Whole-input replay verifies the intervention and is not an independent semantic test.
