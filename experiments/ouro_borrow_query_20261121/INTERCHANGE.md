# Query, readout writes, and controlled free decoding

For each naturally repaired case compare exact token sequences of the two original greedy runs. Use the common generated prefix just before their first divergent token (verified to distinguish the two intended integers). For safe matched controls use the common prefix of the theoretical correct and foil continuations; classify intervention unreachable in either native loop if that continuation prefix is not naturally emitted. Model input is always the unchanged prompt plus an actually produced prefix. Native re-decodes verify exact token replay and full K2 equals resumed K2. A strictly equivalent prefix-replay implementation may reuse the verified identical native prefix and, if the patched token stays unchanged, its unchanged native suffix. New continuations after a changed token use full-vocabulary native greedy decoding with no further actuator.

Both recipient directions are independent physical tests. Patch after rotary position embedding for Q, before attention softmax, at the actual readout position of a single physical layer and head. Keep that layer's recipient keys, values and residual input. Downstream execution remains native. Use the other loop's natural Q at the same tokens and position. A matched Q control rotates the donor vector's component orthogonal to the recipient, preserving replacement vector norm and angle to recipient. An unrelated-head control uses the head with least discovery evidence at the same layer and matches the signed parallel and orthogonal components of the selected head's displacement norm around its own recipient direction, using its own natural cross-loop orthogonal direction. A graph-cut control keeps the query intervention but restores the recipient attention residual write at that position. It must return exactly the native output because this is the only causal route of that query. This verifies the physical target and is not an independent test of computational specificity.

Discovery uses matched naturally repaired cases only. Score at the targeted token with the correct-minus-foil logit margin. Rank the 24 layers by the smaller of mean margin increase for K1 and mean margin decrease for K2 under the all-head Q interchange in that layer. Break ties by earliest layer. Within the winner screen all 16 query heads individually by the same rule. Freeze one highest and one lowest other head. Separately screen each of the 48 normalized attention/MLP residual writes with the same criterion. Freeze a single strongest write, ties by earliest layer then attention. Do not use held-out observations for ranking. Report all scores, including negative means. Compare the wider locked query arms (all heads of favored layer and all readout queries of every layer) to versions using equally sized matched perturbations at each position/head.

Confirmation uses all matched naturally repaired cases and their safe counterparts. Primary exact success on a repair requires both the K1 recipient completing the correct integer and the K2 recipient completing the very same original +100 foil. Report each direction separately, original exact accuracy, all outputs and safe harm. Target-clustered paired bootstrap comparisons use 20,000 resamples. Predeclared support for the selected head requires at least 8 exact two-way cases across at least 6 target bins, with positive 95% lower endpoints versus both controls. The wider Q and residual-write comparisons are secondary and use 97.5% intervals against their own same-support geometry. Expose all failures and controls. When the selected query does not suffice, the evidence constrains the tested physical paths. A favorable decoded result does not by itself determine the algorithm within the block.
