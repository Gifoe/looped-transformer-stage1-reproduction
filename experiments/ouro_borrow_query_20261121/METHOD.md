# The boundary between routing and state

For a confirmed natural repair, both frozen-model loops process the same prompt and freely generate an identical prefix. The next token is the first difference between exact integers y+100 and y. At the Q intervention the recipient input x is unmodified. A single head's query becomes its other-loop native q at the same position and rotary phase. The head then uses recipient projections and native mask in softmax(q K^T / sqrt(d)) V. Later replacements in the all-query-stack arm are also post-projection and leave each receiving layer's actual keys and values to its native execution. The restored attention residual write in the graph cut closes the manipulated query's local route.

Autoregressive decoding replays the common prefix only after the actual native sequence has been independently regenerated. Modifications apply at a single step. If the pivot token is unchanged, the native suffix is unchanged by deterministic no-cache decoding. If the pivot token changes, all subsequent tokens are emitted anew using the model and the actual generated prefix. Thus a corrected first digit or continuous preference alone is insufficient.

For the layer-input experiment, write X=(C,r) for the earlier state sequence and readout state at a fixed physical layer. The same frozen tail T processes the two natural instances X_1 and X_2. The separately intervened T(C_1,r_2) and T(C_2,r_1) measure different routes of influence. Whole-input substitution replays the other loop's native tail exactly. A finite interaction contrast for a diagnostic margin m is

```text
I = m(T(C2,r2)) - m(T(C2,r1)) - m(T(C1,r2)) + m(T(C1,r1)).
```

This is directional and representation-dependent. Exact complete output switching under the two partial swaps, compared against geometric controls, supplies a separate causal test. Candidate scoring uses the first divergent token only in discovery. Both loops are evaluated independently on held-out natural repairs, and matched arithmetic controls retain the same true and foil integers.

The borrow signature is a behavioral correspondence derived by writing each operand as 100h+l. Keeping the correct remainder while omitting 1 from h_B−h_A when l_B<l_A gives y+100. These tests target that exact error and preserve other errors in the denominators. They do not identify a general subtraction algorithm.
