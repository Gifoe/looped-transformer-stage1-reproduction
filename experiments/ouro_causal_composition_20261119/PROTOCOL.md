# Frozen causal composition protocol

Use the corrected 3,000-group parent manifest and frozen Ouro-1.4B Base. For the old cohorts, fit and discovery have 300 and 100 groups per task. Capture all four native worlds in all four legacy splits. The old 300/300 confirmation/structural groups are retrospective evidence. A hash-defined 60+60 of them receive the new factorial edits. For each task generate 160 new groups with seed and emitted answer-slot permutation independent of state, output and effect. The independent set has 80 new compositions in familiar structures, 40 family-2 compositions and 40 extended family-2 compositions with an additional functional hop. Familiar and structural independent groups differ from fit in queried names for relation/logic and in intermediate value ranges for arithmetic. This design does not independently identify the effects of depth, value range, and syntax.

The one primary intervention site is native K1 post-loop normalization. On the same recipient r, copy source tokens from x and map tokens from y. Verify that the donor changes only the designated prompt factor and all roles/positions/candidate tokens align. The K1 source span of a relation item includes both payload and binding tokens. Source/map edit masks are disjoint; verify the exact pre-K2 additivity of the full edited boundary. Use three independently propagated matched random arms, an irrelevant-token source edit crossed with the matching map, and a map from the mismatched d context crossed with matching source. Controls are measured on a hash-defined quarter of discovery and independent groups. Physical patterns keep the unedited recipient, including the original query and options. Mapping donor states still contain contextual information from K1. A physical edit therefore tests the response to a block of state, without identifying a single purely semantic coordinate.

Save complete K1 token states, recipient-token IDs, aligned roles and explicit valid masks, native K2 full-width role means, and all K1–K4 candidate scores. For Loop×Layer attribution use one fixed 32D orthogonal projection and identical role positions across all arms. Calculate the factorial difference before taking any norm. Distinguish natural interaction, where input prompts differ, from physical interaction, where the exact pre-K2 edit is additive. Compare norms and signed semantic and output effects.

Predict full-width five-role K2 changes through fixed equal-width input encoders. Both use the same 64D orthogonal projected channels. The Region-Mean encoder uses the same weights for every valid token. The Token-Aware encoder uses four shared masked pooling heads with position, correct-token recurrence elsewhere among roles and bridge-state affinity. It uses aligned recipient token IDs, never donor text or a semantic label. The fitting of the response coefficients learns how to combine these moments. Compare zero, direct full-width ridge, 32-rank linear, state-conditioned additive ridge and a state-conditioned ridge with one 16×16 bilinear feature. Use the same training groups and six training examples per group: three forward natural differences for all estimators, plus three reverse natural differences for Natural-only or the three true forward physical responses for Natural+Intervention. Hyperparameters for natural-only models see natural discovery responses only. All learners use fit groups only for weights, scalers and label decoders. The naturally observed absolute K2 and its update share the same error when the same K1 is provided.

Advance only if a single frozen supervised model, chosen before reading independent responses, achieves at least 15% relative reduction in mean downstream response MSE versus every simple baseline on fresh structures. Require positive paired group-bootstrap lower bounds for these contrasts on both fresh cohorts. Also require independent improvement on the true factorial difference, the intermediate and final composition probe response, and K4 answer-margin response beyond the strongest simple baseline on fresh structures. Geometry and diagnostic checks are simultaneous criteria. Use 6,000 unstratified group bootstrap resamples within each split, no pooling of different cohorts. Probe and answer evaluation use the real clean K2 anchor and are labeled as such. Actual K3/K4 scores are original native outcomes. A lightweight fit-only diagnostic tests K4 margin prediction from the K2 change, without a claimed native rollout. A response model that predicts region means cannot be used to inject a complete K2 boundary.

If the gate fails, stop before a learned chain, full benchmarks and cross-scale validation. Preserve all seed, model and evaluation artifacts. Keep the full-token archives on the compute server and release their checksums, labels and all group-level metrics as reproducible artifacts.
