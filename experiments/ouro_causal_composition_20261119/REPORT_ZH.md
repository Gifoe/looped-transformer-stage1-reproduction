# Ouro-1.4B 的来源×映射因果组合

**K2 已产生非加性隐藏态响应，有符号答案交互从 K3 开始稳定出现。** 在 240 个结构留出组上，真实源区与映射区联合替换产生的 K4 答案 margin 交互为 **+0.268、+0.398、+0.529 nats**（关系、逻辑、算术）。联合替换本身的平均答案优势均未超过 clean。等剂量对照与独立探针表明，不能把交互范数或正的 margin 差分直接解释为模型已经得到正确组合结果。外部代理没有超过最佳简单基线，三个任务均未通过独立推进判据。

## 1. 执行与冻结

运行于单张 RTX 4090。模型是固定 ByteDance/Ouro-1.4B Base 修订 574fa66，BF16、原生循环、SDPA、无 KV cache，权重保持冻结。继承已纠正选项顺序的 3,000 组。正式采集包括 **3,480 组、13,920 个自然世界**，以及 **2,040 组的 6,120 个真实 S/M/SM 干预**。另在 205 个按 ID 哈希预选的组采集 1,435 个对照干预和 205 个无关自然供体。共 21,680 次正式前向。开发采集最长单任务约 609 秒，新组最长约 160 秒。三个任务在同一设备上并发；这两个数字不相加到各进程累计时间。

| 阶段 | 每类任务组数 | 新测物理组合 |
|---|---:|---:|
| 原有 fit / discovery | 300 / 100 | 300 / 100 |
| 原有 confirmation / transfer，作回顾复核 | 300 / 300 | 60 / 60 |
| 新独立熟悉结构 / 新独立结构留出 | 80 / 80 | 80 / 80 |

独立组去重涉及 3,000 组纠正清单和前序三份清单的语义签名。每种任务新组都含 80 个熟悉结构但新实体或数值、40 个旧训练未见的 family 2、40 个额外功能步骤的 family 2。关系增加地理别名跳，逻辑增加徽章规则，算术把后段净移动拆成两步。关系和逻辑使用未参与拟合的人名，算术基数在 34–67。额外步骤组同时改变句式，结果不可分解为纯深度效应。新题选项排列独立于语义生成。独立采集在冻结模型、检查点、指标和代码散列后开始，时间记录为北京时间 2026-11-19 20:22:14。[生成审计](data/generation.json) · [冻结记录](final_freeze.sha256) · [执行审计](results/execution_audit.json)

## 2. 双因素干预在何处改变表示

自然四世界是 r（00）、x（10）、y（01）、d（11）。物理组合以 r 为接收方，在 K1 归一化输出用 x 替换源区，用 y 替换映射区。源区包含关系题中被换的绑定和载荷 token。供受体的分词位置、候选 token、语义因子与区域掩码逐组验证。联合条件在完整 K1 边界与两个互斥编辑严格可加。自替换和完整边界替换的 K1–K4 logits 逐位复现。全部测量均使用未改动参数的 Ouro 推进到 K4。

在相同角色位置先计算 I = H11 − H10 − H01 + H00，再计算一套共享 32D 投影下的 RMS。结构留出中，**自然读出区在 K1 末已非零**，约 0.0165、0.0167、0.0190。物理编辑的 K1 边界交互为零，K2 读出末变为 0.0205、0.0202、0.0238，K4 为 0.0572、0.0572、0.0735。说明从可加的输入出发，Ouro 后续计算产生了形态上可测的非加性效应；自然数据则无法说明组合第一次发生在 K2。

匹配对照包括逐区配幅随机方向、无关 token 改动和来自不同源上下文的映射供体。新结构中，关系读出区 K2 的匹配语义交互还比随机小 0.00455 [−0.00836, −0.00131]。逻辑与算术的相同差值区间均跨零。算术映射区的真实交互高于无关对照 0.0121 [0.0063, 0.0191]，与随机的差值区间跨零。因此范数只能定位传播与非线性，不能单独确认计算内容。[Loop×Layer 图](results/figures/02_interaction_by_loop_and_layer.pdf) · [配对对照](results/interaction_controls.csv)

## 3. 2×2 表示 × 训练数据

输入来自实际完整 token 状态。Region-Mean 直接按角色掩码平均，Token-Aware 用相同 64 个投影通道和共享掩码汇总，加入相对位置、同 token 复现和桥接状态相似度。两个模型输入宽度、响应回归结构、训练组数以及每组训练条数一致。所有模型保留三条正向自然差分。自然训练再用对应三条反向自然差分，混合训练用三条真实编辑差分取代它们。既有 fit 只训练一次，discovery 筛选正则强度。全坐标岭回归直接读取 2,048D 角色池化基础特征。双线性模型使用 S×M 的 16×16 特征，和普通秩 32、状态条件化的加性响应及零响应对照并列。

全坐标 Ridge 在熟悉结构新组上自然 K2 MSE 为 0.209、0.226、0.247，恒等为 3.602、4.300、6.519。在结构留出组上变为 2.322、0.758、2.775。自然状态和更新量的 MSE 数字相同，因为二者都减去同一个实测 K1。Token-Aware 的自然 Ridge 在结构留出上只有算术略低于等容量的 Region-Mean Ridge（4.188 vs 4.247），关系和逻辑较高。

以下是 80 个结构留出组上的 2×2 联合响应 MSE。各区域由 fit 的自然 K2 RMS 缩放，误差在映射、查询、读出坐标上平均。组级区间来自 6,000 次配对重抽样。

| 任务 | A · 均值自然 | B · 均值混合 | C · Token 自然 | D · Token 混合 | D 相对 C 的误差下降及 95% CI |
|---|---:|---:|---:|---:|---|
| 关系 | 0.12652 | 0.11894 | 0.12782 | 0.12026 | +5.91% [4.04%, 7.92%] |
| 逻辑 | 0.10632 | 0.09161 | 0.10646 | 0.09176 | +13.81% [10.83%, 16.71%] |
| 算术 | 0.21582 | 0.10594 | 0.22383 | 0.10668 | +52.34% [49.02%, 55.60%] |

改用真实干预监督的收益大于改变这套低维 token 汇总的收益。D 对 B 的联合响应误差下降为 −1.11%、−0.16%、−0.70%。D 对 C 的**独立交互**误差在关系、逻辑分别增大 37.0% 和 62.4%，算术降低 38.4%。所以整体联合响应的收益没有自动延伸到交互预测。算术的双线性模型虽比同架构自然拟合好，仍无法达到最强简单基线。原始档案保留所有 token，本次代理最终只使用有限的掩码统计，结果不能排除更完整的 token 结构有用。[2×2 图](results/figures/03_representation_by_supervision.pdf) · [配对估计](results/factorial_2x2_comparisons.csv)

## 4. 独立反事实与语义结果

探索集在三个任务均选择了 Token-Aware 的混合双线性模型。以下相对各独立分割上组均误差最低的简单基线，正数才是改善。

| 任务 | 熟悉结构下 S/M/SM 平均几何误差下降 | 新结构下 S/M/SM 平均几何误差下降 | 新结构下 I 几何误差下降 |
|---|---:|---:|---:|
| 关系 | −21.26% [−28.64%, −14.67%] | −15.73% [−19.36%, −12.65%] | −40.65% [−53.48%, −29.23%] |
| 逻辑 | −10.87% [−16.01%, −6.29%] | −11.50% [−13.63%, −9.50%] | −79.91% [−92.91%, −67.72%] |
| 算术 | −6.24% [−9.57%, −2.64%] | −19.72% [−23.26%, −16.35%] | −14.54% [−19.39%, −10.28%] |

冻结候选在新结构的中间变量预测误差均高于零响应。最终变量的交互误差也没有优于最佳简单基线。以真实 clean K2 加预测响应进行 oracle-anchor 评价，无法独立复原完整 K2。直接对真实 P11 的读出做拟合集探针，预定组合答案准确率为关系 22.5% [13.8%, 32.5%]、逻辑 40.0% [30.0%, 51.3%]、算术 5.0% [1.3%, 10.0%]。对应均匀选择为 20%、50%、33.3%。算术连自然新组的同一探针也只有 6.25%，数值外推不足限制了语义诊断。对连续算术响应使用回归数值变化检验，避免候选距离在拟合值落于整个候选区间之外时变成常量。当前探针未建立 P11 在 K2 等同自然 11。[语义响应图](results/figures/04_semantic_response.pdf) · [指定答案解码](results/semantic_accuracy_summary.csv) · [推进判据](results/gate.json)

## 6. 迭代结论

| 轮次 | 假设与检验 | 证据与决策 |
|---|---|---|
| 1 · 技术闭环 | 确认关系等任务的 K1 边界可被独立替换 | 掩码和因子分离成立，完整边界交换通过，不根据结论改动位点 |
| 2 · 冻结前开发 | 等容量比较均值、token 统计和两种训练信号 | 混合双线性 token 候选在开发集胜出。封存后在 480 个独立组评分 |
| 3 · 独立失败诊断 | 检查交互能量、语义准确率和答案差分是否一致 | 形态上可测的交互缺少稳健的语义和预测支撑。固定同一模型作事后汇总，未用确认数据重训 |

能够成立的是**两区扰动相对于独立效应产生非加性传播，并且行为差分在晚轮增强**。当前设计没有证明高维状态中有单独可识别的通用组合操作。优先追加一个小型定位实验，固定同一组和剂量，沿 K2 层逐段比较原生 S/映射依赖，使用同映射语义且不同来源背景的供体测量背景泄漏。这样可先区分 K1 映射供体中已有的上下文信息与 K2 内部新形成的依赖。之后才值得测试保留逐 token 邻接的低容量模型和新独立干预组。未进入学习 K2→K3/K4、完整基准或 2.6B 阶段。
