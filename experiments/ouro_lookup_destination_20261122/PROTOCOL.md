# Full-dose routing with the same debit and different destination

Natural repairs have a full K1 wrong answer corresponding to another table entry and a full K2 correct answer. Preserve the queried key, all inputs, live values, and ordinary downstream computation. Only query positions after all four values are complete may receive the routing edit.

At every actual emitted prefix take native receiving weights for the four digit rows as a common reference. The requested full shift is the difference between the recipient's native target-row mass and the mass given by imposing the donor's target-versus-foil fraction on the native recipient's total mass for the two rows. At each layer, head, and query subtract this unsigned amount from the same source row and same digit weights in both arms. True credits the native destination (target or foil, as specified by the signed change). Redirect adds the identical vector of credits at the aligned digits of a third row. Credit fractions come from the true destination's native digit weights. The same prefix therefore yields exactly the same per-digit debit, L1 and L2 of the sparse probability delta, with no smaller unrelated-row source limit.

The dynamic forward uses the native four-row reference totals at the edited queries to implement the common transfer. It preserves the relative non-row weights of its live attention and rescales them to fill the remaining mass. All values, Q/K projections, all remaining queries, and downstream computation run on their actual states. Consequently the exact dose match is against the common four-row anchor at each prefix. An anchor-only condition verifies clean generation. Also reproduce the previous full-live route with the live two-row total and donor fraction.
