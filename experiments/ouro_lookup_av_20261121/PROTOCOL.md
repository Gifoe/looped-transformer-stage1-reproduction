# Does route–content interaction contribute to bidirectional lookup correction?

Hold the pinned frozen Ouro-1.4B Base model, FP32 eager, no cache. Freeze 384 new prompts per confirmed format, distinct from the previous lookup datasets, and collect unmodified full greedy K1 and K2 responses. Intervention eligibility requires K1 to emit a different value from the actual table and K2 to give the exact correct integer. Both formats must supply at least 48 eligible examples. The intervention window is physical layers 12–17, every valid input position and every head.

For every arm's actual free-generation prefix, collect native receiving phase r and donor phase d tensors at the same physical layers. Use true masked softmax weights A and native grouped-query values V. Preserve the recipient state through physical layer 11. At each target layer install the attention vector formed from these native operands, at the native output projection immediately before post-attention normalization. Keep all MLPs, normalization, residual sums and layers 18–24 recomputing on the intervened state. Apply independently in both directions.

The five active arms are routing only A_d V_r, content only A_r V_d, joint A_d V_d, joint minus D, and joint minus a matched control, where D=(A_d−A_r)(V_d−V_r) projected through the weight of the native output projection. The no-interaction arm therefore implements A_d V_r + A_r V_d − A_r V_r before projection. For the matched subtraction use the same projected displacement norm and radial component with respect to the native joint projected write at each token. This control is constructed without labels. Native recipient A_r V_r replay is an identity arm in both directions. No candidate tokens are inserted. On a fixed subset audit native projection reconstruction, the exact interaction identity, equality of installed valid prefix values, unchanged layer-12 entry, independent physical suffix recomputation and full native answer replay.

The main endpoint is exact dual success on one problem: K1 generates truth and K2 generates its original K1 wrong table value. Report directional results as well. Main contrasts are joint versus A only, joint versus V only, and joint-minus-control versus joint-minus-D, each in both formats. Also report the two singles versus recipient identity and joint versus the norm/angle-matched removal arm as descriptive contrasts. Use 40,000 paired bootstrap replicates with Bonferroni simultaneous 95% intervals across the six main contrasts. Support an interaction contribution to this intervention only if joint has at least eight dual successes in each format, all six lower bounds exceed zero and the matched subtraction retains at least eight dual successes per format. Stop pursuing this interaction in this interval if the simultaneous one-sided 97.5% upper bounds on its extra dual wins, with losses ignored, are below ten percentage points in both formats. A positive result does not itself establish necessity of the same factor in an untouched native K2 trajectory. A non-significant contrast with a wide interval remains unresolved.
