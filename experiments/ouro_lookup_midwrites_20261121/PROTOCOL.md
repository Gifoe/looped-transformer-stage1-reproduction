# Do endogenous middle-layer branch writes contribute to natural lookup correction?

Use frozen Ouro-1.4B Base in native FP32 eager mode, no cache. Freeze 384 new prompts per format, distinct from all preceding lookup prompts, with unique targets within this deck. Standard and shifted formats replicate the confirmed layout families. Native complete integer generation is scored for all prompts and all four K1→K2 transition classes are retained. Intervention enrollment requires a complete K1 error equal to another value in the table plus exact K2 correction. Both strata must have at least 48 enrolled questions.

For a fixed table and the actual emitted prefix in a given arm, record normalized attention and MLP writes in both native passes. In either direction, begin at the recipient's own natural state and keep physical layers 1–11 native. Replace selected writes at every valid position in physical layers 12–17 with the other phase's native writes. The arm selects attention, MLP, or both. Unselected writes are recomputed natively on the altered state. Layers 18–24 are recomputed without hooks changing their values. Use the original task prompt, native normalization and vocabulary head and unrestricted generation. Independently reproduce the clean suffix from a captured boundary state to check instrumentation. A native-write replay must recover the same full answer; for a fixed audit subset, also check the full installed prefix at every replaced site, the unchanged input to layer 12, and the last pre-norm state in recipient-identity replay.

The geometric control preserves each token's displacement norm and angle to the native recipient write. The unrelated-row control swaps only the other two entries and adds that change in the donor phase's actual writes to the recipient native write with matched token-wise displacement norm. Positions where the unrelated swap gives a zero usable direction use the geometry displacement, counted separately. Pair only aligned token grids of equal length. A dual hit requires K1→truth and K2→its exact original K1 error on the same question. No candidate tokens are injected. Save full natural and edited strings and token IDs. Native rescoring also records outcome transitions without pooling the formats.

There are twelve primary paired contrasts (two domains × three branch selections × two controls). Use 40,000 within-question paired bootstrap draws, simultaneous 95% Bonferroni intervals. A branch selection is supported only when each domain records at least eight authentic dual hits and both lower bounds exceed zero. For an informative negative, use exact one-sided upper bounds on the extra-success indicator, which conservatively bounds the net effect because it drops losses. Stop expanding the interval replay if all 12 simultaneously corrected 97.5% upper bounds are under 10 percentage points. Report both corrected and uncorrected upper bounds, disagreement cells, directional results, and any underpowered or mixed result. Neither a transplant sufficiency result nor a null replay alone establishes a uniquely mediated attention or MLP route.
