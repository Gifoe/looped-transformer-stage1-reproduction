# 本轮结束后的研究判断

最新授权的nl33w机制审计已完成，当前没有待续跑的本任务GPU实验。nl20→nl23完整训练仍暂缓；所有数据、模型、chain和准备/成本pilot保留。

**No-Go：当前证据不足以宣称发现了一个已验证的新通用失效机制，也不足以支持Loop。** 16个新干预目标全部交付，13个保留head-dot下的原始伤害转移；0个在两个读出中通过反向切断或范数匹配K/V修复。一次native修复未通过输出点积复核。探索候选不能代替重复验证。

后续如果继续研究，优先顺序是：

1. 对既有大margin直接伤害和NCEOGA反馈候选做少量完整FP32 backbone/TF32关闭的推理复核，区分上游BF16和读出边界；先记录原始批量与同题逐token位置。不再扩大低margin BF16网格。
2. 在同一checkpoint中构造答案相关变量已知、错误值和正确值可配对置换的必要私有证据诊断。保持问题、token时序、写入norm及有效BF16残差控制，分别改K、V和指定读出路径；随机方向及无关同题片段是必要对照。
3. 只在“特定变量进入接收方、其作用被后续层抑制”具有反事实证据时，才检验利用失败。探针可读性、attention峰或末层CUT回填不能代替该证据。
4. 只有明确要比较“QA训练是否改变该路径”时才需要nl23 QA权重；先寻找新发布权重。不要为补齐表格重建整个nl20预热/混合训练链。当前研究问题不以严格nl23复现为前置。

进一步实验应形成新的固定问题、精度门槛与成本边界。本轮没有排队新的训练、Loop或无期限搜索。已有代码与负结果足够支撑一次可复核的机制审计报告，但尚不足以包装成模型方法论文。

次要margin结果：固定FP32 Write范数的CUT K/V在16个新目标中13个提升margin（native均值+0.1641；FP64-dot均值+0.1825），但没有新增两种读出均成立的纠错。13个保留原始转移的目标中11个margin提升。该效应值得用匹配随机方向和语义值置换继续检验；不能把失败的原定纠错标准事后改成成功，也不能把0纠错说成没有margin因果效应。见secondary_margin_effects.json。
