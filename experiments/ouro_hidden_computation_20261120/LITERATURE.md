# Ouro-1.4B 循环机制的文献边界

检索截至 2026-11-20。范围为近一年 recurrent-depth Transformer、已训练 Ouro 的原生计算、跨轮因果干预和读出协议，另保留两类基础工作作为比较。预印本用 arXiv 版本固定，已发表论文按会议或期刊引用。公开代码核对覆盖作者仓库或官方实现、关键入口及能追溯的实验设置。本次文献核对未执行作者 GPU 复现。

## 协议与读出对照

- **选择协议有独立文献。** Pezeshkpour 和 Hruschka 记录了多选题的顺序敏感性。Zheng 等在 20 个模型和三个基准中分辨 option-ID 先验并提出 PriDe。两项结果让位置/标签偏置成为必须控制的竞争解释。跨排列内容一致性提高，另外还可能受候选正文相对打分和规模改变影响。 [Pezeshkpour 和 Hruschka](https://arxiv.org/abs/2308.11483) · [Zheng 等，ICLR 2024 Spotlight](https://arxiv.org/abs/2309.03882)
- **LoopCD 的比较对象是输出分布。** 已读论文 §3、表 2、附录 B/F。固定 Logits 为 z_K + ω(z_K − z_1)，Adaptive 的不确定性是全词表中最高两枚 token 的 softmax 概率差，Hidden 在 Ouro 的末归一化前对完成的循环状态作外推再投影。作者的 Ouro-1.4B ARC-C 25-shot 正文续写分数为 Native 60.41%、Fixed 62.29%、Adaptive 61.69%，附录的具体案例用每字符 log-likelihood。未见论文给出的 Ouro-1.4B Hidden ARC-C 结果。上述公开数值与项目的 25-shot 历史重算和 0-shot Pareto 结果应分别注明记录和运行口径。固定前缀下，这些变体可用同一原生轨迹重算输出。自由生成因读出改变后续 token 而会改变后续原生轨迹。 [LoopCD §3、表 2 及附录](https://arxiv.org/html/2610.02185v1) · [原生 ARC 格式](https://github.com/EleutherAI/lm-evaluation-harness/blob/v0.4.13/lm_eval/tasks/arc/arc_easy.yaml) · [项目逐候选实现](https://github.com/Gifoe/looped-transformer-stage1-reproduction/blob/5557699b244a0a6981beeb540dc58491bf165096/experiments/ouro_arc_pareto_20261119/run_arc.py)
- **晚形成导致后续操作不足已有比较。** Biran 等在非循环自回归 Transformer 的闭卷多跳查询上报告桥在比较晚才解决时最终第二跳容易失败，并做过将后层表示提前的干预。Lam-Muir 在目的训练的 30M recurrent 模型上同样报告了与难度相关的决策时序，同时撤回了依赖几何坐标选择的速度信号。述及 Ouro 的协议时序时，需要把已知的晚桥、决策阈值和真正的功能时移分开。 [EMNLP 2024](https://aclanthology.org/2024.emnlp-main.781/) · [Lam-Muir 预印本](https://arxiv.org/abs/2608.03263)

## 尚缺的证据

1. **在哪一步把来源和映射变成可重用的桥或结果。** 原生 1.4B 的末位 Q 移植已经证明合成题可以提早调用某些检索，证据止于消费端。当前测试需用相同最终答案但不同中间值的供体，以及三值以上独立组合，检查候选函数能否预测新组合的实际替代结果。桥接位置应有对背景干扰稳健的写入效果，并有下游阻断或二次恢复验证。
2. **候选可见性是否改变同一语义转换的时间或作用。** 已有本地工作展示带选项字母、无选项正文的峰值轮次不同，两条件同时改变提示与目标。对共享 token ID 前缀，因果注意力强制每轮的前缀位置无法接收未来选项，须先验证这一技术性质。需要在候选可见/隐藏但目标相同的两种自然续写中观察共同语义因素的响应，固定语义角色和有意义的共同测量；随后独立检验预测到的物理层、轮次、作用方向和对应的行为效应。只有输出最佳轮发生移动，或逐轮 margin 的单位不同，仍可由读出解释。
3. **将匹配的因果功能与不同几何区分。** 固定 K1 线性探针的 K4 失败、source→mapping K2 阻断后只在更晚影响行为，都有本地先例。真正增加的信息是能提前预测某种协议下哪个位置会读取哪种语义状态，在独立结构和真实多跳中检验该对应，并测量它何时失效。注意力权重、范数、候选 margin 和最终错误类型提供不同证据。

上述问题是根据已读文章对当前证据范围的判断。现有工作分别触及阶段、选路、复用、写回和读出，尚不足以陈述冻结 Ouro-1.4B 的跨协议通用算法。
