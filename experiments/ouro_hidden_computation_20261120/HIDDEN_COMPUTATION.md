# Ouro-1.4B 的跨循环组合与因果路由

在 48 组独立增跳题上，将分别只改变来源或规则的供体状态写入 K1 后的相同角色，K4 对两个预定新组合答案的候选准确率为 **63/96（65.6%）**。同样问题的原生新组合世界是 **56/96（58.3%）**。联合写入相对干净接收方的新结果优势为 **+1.595 [+1.312, +1.868] nats**，相对等幅同 Y 供体为 **+1.911 [+1.611, +2.205] nats**。新组合效应高于全部指定对照。 与结果无关的标签置换保持共享题干状态逐位一致。HotpotQA 证据替换验证了具体证据的行为作用，受控任务的 K2 路径未达到跨任务复现门槛。

## 7. 计算模型的有效范围

我们识别的是一个可检验的局部组合规律。来源与规则状态可以独立作用于原生后续循环，联合操纵能产生预先指定、未被任一供体单独指定的结果。它使用的是完整角色 token 状态，在 3×3 世界和结构留出上逐条验证。早轮读出、干预后的组合准确率和局部路由恢复分别约束可观察信息、计算的可操控性和状态的因果用处。它们没有共同确定一个手写等价的全网络程序。

原生输出的跨协议内部状态变化有证据，固定阶段提前需要留出阶段匹配及下一轮行为预测同时支持。功能对应没有达到该双门槛时，应保留多个在后缀内发生的路径，包括候选条件化、内容和字母绑定，以及同一信息从不同位置进入读出。固定 K2 路径的真实多跳迁移和可直接替代循环的性能提升保持为各自要验证的命题。

交叉供体移植属于已有因果抽象方法。前序 Ouro 四世界实验中，主要联合改动回到同一答案，正的非加性交互仍可能来自两项单独损害。本次选择联合目标和任一单因素目标都不同的两个 3×3 对角条件，直接验证预定的新答案。Wu 等已在任务微调的 Ouro-2.6B 和拟合状态控制器上，用注意力模式移植区分重新路由和复制答案。Mu 和 Wang 已在预训练 Ouro-1.4B 上用跨轮末位 query 移植改变合成两跳检索。本次干预的是同一循环边界的完整角色状态，来源与规则分别取自自然供体。匹配剩余深度的行为比较约束的是这两个角色能否在原生共享循环中继续组合。 [因果抽象](https://arxiv.org/abs/2106.02997) · [Shared Weights, Appendix D](https://arxiv.org/html/2609.39892v1) · [Cross-Loop Query Handoff](https://arxiv.org/abs/2610.34639)
