# Sol 机制研究移交

固定模型为 ByteDance/Ouro-1.4B Base `574fa66cb8bf5abdc979642d01cf2b79b16bfab1`。移交基于冻结确认结果，供 Astra 评估性能路线。首选目标、数据、物理位点及干预分组见 [机制研究](HIDDEN_COMPUTATION.md)、[协议比较](PROTOCOL_COMPARISON.md) 和 [复现入口](README.md)。

## 1. 可靠发现

- 对增跳结构留出的 48 组，写入来自不同单因素供体的 K1 来源/规则角色状态，开放候选 K4 的新目标 **63/96** 成为独占首选。相对等幅随机的目标 margin 为 **+1.067 [0.577, 1.532] nats**，相对同 Y 为 **+1.911 [1.611, 2.205]**。两个单独编辑的同目标对照也稳健低于联合写入。该布局保留接收方桥接与读出位置，兼容后续原生组合。带列表正文也超随机，效应和自然能力均受协议影响。 [逐臂结果](results/mechanism/mechanism_summary.json)
- ARC Validation 的 C/E 在全部 299 道题使用相同提示 token，不同候选目标足以使 K4 差 **+26.76 pp**，K4−K1 净收益差 **+19.06 pp**。同位置遮罩控制下，可见候选又使正文 K4 分别增加 0-shot **21.88 pp** 和 25-shot **35.94 pp**。字母与正文的相对优势会随示例作答格式反向。 [协议确认](protocol_results/PROTOCOL_NATIVE_METRICS.json)
- 自然分叉证实 120 组七种后缀的共享前缀状态在 196 个事件上逐位相同。对齐后的下游候选与读出状态才发生变化。HotpotQA 两批支持句扰动影响候选选择，固定物理路径复现未通过。 [图谱](CAUSAL_COMPUTATION_ATLAS/README.md)

## 2. 与近期文献的实际差异

已有工作分别建立循环阶段重复、共享块受输入状态控制、Ouro 支持跨轮末位查询移植、其他循环骨干带有计算状态方向、以及 Ouro 会出现可读但未获因果验证的中间量。本研究增加的是同一个冻结 Base 内、同一循环边界上，交换两段真实题面的全宽角色状态，使原生后续循环表达一个事前计算且不同于两边供体答案的结果，并用 3×3 设计在增跳留出检验。联合干预使用真实状态，尚未恢复 token 级唯一算子。 [文献核查](LITERATURE.md) · [前序本地实验](PRIOR_AUDIT.md)

## 3. 被证据排除或限制的解释

| 解释 | 证据结论 |
| --- | --- |
| 复制一个供体最终答案即可解释新目标 | 两个联合目标均异于各自单因素供体，行为及指定 margin 超过对应单因素和同 Y 对照。解释不足。 |
| 可见性效应只是序列更长或最终 token 更远 | 同长度候选遮罩确认仍有明显差异，限制该解释。 |
| ARC 的额外收益全部来自隐藏算法改变 | C/E 提示 token 一致，仅改变评分目标便可重现一部分差距。 |
| K2 对所有题实现可识别的固定运算 | 统一一个剩余循环后，结构留出和配对随机的差跨零。保留至 K4 的组合支持不等于一轮运算峰值。 |
| K2 来源→规则→K3 读出的确定串联 | 结构留出开放 K4 同接收方恢复约 +0.029 nats，但来源特异切断及恢复消除的区间跨零。新实体上的再切断差方向相反，HotpotQA 同样未通过。 |
| 候选使同一计算函数稳定提前 | 结构留出匹配未超过同层对照，未来纠正预测也未稳定超过当前原生 margin。 |

## 4. 可优先评估的计算环节

先关注循环边界上来源和规则的可分离携带，以及后续读取是否真利用双方。它是本阶段唯一同时通过了语义新值、匹配随机、单因素、同答案供体和增跳留出的内部行为规律。开环把支持题目的真值供体写入接收题，无法直接变成部署方法。优先检查接收方自身的来源及规则状态，在无需额外循环的预算内是否对错误类型有额外可用信息。确认需针对真实任务而不是只凭合成题。

## 5. 剩余的区分实验

1. 对严格同答案与答案互变的匹配自然世界，找到可以移入 K1 或 K2 后实际生效的最小角色子块，比较角色×物理层而非追加区域均值的表示宽度。
2. 将 K3 规则到读出的再切断拆分为查询、末位、候选 token 和并行读取。需要在干净和已恢复的接收方都比较显式剂量对照，并把验证迁移到不重叠的真实多跳例。
3. 在自然后缀固定同答案内容、编码标签和长度，从冻结开发阶段预测增跳留出上哪一种候选会改变哪个物理事件，再检验它能否改善逐题预测。当前对齐的失败是强基线。
4. 对支持文与无关文均包含相同答案字符串的真实题，验证正确结果与外部可解的桥接是否同向变化。扩展自由生成解析及候选筛选落差的检查。

## 6. 可立即小规模验证的性能假设

在问题和预算固定时先上同协议 LoopCD 的固定、适应与 Hidden 对照，另对同一实际输出策略保持一致解析。受控任务表明原生循环能利用互相独立的局部信息，而 ARC 共同提示证明候选输出会直接影响观测收益。因此零额外共享循环的探针应从同预算的原生 logits 或已有边界状态检验额外可读信号，并用原生 margin、候选长度和更简单的输出格式校准作同成本基线。用新开发留出和原生答错分层作小规模验证，独立汇报真实行为、配对错误、实际时延和额外投影开销。独立生成中，C/E 同预算同方法的续写有 208/208 对 token 完全一致。K4 Native 按正文与字母标准却分别为 0/16 和 12/16。该对照要求候选和实际生成各自设定成功标准。具体的推进条件见 [性能可行性](MECHANISM_TO_PERFORMANCE.md)。

## 7. 超过 LoopCD 所需证据

在任一 K 的成功同时需要同协议准确率提高、逐题救回超过误伤，并在实际相同推理方式下计时。K1 只有一个原生状态，三种 LoopCD 退化为 Native，读取额外退出头只能作为有投影成本的比较。K≥2 有额外原生读出可供使用。C 的 K3 Fixed 救回 20 题，下一轮原生独立救回 14 题，只有 8 道相同。C 的 K4 Adaptive 改善 +4.68 pp；同提示字母 E 的 Adaptive 少 3 道。用这些结果定位潜在改进和不能替代后续循环的题。跨任务无固定路径及相同剩余时长的虚弱效应，使提前完成计算现在还不足以承诺更少预处理或更低循环预算。单个预算的改善不能代替所有预算的验证。

## 8. 缺乏重复价值的路线

在相同数据上仅提高区域均值、token pooling、Ridge、MLP、双线性代理或单方向探针的维度，尚无改善独立因果预测的证据。用预测正确率筛掉困难组、合并两套不一致的历史端点、用候选排序代替自由生成，都会破坏已有对照。根据目前的合成状态移植直接大规模训练 LoRA、状态预测器或蒸馏，无法检验是哪一项语义计算提供收益。
