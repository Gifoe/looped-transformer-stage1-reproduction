## Populations and tests

The independently generated full factorial has three source values and three rule rotations per problem. The outcomes rotate through three possible object names, among five presented/evaluated candidates. Nonzero same-index joint changes produce an answer different from the base and from both single-factor changes. The development split has 24 groups. New entities and new structure each have 48 independent groups. The structural split changes the entity/answer vocabulary, lookup key domain, and adds a bridge rule in every problem. All confidence intervals resample problem groups with 3,000 deterministic bootstrap draws. Report intervals as pointwise intervals across prespecified contrasts. For ranks with an exact tie, all tied candidates fail the strict correctness check. Chance for a uniformly random choice among five candidates is 20%.

Compare these rival claims.

- **Late composition.** On the structural holdout, separate source/rule donor patching should increase the designated newly composed answer's K4 margin over both matching single edits, random perturbations, same-result controls and clean. Under late composition, an early boundary patch must allow the downstream model to form the novel target even though it did not co-occur in either donor. Natural answer evidence and response RMS are secondary diagnostic outcomes. K1, K2 and K3 boundary effects are reported.
- **Early results enter a later route.** A K2 source-to-map cut lowers later answer margin relative to matched noise keys. Same-receiver K2 map restoration rescues later margin and an independently controlled K3 map-to-query or map-to-read re-cut selectively removes that rescue. If the same re-cut attenuates native answer margin in a clean recipient, it is evidence of a route with native relevance. A rescue alone establishes downstream recoverability in the edited context. An early direct logit-lens answer margin supports readout availability. It does not identify the first construction time or show what is used natively.
- **Candidate-driven rerouting.** Open and content-list prompts use the same output vocabulary and exact shared prefix. An input-to-output effect that differs between the two protocols is evidence of task-context dependence at downstream sites. A stable earlier or later phase requires matching the signed 9×5 answer-response pattern on development, exceeding the same physical stage on each holdout, and improving out-of-sample correction/retention prediction over current native margin. Lens similarity alone cannot confirm phase shift.
- **Content–label binding.** Shuffle positions while preserving label mapping. Separately permute labels while keeping content order fixed. Measure native content selection changes and, among forks changing the correct label, compare the new and original label's score and selection. The letter-output branch keeps the same candidate list as the content branch. Compare the distractor replacement and irrelevant evidence addition forks with the fixed candidate list. Fork invariance is tested at every layer input, output and loop norm. A fork-specific change in the quality of the text-continuation distribution is not evidence of a changed prefix computation.

The natural tensor atlas records unprojected dimension RMS at each output component. Source and mapping response RMS average all six axis contrasts from the base source/rule index. A fixed same-answer contrast is world (1,2) minus (0,0). Four factorial double differences use the base source and rule reference. Atlas representations and norm values are descriptive. Event selection uses only signed candidate score responses under the original tied head and a common terminal normalization. Re-centering removes fixed candidate logit biases and global shift per world. Phase matrices use physical layers 5, 11, 17 and 23 of each loop. Forecasts select only open events available by the prediction depth. Independent evaluation runs the fixed script once.

HotpotQA real-task validation uses hash-prioritized 64 official bridge validation examples with literal cross-document links, one-token gold answers and two labeled supporting titles. Gold answers must occur in precisely one marked supporting text. Conditions compare three prompts, length-preserving role replacement at token positions, and K2 antecedent-evidence-to-answer-bearing-evidence cuts against equally many non-support keys and same-receiver K2 restoration. This is a selected answer-reranking population. The roles are annotations, and replacements are perturbations in token space. The transfer criterion requires restoration and route specificity in the same direction on the real corpus. Three protocols and free next-token hit rates are reported.

## Prespecified follow-ups before independent tableau readout

The early-development result motivated a matched-horizon check. Compare the same-role interchanges after exactly one downstream loop (K1→K2, K2→K3, K3→K4), with matched random, same-Y, and single-factor controls at each. If K2 is more responsive than K1 or K3 with the same remaining computation, depth-to-end cannot by itself account for stage selectivity. Contrast the open/content causal effects within the same problem, rather than comparing visual overlap in separately bootstrapped intervals.

The first Hotpot cohort used wrong options absent from the visible text and saturated in candidate ranking. A disjoint 48-example Hotpot subset instead requires exactly two wrong options present in the same visible non-supporting excerpt, two distractors absent from all visible excerpts, and a bridge title that is absent from the question. It uses the previously specified inference and perturbation arms with a new hash prioritization key. No first-cohort question IDs can appear.

The fork follow-up compares states at aligned question, final Answer-colon, and unchanged core candidate-content positions through all layers. Its eight-token unrestricted BF16 generation on 12 hash-selected prompts per structured split and 16 official Hotpot questions is descriptive. It retains emitted token IDs and strings and reports a bounded short-response parser, with no substitution of candidate probabilities for generation.
