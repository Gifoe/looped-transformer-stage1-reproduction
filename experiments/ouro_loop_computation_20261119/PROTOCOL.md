# Protocol for what an additional Ouro loop computes

Use the frozen BF16 Ouro-1.4B Base checkpoint 574fa66, native SDPA and no KV cache. The four primary worlds cross an independent source change with an independent mapping change. They have four distinct final outcomes. An extra compensatory world changes source and rule while preserving Y. A nuisance world changes an unrelated prefix. Within a group, emitted answer slots stay fixed and are independent of the scene. Every natural world is scored with an option suffix and with the same stem without options. Relational and logical names and mapping formats change in transfer. Arithmetic changes base range and adds a functional instruction.

Development uses 112 fit and 48 discovery groups per task. Independent same-structure and additional-step transfer each use 96 groups per task. Declared tasks are retained regardless of scores. Public development screens are ARC Challenge validation, HellaSwag validation, PrOntoQA proof-only and GSM8K test. Separately reproduce the published row-normalized attention entropy, ColSum concentration and sink rate on 256 hash-selected GSM8K questions. Native SDPA still computes the forward. The diagnostic reconstructs attention from exact rotary Q/K and head mapping. These independent prompts and fixed checkpoint support a metric/profile reproduction at four loops. Public authors' exact item IDs and additional reference models are outside this reproduction.

Estimate S, a witness of M (the output under the first source key or arithmetic net rule value), and Y with group-held-out linear probes. Report the candidate set, surface n-grams and same-decoder cross-loop transfer. Compare 48D all-layer readouts with 2048D boundary readouts. Independent selection uses no confirmation output. Probe ability to solve a task from an encoding cannot establish whether Ouro itself has used the decoded information. For natural scoring take full answers where multi-token, and report unconditional answer-prefix generation separately. A tied maximum never counts as correct.

Freeze a four-layer early-attention window for each task, loop K2–K4 and prompt protocol using the highest mean entropy among contiguous windows wholly inside L0–L11 on discovery r. Run cuts on an ID-hash cohort of 48 groups per split for open prompts, plus 16 of those groups for the choice protocol. Cut the changed source-token keys for map queries, compare to a neutral explicit causal mask, same-count nuisance keys, and a separate direct source-to-query/readout cut. Restore the same receiver's clean map activations after the window. A cut or rescue does not change the input text or any past loop. Compare both natural sources r and x for the cut effect, and record all group trajectories.

Independently transplant the entire map region after K1, K2 or K3 normalization, prior to the upcoming loop. Compare matched source-change donor with the same rules, a same-Y donor with different S and mapping, a donor with both factors changed, an irrelevant donor and Gaussian random vector. All local controls are scaled to the matched donor's actual movement. Record exact whole-boundary and self-replacement positive/negative checks. Evaluate the difference in the next-loop and K4 log odds of the designated donor answer versus recipient answer. The open arithmetic intervention uses distinct first-digit log odds; the natural open task also scores both digits. Discordance between these readouts limits causal interpretation in arithmetic.

Progressive composition predicts later emergence of Y beyond surface and earlier readout, with loss of newly available Y under causal interruption. Reorganization predicts a gap between within-loop fits and cross-loop transfer of the same Y decoder. Utilization predicts large delayed or loop-selective causal effects despite earlier Y readout. Treat these as possible components of the same computation. Use paired independent group-bootstrap intervals for cut, nuisance, rescue, interchange and decision contrasts. Prediction controls use current answer margin, state geometry and attention, then add semantic scores without changing held-out cases. The K2 open-prompt test is the primary causal contrast. Cross-scale execution requires at least two tasks with positive bootstrap lower bounds for source-cut cost over nuisance, same-receiver recovery, matched-donor margin over same-Y control, and semantic-augmented next-loop Brier gain in both independent splits. If that gate fails, report the null and the best-supported localized causal result.
