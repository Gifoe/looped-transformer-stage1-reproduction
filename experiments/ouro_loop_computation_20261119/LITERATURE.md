# Literature and code inspected

- Blayney et al., NeurIPS 2026, arXiv v2 dated 2026-11-16, report repeated stages within four native Ouro-1.4B loops. Eq. 3 normalizes each causal attention row by the logarithm of its available positions. Their U-shaped LogitLens results support repeated changes in next-token readability. This study reproduces the attention profiles and tests whether a particular source-to-mapping dependency accounts for behavior after those stages. The paper studies longer convergence regimes and other architectures that are outside this replication. [Paper v2](https://arxiv.org/html/2604.11791v2) · [NeurIPS program](https://neurips.cc/virtual/2026/poster/153805)
- The authors' public commit 3429a8d61fdae95d441cb18eb3bd695268d086f4 was inspected. The relevant paths are experiments/stages_of_inference.ipynb, experiments/support.py, the GSM8K likelihood configuration, capture/attention.py and analysis/attention.py. The notebook's full-mode sample uses 256 GSM8K test indices with a Python shuffle seed of 42. The collection runner includes the reference answer in the token stream. The head-level sink metric thresholds each head's mean first-key attention, not individual query rows. This study directly imports all three author metric functions and pairs the same questions with and without the reference answer. Ouro 1.4B uses no BOS in both harnesses. [Pinned stage notebook](https://github.com/HughBlayney/looped-mechanistic-analysis/blob/3429a8d61fdae95d441cb18eb3bd695268d086f4/experiments/stages_of_inference.ipynb) · [Metric implementation](https://github.com/HughBlayney/looped-mechanistic-analysis/blob/3429a8d61fdae95d441cb18eb3bd695268d086f4/src/looped_internals/analysis/attention.py)
- Zhang et al.'s graph-walk study shows that an entering state can select different computations in a frozen shared block, with evidence via attention patching. Its purpose-trained graph models and trained steering map differ from native base-model question solving. Our tests keep Ouro's parameters and original recipient prompt fixed and ask whether natural same-context routing and rescue predict loop-specific output effects. [Paper](https://arxiv.org/abs/2609.39892) · [Public code](https://github.com/wjjpku/howloop)
- Olszowiec et al. distinguish carry-loop systems, including Ouro, from architectures that reinject the input. Wang and Reid report limited linear transport across loop boundaries in Ouro-2.6B under their Jacobian lens. They motivate evaluating fixed cross-loop decoders and examining recurrence of causal access independently. Cutting K2 attention to source keys in Ouro is a test of reading the carried source-token state, not input reinjection. [Monitoring latent reasoning](https://arxiv.org/abs/2610.18127) · [Jacobian lens](https://arxiv.org/abs/2609.01924)
- Geiger et al. formalize interchange interventions as tests of a proposed variable alignment. A same-Y control with altered S distinguishes response to a changed target from generic disruption. Whole-boundary and self replacement are technical controls. Neither establishes that a local activation carries precisely one symbolic variable. [Causal abstractions](https://arxiv.org/abs/2106.02997)
- The Ouro release describes 2.6B as upcycled from an earlier shared 1.4B checkpoint by layer duplication. Replication would test transfer across related checkpoints, with a separate external-architecture test needed to establish independence. [Ouro paper](https://arxiv.org/abs/2510.25741) · [Model project](https://ouro-llm.github.io/)
