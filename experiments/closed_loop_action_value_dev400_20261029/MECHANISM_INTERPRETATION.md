# Interpretation boundaries for this intervention family

The shared Ouro recurrence is applied after each RMS normalization. In the pinned source, `current_ut` affects cache indexing; this experiment disables the cache. Thus, in exact arithmetic and with the same deterministic shared operator F, setting the depth-2 state back to h1 and then applying two more loops gives F(F(h1)), the ordinary depth-3 state. Floating-point equality of that identity is not separately asserted here. Fixed full rollback is therefore primarily an effective-depth control, not a new feedback mechanism by itself. It still executes the discarded loop and does not save its cost.

Partial rollback and extrapolation instead modify the state between h1 and h2, or beyond h2, before subsequent nonlinear recurrence. Their implemented causal effects were checked, but state changes alone do not establish beneficial correction.

The proposed variable measures known-input prediction responses, not a proven estimate of answer accuracy. Its two token groups share context and are correlated. A group-B veto cannot certify semantic correctness. Its predictive information must be assessed using actual intervention outcomes, with event counts, uncertainty and selection controls.

The confidence control uses the full-vocabulary margin at the last prompt position, at the same intermediate decision point; it is not a claim to reproduce every confidence-gating variant. The terminal-only ablation applies the same earlier update vector at the final readout and holds the selected action fixed; it isolates propagation within this action family, not all possible readout methods.

These definitions and limitations were written before the complete 400-question outcome analysis. They do not change the locked intervention, action-selection rule or statistical tests.
