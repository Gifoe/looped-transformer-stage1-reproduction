The first attempt terminated after 52 complete rows at the fixed 1e-5 absolute candidate-score parity check. On the next question, an isolated audit reproduced a 1.71661376953125e-5 difference in the first candidate. All other candidates matched. The original scorer, rerun now, exactly matched its sealed scores; the pilot and initial development scorer agreed with each other. Zero-feedback hidden states were elementwise identical to native states at all four depths, and all four implementations predicted the same answer. The audit did not access gold.

The implementation difference is LM-head/log-softmax position packing: the original scorer includes question-probe positions alongside candidate positions for the first candidate, while the new code projected only candidate positions. The mathematical candidate score is the same, but numerical results differed. A new worker includes the same probe positions and discards their log probabilities from the candidate sum, matching the original packing. The decision rule, state intervention, precision, full-candidate scoring convention, statistical protocol and 1e-5 parity threshold remain unchanged.
