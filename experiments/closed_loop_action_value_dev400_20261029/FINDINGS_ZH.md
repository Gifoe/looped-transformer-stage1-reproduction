# 400 题闭环动作价值开发实验

本实验回答输入探针变量是否能选择有益的真实状态干预。所有题来自已暴露的 OpenBookQA discovery；这是开发证据，不是新的独立测试。前 8 题曾用于实现试验，另报排除它们后的 392 题结果。

## 中间变量是否包含动作收益信息

控制器动作次数：{'0.0': 224, '-1.0': 0, '-0.5': 3, '0.5': 173}；有足够输入探针的题数为 385/400。推理时不使用 gold，同一个 prompt 决策用于所有候选。

| 状态动作 | 有益 / 有害事件 | 探针收益 AUC [95% CI] | 与 gold 候选归一化 log-weight 收益的 Spearman 相关 |
|---|---|---|---|
| 完全回退 | 10 / 13 | 0.769 [0.554, 0.938] | -0.035 |
| 部分回退 | 8 / 11 | 0.534 [0.227, 0.807] | 0.034 |
| 外推 | 3 / 12 | 0.222 [0.000, 0.528] | 0.002 |

AUC 只在该动作会改变正确性的非零事件上计算；置信区间为未作跨动作校正的分层 bootstrap，属于探索性诊断。不能将 AUC 或 log-weight 相关性当作最终准确率收益，也不能将两组相关输入 token 称为独立证据。

## 成本与实现完整性

串行回放成本估计：控制器 / 基线为 1.149 倍。决策耗时包含额外置信度诊断，零动作分支已扣除末端扰动诊断；这不是优化后的部署性能或算力节省证明。
本次所有工作进程、失败尝试及数值审计合计保守计费 0.3115 GPU 小时；累计新增研究用量 2.0673/8 小时。

首次运行 52 条记录后，被 1e-5 绝对分数一致性检查拦住。单独审计定位到读出位置打包差异；零反馈状态及答案一致。修正位置打包后，边界两题与原分数完全相同，保留原阈值并完整重跑 400 题。失败记录、诊断脚本的一次参数传递错误和全部计费收据均保留。控制器、状态动作、模型及统计方案没有因结果而修改。

全部动作只改变第 2 轮及之后的状态，未改变第 1 轮；主干保持冻结。原实验与原型文件哈希由独立本地审计核验。没有 early stop；撤回已经执行的计算不节省其成本。

## 研究判断

当前训练免费输入探针控制器没有通过预设开发标准。实现了“变量进入控制环”不等于发现了可靠质量变量；其是否有动作收益信息应以以上事件数、区间和随机对照判断。该结果不否定所有闭环变量，但不支持把这一版本作为有效方法发表或直接进行独立确认。任何后续轻量监督都必须使用实际状态干预的收益标签，且不能靠本结果选择新阈值或翻转符号。

## 主分析后的定向诊断：排序与校准不同

完全回退的输入探针增益在全部 385 道探针充分的题上均不为正，最大值也只有 -0.025702 nat/token。因此当前正值门槛必然不会选择完全回退。有益回退事件的探针值中位数为 -1.604，有害事件为 -1.957，存在需要新数据验证的排序线索。
同一 23 个非零事件上，预设正向 margin 变化的 AUC 为 0.331，探针 AUC 为 0.769；未校正的配对 bootstrap AUC 差区间为 [0.131, 0.723]。这是主分析后的探索性比较，不能证明条件独立的信息增益。训练后的置信度控制可从训练标签学习相反方向，必须公平地一并校准，不能用未校准的弱控制夸大探针优势。
原始探针响应 S 的单位是已知输入 token 的损失变化，不能直接当成最终准确率动作价值 V。下一项有界检验应在不同训练题上用实际状态干预的收益校准 S→V，再检验未参与拟合的题；不在这 400 题上移阈值、换符号或宣称已得到可靠控制器。
