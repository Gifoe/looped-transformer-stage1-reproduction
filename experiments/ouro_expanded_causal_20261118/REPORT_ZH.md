# Ouro-1.4B 扩展因果研究

本轮沿用固定版本的 Ouro-1.4B Base、BF16、原生 SDPA 与 K1–K4。上轮在受控两跳中将查询相关的影响定位到 K2/L5 的箱子词，保留了字面身份、上下文归属和后续传播三种解释。本轮更换了数据结构并使用互斥的新组，分别检验这三部分。在同一张 RTX 5090 上并行运行采集、确认和后续干预。[复现与证据定义](README.md)

## 自然行为与能力差距

主自然队列由开发组、预先切分的确认组和自然组组成。控制任务的分母为四个因子世界之和，联合正确要求每一组的四个世界在同一深度全部正确。基准分母为实际条目数。

| 多记录关系 | 960 | 143 | 348 | 333 | 398 | 18/240 |
| 派生 PrOntoQA | 720 | 361 | 395 | 553 | 560 | 50/180 |
| 算术 | 960 | 316 | 373 | 599 | 650 | 72/240 |
| PrOntoQA 发布条目 | 270 | 131 | 184 | 182 | 205 | — |
| ARC-Challenge validation | 299 | 127 | 232 | 252 | 249 | — |
| HellaSwag validation | 150 | 41 | 42 | 53 | 54 | — |

在扩展关系任务中加入三个及以上实体、逆向表述和第三跳，四世界联合成绩显著低于单世界成绩。派生逻辑的 K4 中间问题正确数为 704/720，算术为 916/960，关系为 924/960。最终输出还需要使用规则或执行后续运算。前缀中间问题只改变读出任务，成绩反映对可解中间变量的行为敏感性。

简化虚构类别演绎的两种提示在开发数据中分别只有 1/15 和 0/15 组四世界全对。额外的布尔规则开发队列三个结构合计 0/30。双加法的新开发组为 18/30，另一个预先分开的确认队列达到 63/90。为得到可用于逻辑和算术的自然能力对照，在独立池中冻结筛选标准后，按自然 K4 四世界全对筛选出了逻辑 156/600 组、算术 155/210 组。两队列各按固定哈希顺序选 90 组进入因果检验。筛选使用原生结果，没有读取任何移植结果。[自然分数](results/natural_behavior.csv) · [筛选收据](results/screened/screen_complete.json)

## A　相同词元的上下文作用

在 90 个实体归属互换的新组上，第一阶段的箱子词 token ID 在供体与接收方逐位置相等，变化的是两个箱子的归属人。后段映射反向补偿，使原生供体和接收方的真值相同。只移植相同词元的状态，K4 反事实相对原结果的 log-prob 优势比原生增加 **0.104 [0.080, 0.133] nats**，比配幅随机增加 **0.101 [0.078, 0.127]**，比配幅无关位置增加 **0.098 [0.072, 0.127]**。三个区间均为 98.33%。

移植变化的人名位置时相对随机的最终效应为 **0.320 [0.247, 0.401] nats**。整个前缀为 **0.473 [0.369, 0.589]**。相同词元状态在额外的中间问题上效应为 **0.163 [0.118, 0.213]**，而人名位置和整个前缀分别为 **4.255 [3.991, 4.519]** 与 **4.767 [4.482, 5.054]**。这些区间是描述性的 95%。整段、词元和人名干预的写入范围不同，各自只与同剂量对照比较。联合自然能力只有 6/90 组，因此这批结果首先支持有方向的分数变化。等词元状态携带可用的上下文线索，可能是局部人名痕迹、查询匹配或更抽象的归属状态。[A 线逐组数据](results/A-relation/rows.jsonl)

独立的 90 组重命名队列保留被编辑箱子词的 ID 和位置，但替换供体所有人名。相对于配幅随机，原名供体的 K4 效应为 **0.083 [0.063, 0.106] nats**，异名供体配幅后为 **0.062 [0.041, 0.084]**。异名相对同名下降 **0.022 [0.005, 0.038] nats**。独立中间问题上，异名相对随机仍增加 **0.097 [0.061, 0.138]**。由此可以排除「被移植位置的 token ID 改变」作为这批效应的充分解释，也可以观察到跨人名的可迁移部分。对应的人名对齐仍影响效果。固定箱子词的词汇意义、归属语境和查询相符度可能共同编码在同一向量中。这些证据约束了抽象绑定假设的强度。[重命名效应](results/renaming/effects.csv) · [同词元和重命名图](results/figures/same_token_context.png)

**A 线病例 `relation/A/012`。** Luke 在接收方拿白箱，白箱去 Dallas，绿箱去 Tokyo。在供体中 Luke 拿绿箱，后段映射补偿为绿箱去 Dallas。两个输入都以 Dallas 为真值。移植的两个位置在两输入中仍分别是原来的白箱和绿箱词元，只是上下文归属改变。K4 的 Tokyo−Dallas margin 从 −0.563 升到 +0.063，决策翻为 Tokyo。配幅随机和配幅无关分别为 −0.500 和 −0.688。该例取供受体及自然反事实输入均答对且移植翻转的方向，按效应排序选中位例。[病例数据](results/case_witnesses.json)

## B　第一轮信息如何在后续轮起效

在另一批 90 个关系组上，于 K1/L5 移植来源箱子词。开放条件的反事实 margin 效应随读出深度增加，K1–K4 分别为 **0.006、0.072、0.428、0.605 nats**。K4 相对配幅随机为 **0.561 [0.404, 0.729]**，相对配幅无关为 **0.575 [0.422, 0.739]**（95% 描述性区间）。这批组的四世界自然能力为 5/90，以下结论针对方向分数与受控路径贡献，行为普遍性仍有限。

| 路径干预 | K4 效应的变化，nats | 区间与解释 |
| --- | ---: | --- |
| K2 切断 source→mapping | −0.238 | 98.33% 区间 [−0.319, −0.165] |
| K2 切断 source→query/options/readout | −0.012 | 98.33% 区间 [−0.025, +0.001] |
| K2 同时切断两类边 | −0.245 | 98.33% 区间 [−0.328, −0.172] |
| K3 同时切断两类边 | −0.143 | 95% 区间 [−0.190, −0.099] |
| K2 与 K3 均切断两类边 | −0.414 | 95% 区间 [−0.530, −0.307] |
| K2 双切断后恢复映射区域 | +0.144 | 相对双切断，95% 区间 [0.103, 0.189] |
| K2 双切断后恢复查询区域 | +0.076 | 相对双切断，95% 区间 [0.051, 0.103] |

阻断效应为开放与关闭之间的差分。每个掩码内分别运行有注入与无注入，零切断的显式掩码与原生分数在全部检查中完全一致。K1 归一化后恢复来源词的原生接收方状态，使 K4 效应减少 **0.507 [0.370, 0.655] nats**。只恢复映射区域减少 **0.098 [0.066, 0.131]**，只恢复查询区域减少 **0.006 [−0.003, 0.014]**。完整恢复 K1 边界的所有位置与原生输出逐位相等，用作技术对照。

每轮末的每 token L2 差中位数在映射区域从 3.602 上升到 7.633，读出从 0.488 上升到 3.697。来源早已被写入，映射和输出区域随后逐步偏移。对来源→映射边的选择性阻断及恢复支持 **K2 对来源信息的重新读取，并将其写入映射侧状态**。到 K3，来源到后段的直接边仍有补充贡献，具体是映射还是查询方向尚待分开。给定相同最终答案供体、互反反事实方向及配幅对照，简单的统一输出偏好变化难以解释该模式。掩码改变了指定行的可用注意力集合，恢复混合区域状态，具体头、并行路径与局部组合算子尚待识别。[逐轮因果对比](results/causal_effects.csv) · [状态轨迹及路径图](results/figures/loop_routes.png)

**B 线病例 `relation/B/032`。** 接收方 Olivia 拿白标签，经 Maple 仓到 Paris。供体改成灰标签，调整灰标签仍经 Maple 到 Paris。只移植来源标签后，预期接收方按灰标签→Birch→Boston。Boston−Paris 的 K4 margin 由 −0.313 变为 0；将 K2 和 K3 的来源到后段直接边均切断后，移植条件只有 −0.125，同掩码无移植时为 −0.188。接收方和供体原生均选择 Paris。自然反事实输入也误选 Paris，移植则将 Paris 和 Boston 推到并列。该例是开放效应的中位方向。以物理层 L23 为例，读出处 attention 输出 L2 差中位数从 K1 的 0.095 增至 K4 的 0.544，MLP 从 0.095 增至 0.480。模块输出差可显示传播，模块本身的必要性需要直接干预。

## C　跨任务和能力对照

在主派生逻辑的 120 个组上，移植第一阶段事实信号相对配幅随机使 K4 最终 margin 增加 **0.085 [0.068, 0.102] nats**，中间问题增加 **0.642 [0.608, 0.677]**。自然四世界全对的组只有 35/120。因此另外检查了 90 个冻结后筛选出的独立自然全对组。在这个分层里，输入信号的最终效应仍为 **0.074 [0.057, 0.092]**，中间问题效应 **0.536 [0.496, 0.578]**。整段前缀的最终效应升到 **0.487 [0.451, 0.525]**，中间问题为 **1.941 [1.806, 2.083]**。词面固定的规则桥接区域也有小效应，最终为 **0.040 [0.029, 0.052]**，中间问题为 **0.047 [0.034, 0.062]**。这在具备自然任务能力的样本里复现了「移植第一阶段信息会改变后续决策」的功能关系。前缀可含输入、规则以及已传播的信息，桥接小效应也可能是局部条件匹配的痕迹。

双加法队列的 90 个确认组中有 63 组四世界全对。相对配幅随机，输入操作数状态的移植使 K4 最终反事实 margin 增加 **2.330 [2.159, 2.496] nats**，独立中间问题增加 **3.513 [3.360, 3.661]**。另一个 90 组定位队列保持这一效应，输入、尾部桥接位置和完整前缀相对随机的最终效应分别为 **2.449、0.083、2.599 nats**。桥接位置保持相同文字，只取紧接操作数的语法尾部。其分数作用相对弱，因此当前大部分加法移植证据定位在可见操作数或含操作数的前缀。用事实位点和前缀干预得到的跨任务功能相似性，仍可由任务各自的输入表示和后续计算实现。[跨任务矩阵](results/cross_task_causal_matrix.csv)

宽样本算术也有独立的正效应。主确认 120 组中有 37 组四世界全对，操作数状态移植相对随机使 K4 最终效应增加 1.761 nats。宽样本的另 90 组中，词元不变的桥接尾部为 0.052 nats，完整前缀为 1.624 nats。三类运算混合后的效应低于自然能力筛选的双加法队列，因此两个口径分列报告。

在同样四世界全对的 90 个独立算术筛选组中，操作数、桥接尾部和完整前缀相对随机的 K4 最终效应分别为 **2.650 [2.462, 2.838]、0.066 [0.028, 0.109]、2.866 [2.709, 3.025] nats**。对应中间问题为 **3.597、0.158、3.841 nats**。这是与自然失败区分后的定位结果。逻辑与算术的桥接效应虽为正，量级都远小于同队列的完整前缀。根据不同范围的实际剂量，这些数值适用于各自的干预对照。它们不能量化一个抽象变量散布在各位置的比例。

主关系确认的 120 组中有 8 组四世界联合正确。变化的箱子或标签词元移植相对配幅随机的最终效应为 **0.519 [0.383, 0.669] nats**，中间问题为 **5.106 [4.850, 5.372]**。该结果与 A 线的纯上下文小效应和 B 线的重新读取证据互补。[主确认指标](results/cross_task_causal_matrix.csv)

**C 线病例 `arithmetic/competence_confirm/255`。** 接收方先算 7+3，再加 8 得 18。供体改为 7+4 再加 7，两者最终真值仍是 18。移植 `4` 的 K2/L5 状态后，后续仍用接收方的 +8，预测为 19。K4 的 19−18 margin 从 −0.625 升到 +2.000，配幅无关和随机分别为 −0.625 与 −0.375。K2 的效应很小，K3 已出现明显的 19 倾向。这是自然反事实正确且干预翻转的中位例。[逐组病例与输出](results/case_witnesses.json)

## 可证伪的循环计算解释

**关系任务**支持一种位置依赖的循环读取解释。实体归属塑造第一阶段记录的状态，其中有小幅、跨人名可迁移的上下文成分。这个状态在 K1 即可影响后续过程。K2 将来自早期记录的差异重新带入映射区域。映射、问题和输出状态在随后几轮继续变化，K3 可重复访问来源并补充效果。该解释要求在相同最终真值的供受体组合中，局部阻断提前读取能减小反事实影响，恢复映射能部分救回。这两项预测已在本队列中得到支持。

**跨任务**可保留的结论是早期变量的局部状态对独立中间问题及下游反事实选择都有因果作用。逻辑的整段前缀作用强于孤立输入，双加法的大部分效应随操作数位置走。三类任务的自然能力、位点、扰动范围与实际幅度不同，抽象符号变量、独立于表面的数值编码，以及共用的跨轮路径均有待定位。单 token 的首选答案改变、连续 margin 变化和完整语义机制在报告中采用各自的判据。

**Ouro-2.6B 验证**建议先冻结同一组语义对和组级目标，在独立 90 组上做相同词元与实体重命名的来源移植，再做 K2 来源→映射阻断与恢复。物理层只在独立开发组通过少量相对深度候选定位。确认前固定自然四世界能力门槛及主效果差分，同时保留来源词汇变化的阳性对照。若同词元迁移和恢复在更大模型复现，可提升对跨尺度功能结构的信心。也应保留词汇信号与映射路径分离的失败模式。

## 执行与验证

主自然队列共 3,359 个运行世界或基准条目。最终审计通过 13 个主确认或定位队列及 1 个重命名队列，共 1,350 个相互独立的因果组、2,700 个有向记录。逐组检查涵盖自然供受体的同答案关系、自替换身份、同位置词元、独立样本签名和筛选分数的精确重放，保留全部已执行方向和失败条目。单卡各进程计算阶段墙钟累加为 9,234.04 秒，按时间区间合并并行重叠后为 3,018.44 秒（50 分 18 秒）。第一阶段开始到最后阶段结束为 3,491.32 秒，包含加载和阶段间隙。运行结束后设备显存为 0 MiB。[运行时间](results/runtime_accounting.json) · [完整审计](results/execution_audit.json) · [执行日志](results/logs/)
